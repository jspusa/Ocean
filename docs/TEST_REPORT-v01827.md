## GPU 方法修正與判讀界線

首輪八視角 ABBA 已保留於 `gpu-desktop/report.json`：海溝仰視中位差額 +43.36%，同一候選 block 首五筆與末五筆也明顯漂移，不能直接把差額歸因材質。初版只有載入 context 時暖機，換到前景的每個 block 沒有重暖；最終 harness 每 block 至少 60 個完整未計時 frame 且串流穩定，再取得 25 個完整 frame queries，保存暖機耗時與樣本時間戳。

診斷交換 ABBA／BAAB，仰視兩輪結果見下表；淺礁相同像素的控制仍有測量波動。最終全景測量也保留正負差額，不把單次最快樣本或任一診斷輪當成普遍改善。測試期間沒有其他代理 CPU／GPU 測試，但作業系統及其他一般應用未停用；曾觀察到 Spotlight 背景 CPU 活動，沒有擅自終止系統服務。

## 尚未完成
