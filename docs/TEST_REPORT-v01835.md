# 0.18.35 深海生物曲面與柔動

基準為已發布的 `b41784703a5c31b206d846964037c62d9ab6003a`。本輪是深海生物外觀與動畫改善；保留 0.18.33 音效準備最多等待 1.5 秒的修復。完整商用目標仍持續進行。規格見 [本輪規格](parity/ABYSS-REALISM-v01835-SPEC.md)。

## 幾何與動畫

三腳魚的胸鰭膜從獨立小片改為共享邊界的封閉連續表面，普通鰭與感覺鰭加入輕微張力曲面。三個接地點與 25 cm 標準體長保留，沒有添加發光器官或提高全海域亮度。

小飛象章魚的八腕、腕蹼、吸盤與 cirri 共用彎曲腕線；自由端內捲，腕間有柔和垂弧。腕膜動作沿深度傳遞相位，根部固定、徑向變化維持 4.5% 上限，表面法線包含完整相位導數。形狀、配色和節律為原創設計，不是精確生理量測。

正式 Renderer→原生 WebGL 的 RED 測試僅深度時序獨立性失敗；修改後 7／7 通過，包括 1,680 個舊 rig 0–7 取樣的位元一致、身體／眼睛／耳動作一致、根部／上限、確定性及獨立差分法線驗證。既有兩種 rig 的檢查亦 2／2 通過。這些是有界取樣，不代表所有生物全部像素或所有時間均已驗證。

三腳魚兩級模型為 6,492／2,912 三角形，索引資料共 496,944 bytes；章魚維持 8,688／2,288 三角形與 470,208 bytes。兩種既有上限均未放寬。章魚另修正頂端錐形收尖，去除高頻頂點斑點，144 個同位置皮膚取樣的跨 LOD 最大 RGB 差異為 0.00198；這是連續性檢查，不是寫實度評分。

三腳魚 8／8、章魚 9／9 的分段 RED／GREEN 全部保留。三腳魚曲面開發曾因遠模型超出預算及局部法線反向失敗，修正後通過，沒有刪掉原失敗紀錄。

## 編譯與畫面

完整編譯保留 505 批次、457 份獨立幾何、184 分塊；解壓 57,457,392 bytes，gzip 21,750,793 bytes。與固定基準逐批比對，只有兩種生物的四份近遠幾何改變，其餘 501 批次幾何完全一致；地形、障礙與個體清單不變。首次嚴格全節點比對失敗只因三腳魚派生 `modelCenter` 有小於 0.000001 model unit 的曲面外框差，實際 UID、home、尺度與其餘欄位未變；回執明列該差異。

根代理檢視實際正式棲地影像與兩張重新繪製的圖鑑 JPEG：章魚的圓頂、腕間弧面及末端內捲可辨；三腳魚鰭膜相接、薄鰭受光有曲面，但黑色細小頭部仍不突出。眼圈、規則腕緣與整體塑形仍有遊戲模型感，本輪不宣稱照片級擬真，也未為了照亮頭部更改全域燈光。固定影像相機／時間僅作視覺診斷，正常照片另列。

## 驗收狀態

完整 CPU 初跑 108／109 suites 通過，來源前後指紋相同；唯一失敗為模型資料增加後的舊精確大小期望。依逐批編譯對照確認增加 49,968 bytes 全來自三腳魚曲面，精確更新期望後定向重跑 6／6 通過，最終合併 109／109，未重跑其餘已通過套件。靜態初跑與最終封裝皆 71／71 通過。桌機與同機觸控的原生 headless Chrome 完整玩家流程各 52／52 通過；固定模型成本與近遠圖像驗證已完成；公開交付尚待核對。公開仍以 GitHub Pages 與公開檔案回讀收據為準，不能把本機修改或 Git 上傳視為已部署。

## 證據範圍

原始 RED／GREEN、編譯、CPU、GPU、正常操作影像與公開結果保存在 `qa/parity/v01835-realism/`。瀏覽器驗證使用原生 headless Chrome／Apple M3 Max；手機配置是同機觸控模擬。固定影像與 GPU fixture 會明確固定時間、相機及解析度，不等於自然遊玩 FPS。實體手機、耗電、完整原作內容與公網多人仍未由本輪完成。

## 正常玩家影像

桌機從新存檔經正式首頁與海流導覽，依序通過 8 次停留至 7,000 m；兩種生物各停留至少 15 秒不自動命名，主動點選後拍攝、回首頁沖印、完成遊戲內攝影委託並重開。三腳魚原圖 180,164 bytes、章魚 52,919 bytes，沖印、投稿與重載後 SHA-256 相同。15,285 個完成畫面記錄中沒有自動畫質停用、context loss 或未選取名稱；沒有 page／console／GL 錯誤。這是行為紀錄，不能充當逐像素黑閃或 FPS 驗證。

獨立照片複核未見主體裁切、明顯肢體脫離或破面；三腳魚三支支撐完整、章魚雙耳雙眼及腕蹼清楚。細小頭部、規則對稱腕緣與均勻皮膚仍是明列限制，照片距離也不足以驗收所有吸盤及細絲。呼吸氣泡位於側邊，沒有遮住主體。

觸控模擬亦完成相同全流程，三腳魚原圖 58,980 bytes、章魚 25,301 bytes，沖印／投稿／重載後完全一致。15,318 個完成畫面沒有自動畫質停用、context loss 或未選取名稱；兩端預設畫質分別為 2／1，觸控畫布為 585×1266。根代理檢視觸控原圖，主體和三腳均完整；細鰭仍有低解析度邊緣鋸齒，不能以桌機模擬推論實體手機畫質、幀率或耗電。
