# 0.18.34 深淵生物相遇

本輪追加三腳魚與小飛象章魚，保留 0.18.33「準備海底聲景」音效等待修正。規格見 [SPEC-v01834](parity/SPEC-v01834.md)。本機必要驗收與公開交付已完成；完整商用目標仍持續進行。

## 實作範圍

前 44 類索引、舊個體與棲地保留，在尾端新增兩類與兩個固定身分個體。連續導覽於約 2,400 m 及 3,600 m 停留，觀察後由玩家決定續行；未點選不顯示中央名稱。三腳魚的 25 cm 為標準體長，不含延伸鰭；小飛象章魚的 20 cm 為本作代表縱向全體尺度。形態與設計值分別記錄於 [三腳魚](parity/TRIPOD-FISH-REFERENCE.md) 及 [小飛象章魚](parity/DUMBO-OCTOPUS-REFERENCE.md)。

三腳魚三支支撐鰭固定接地，感覺胸鰭微動；小飛象章魚成對耳鰭拍動、八腕蹼緩慢收放。身體、附肢與動畫法線使用既有正式材質路徑；只新增四個近遠模型批次，沒有新增全畫面粒子或更改自動畫質預設。本輪玩家驗收依序經主動觀察、真實快門、底片沖印及獨立原圖投稿；投稿條件本身檢查指定物種／個體、分數與拍攝距離旗標，不強制先前已點選。

模型與兩張 640×360 圖鑑 JPEG 均為本作原創。小飛象章魚的正面朝向及耳鰭靜止角度依可見性修正；色彩、比例、節律與位置是設計值，不宣稱野外精確量測。三腳魚保留深炭灰色，修正照明下近乎全黑的身體，未增加自發光或提高全域深海亮度。
