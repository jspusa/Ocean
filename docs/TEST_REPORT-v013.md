# 0.13 原創洞窟、遺跡與深海調查：驗證紀錄

本輪延續 Wii 第一代 Endless Ocean 的完整 feature parity 目標。新增三處實體區域、六章《回聲潮譜》、三個故事解鎖泊位與五種深海生物；**完整對等仍未完成**。0.12.1 已發布的歷史證據保留在 [前版報告](docs/TEST_REPORT-v0121.md)。**0.13.0已發布並通過公開驗收**，遊戲提交 `0a2818bffa9390d7e9d11ddf5c01c0ad4df0af9e`。GitHub Pages於2026-10-13 08:58:10 UTC建置完成；當日08:59 UTC核對 [公開版本](https://jspusa.github.io/Ocean/?v=0.13.0) **11/11**，85檔位元數及SHA-256全部與本機候選一致。

三區包含有頂洞道、側室與天窗，遺跡中庭及檔案室，以及約94公尺深的裂谷。牆、頂、地面同時影響游動、觀察遮擋與第三人稱鏡頭。頭燈依距離、錐形範圍、表面方向與水中光色衰減照亮實體表面；它是即時近似，沒有光線追蹤或科學光學精確性的宣稱。

六章調查承接眠海號記錄器，包含現地層理、解讀圖形、回訪、三點部署及連續記錄、完整輪廓的生物觀察、回收儀器和船上回報。暫停、失焦、照片檢視、離開距離或遮擋會取消未完成的連續記錄。保存保留已完成步驟，未完成秒數不跨重載累積。觀測器由進度推導，最多三個，部署與回收改變實際場景。

新增腔棘魚、巨型烏賊、吞鰻、駝背鮟鱇與日本蜘蛛蟹，共九個體。8m烏賊含長觸腕、3m蟹是腿展、鮟鱇採用來源記載的9cm個體尺度。32類／734個體；原725個體的順序、ID、home、位置、種子與尺度保留。[形態與尺度來源](docs/parity/ABYSS-FAUNA-REFERENCE.md)、[區域與故事基準](docs/parity/WII-WORLD-REFERENCE.md) 清楚區分原作證據及本作設計。

本機靜態驗收 **47/47**；85個manifest檔案全部符合位元數與SHA-256。最終場景364 meshes／3531 nodes，解壓43,163,484 bytes、壓縮17,686,703 bytes；首頁12,953 bytes，離線單檔38,322,253 bytes。25組CPU回歸套件全部通過。離線最終驗收 **10/10**，桌面與觸控模擬均可開啟、下水及進入工具，沒有網路請求或未捕捉例外；公開驗收 **11/11**，桌面與觸控模擬均可啟動、下水及使用工具，沒有未捕捉例外或繪圖context遺失，85檔完整核對位元數及SHA-256一致；公開啟動診斷在導覽完成後2987ms／1991ms ready，不能當作其他網路條件的載入保證。

離線首次批次的觸控啟動曾超過舊測試實際30秒上限；原始失敗另存，原因未能重現。修正Playwright逾時參數位置並在導覽前收集診斷後，連續兩次離線10/10；最終在頁面導覽完成後1215ms／1227ms ready、consoleErrors為空、context完整。沒有將延長等待寫成產品缺陷已查明或修復。

## 審查與尚存差距

[Spec審查](docs/parity/REVIEW-013-SPEC.md) 與 [Standards審查](docs/parity/REVIEW-013-STANDARDS.md) 記錄兩個獨立審查軸與修正證據。全作仍缺完整214條目對應內容、全部潛區／故事深度、季節生態、全任務／裝備／收藏及訪客、跨客戶端雙人／好友／工具交流、完整手把與實體裝置驗收。214是原作圖鑑保存畫面盤點，不是Nintendo公布數字。

洞壁與裂谷追加細分岩面及岩層起伏；實際頂點留在原碰撞範圍內，游動側內縮不超過20cm。遺跡仍保留石造形態。五種模型修整嘴部接合、鰭緣、斑紋與圖鑑角度，修整前後包圍邊界逐值相同。

新模型仍為原創程序模型，洞窟與遺跡為原創構造。沒有同硬體原作對照，不宣稱已全面超越Wii或達到攝影級擬真；完整目標保持進行中。
