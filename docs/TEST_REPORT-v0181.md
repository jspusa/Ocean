# 0.18.1 每幀更新與查詢成本

## 實際瀏覽器遊戲邏輯

兩個 Chromium context 載入完整正式場景，包括 427 隻一般／裝飾生物及 380 隻群游魚；固定相同畫質、內容及前景狀態，執行真正 `animate()` 的游泳、動物、生態、相機、觀察與介面更新。暖機 240 步，再以交替先後順序量測八輪、每輪 240 步，取每輪 CPU 時間的中位數。每步使用相同 60 Hz 虛擬時間，所有生物、物理位置及動作快照完全相同。

| 邏輯更新 CPU，中位 ms／步 | 0.18.0 | 0.18.1 | 減少 |

這項量測以 render spy 隔離邏輯成本，因此**不含 GPU、繪圖提交、渲染內的串流更新或真實顯示幀率**。虛擬 60 Hz 是固定輸入排程，並非量到 60 FPS。手機型號／瀏覽器尚未取得；不能從此表宣稱其卡頓已全面解決。測試可重跑，原始數據為 `qa/parity/frame-cpu-comparison.json`。

## 刪除的工作

- **軌跡高度：** 固定深度動物不再先求海床再覆蓋結果；計算轉彎傾斜時，前一個軌跡樣本只求實際會讀取的 X／Z。公開完整軌跡預設行為不變。在同一完整生物更新取樣中，海床查詢 1,300 → 901，魚類避障 bucket 查詢 2,442 → 2,153。427＋380 個體的完整狀態，包括重複／倒轉時間、參數修改與展示模式，逐值一致；6/6 檢查通過，原版重播會在兩項無用工作斷言失敗。
- **固定洞頂索引：** 屋頂幾何及角色原已凍結；以 110 個 XZ 欄位、5,043 個既有物件參照索引，不複製模型。1,280 次相同洞頂查詢的 Set 配置 1,280 → 0，map 產生的陣列 5,120 → 0，候選索引查詢 49,648 → 1,280。保留原來精確線段／凸體求交，通用候選 Set 及順序不變；洞頂內外、負格邊界、深海與特殊高度輸入一致。
- **區域海床範圍：** 保守界限以外的區域混合權重必為零，直接返回同一原始海床值。147,095 個世界／邊界／特殊輸入以 `Object.is` 完全相同。10,000 次區域外查詢的區域 `hypot` 運算 50,000 → 0；沒有量化或近似高度。
- **附近地圖範圍：** 必須載入、前方預載及遠離保留三個目前位置集合一次判斷，仍讀取即時位置、可見狀態及原有畫質比例。靜止淺礁的 instance 位置讀取 1,530 → 788，外海 13,822 → 4,626，海溝 14,031 → 4,677。移動方向的前方取樣、48／128 m 邊界、陰影中心、請求順序、載入等待及釋放時機不變；5/5 新檢查及原串流 8/8、拍照等待 3/3 通過。這項額外節省不包含在上表的 render spy 量測。

沒有新增畫質降級、限幀、降低遠方動物更新頻率或擴大地圖載入範圍。原始幾何、貼圖、著色器與光影設定均沿用。

## 回歸與審查

區域相機 11/11、自由游泳 12/12、空間碰撞 8/8、生態 39/39、攝影 18/18 通過；原動作及鯨豚動作檢查通過。獨立 Standards 與 Spec 程式審查均未發現需處理的問題；Spec 要求另補實際 WebGL 與可見游泳證據，不能以 CPU 表格代替。

相同軟體 WebGL 環境中，0.18.0 與本版的 **11 個完整內容視角逐 RGBA 位元組相同**，沒有隱藏四種新魚。桌面／觸控、淺礁／外海／海溝、洞窟／遺跡、反向／寬畫面／直向皆保留相同解析度、體積光尺寸、4× MSAA、提交三角形、draw／陰影／上傳／uniform 次數；零 GL／pageerror。實際 `animate()` 的受控回呼測試保留低／高畫質／首頁每 120 回呼渲染 120 次、暫停／背景為 0，模擬時間與游泳位置相同。這驗證沒有用減少畫面工作或限幀換取 CPU 改善；不是實機幀率量測。

解除凍結後，桌面與觸控配置各完成六個真正 RAF／WebGL 畫面，實際游泳位置與生物動作持續改變；沒有繪圖 spy、強制回呼時間或 GL／pageerror，維持高畫質與 render scale 1。這補足連續渲染的功能證據。此環境使用 SwiftShader，實際回呼仍出現秒級間隔，**不列為流暢度通過或裝置 FPS 改善證據**；使用者裝置的 GPU 與完整幀時間仍未取得。

桌面／觸控的真實地圖網路與 WebGL 生命週期亦通過：啟動不請求整包場景，必要目的地缺失時保留畫面並凍結模擬，釋放 258／203 個遠方模型；回到淺礁後完整畫面雜湊相同，生物與船的資源有效，無 GL／pageerror。

整體自由海洋瀏覽器 33/33：桌面／直向／橫向的啟動、鍵盤／觸控、跨越舊邊界、7,000 m 存檔重載、外海生物與深海燈光；無瀏覽器錯誤。建置完整性及兩種散布格式的 MIT 包裝檢查通過；原始場景壓縮檔仍為 SHA-256 `719cee472608b570784271d4004ea47cf3d5c4427eff84d86d00bed72f6d96a6`。
