## 問題與實作

正式 load/save＋Storage 故障邊界重現：兩份航程損壞時，啟動仍可把 initialVoyage 寫回主檔並回報 true。最小 regression 在原實作得到 `true !== false`。只嘗試寫 primary 的案例同樣失敗，排除必須由備份輪替才能造成覆寫的假設。

安全讀取狀態現在與「曾載入既有航程」分開：兩份確定不存在可新建；任何不可讀且無可用備份時，不保存預設航程。日誌與航程任一不可讀時，照片初始化也不開啟／遷移資料庫，先顯示恢復畫面並停止入海。正常完整匯出不冒充未載入的舊資料；另有逐 key 原始文字救援，清楚標記 missing／read／unavailable，明示不含原圖與不可直接匯入。

正常寫入失敗保留本頁進度，以持續提示分列航程／圖鑑設定，提供重試及完整匯出。攝影／沖印的 IndexedDB 成功不再蓋過航程或日誌保存失敗。成功 primary 寫入後同步清除水下提示及首頁舊警告。
