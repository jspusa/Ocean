## 背景與量測

正式 blur／focus／visibilitychange 事件切斷渲染間隔量測，避免瀏覽器離開後不再執行 RAF，導致背景時間污染報告或誤降自動畫質。沒有裁切真正前景慢幀，也沒有改變畫質預算、取樣算法或模擬頻率。

`performance-lifecycle.cjs` 的正式事件處理器測試 5/5：背景 60 秒、零背景 RAF、恢復後完整 20 秒量測、僅焦點切換、自動畫質及可見慢幀。兩輪有效 RED→GREEN 保留在 `qa/parity/v01812-performance-lifecycle-red-hidden.log`／`-red-blur.log` 及 `-green.log`。

原生測試首先發現 Playwright 預設強制各頁維持前景，沒有任何真實離開事件；那些執行是測試環境診斷，不是產品失敗或通過證據。`performance-lifecycle-browser.cjs` 明確解除該覆寫後，用真正 Chrome 視窗失焦／恢復驗證七秒離開時間不進入量測，並繼續完成二十秒有效量測。原生執行不聲稱完全停止背景 RAF；零 RAF 邊界由上述 CPU 測試覆蓋。

首輪觸控完整流程中的另兩筆面板邊界失敗，是在 300 ms 滑入動畫的第 130 ms 讀取暫態位置；測試現在等待真實 `getAnimations().finished` 再量測，保留原動畫及幾何斷言。該診斷與真正頁尾裁切的原始結果同保留在 `v01812-activities-touch-layout-red.json`，不把暫態誤判列成產品修復。
