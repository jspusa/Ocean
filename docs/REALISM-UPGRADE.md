# 光之海 0.8 升級範圍

2026-10-12，依使用者要求，以 Wii Endless Ocean 的安靜探索感為方向，直接改善現有 GitHub Pages 遊戲。保留六段航程、九處地標、十二類生物、攝影、圖鑑和既有本機存檔格式。沿用原創素材與 WebGL2，不增加帳號或付費服務。

本輪交付：自然水體散射、海面折射、細緻光紋和陰影；珊瑚形態與遠景輪廓、海草和生物游動；第一人稱設定、視野調整、滑鼠自由環視；更清楚的相片；適應畫質恢復；桌機和手機介面。以瀏覽器畫面、真實 shader 編譯、操作測試和同機幀率為驗收依據。

測試：原有主要航程功能回歸、十二類生物視圖、三檔畫質、三種光照、資料保持與匯出、手機直橫向控制、無遠端素材依賴、WebGL 錯誤。新功能加入後才測試對應行為。

本輪不宣稱攝影掃描、科學光學求解、Wii 全內容對等或全裝置效能已驗證。Nintendo 原作為體驗參考，沒有使用其資產。
