# 0.18.6 游動光影、黑閃與海溝探索

基線 `bc68a543368585f2b576c58cf3a5b6e8165554db`（0.18.5）。依 [本輪規格](parity/SWIMMING-v0186-SPEC.md) 修正五項玩家回報，延續已授權的線上更新、電腦／手機自動畫質、自由游泳與主動指向／短點選取。AskMatt 的診斷、實作及兩軸審查流程已使用。

## 黑色閃屏

原生 Chrome／Apple M3 Max／ANGLE Metal 重現：`animate()` 畫完後，`oceanPerf.record()` 自動調整比例並呼叫 `resize()`；寫入 canvas 尺寸會清掉剛完成的畫面。原版在比例 1→.935 與 .935→.97 當下讀得 RGB 全零，GL 沒報錯。

現在只排程尺寸變更，在地形已可繪製的下一次 `render()` 開頭套用。區塊下載等待時保留上一張畫面。原生測試涵蓋自動下降／恢復、手動畫質、真實視窗 resize、直橫向轉換與攔截真實冷區塊下載；不是僅呼叫假的 resize listener。跨瀏覽器事件使用 compositor 截圖，避免把 `preserveDrawingBuffer:false` 的合法 readback 清除誤判成可見黑閃。

`resize-presentation-browser.cjs` 桌機／觸控全部通過；`native-adaptive-browser.cjs` 真實 4K DPR2 游動24秒，1396幀、兩次自動比例變更，當下 RGB 最大值113／106且下一次有效 render 尺寸正確，GL=0。這是已重現原因的回歸，不保證所有裝置／驅動永遠沒有閃屏。

另修正深海浮動原點切換時，陰影快取未包含原點的問題：`shadow-origin.cjs` 4/4，同原點仍重用陰影。

## 海溝與可見生物

保留原三站與原807個體的身分／棲地，另追加9隻既有種類到合理深度的沿途棲地。五段近側岩脊、有限泥台與海溝底18m下切溝都使用真幾何與相同碰撞表面，沒有只修改深度標籤。地形預算91,056三角形／107批次；場景總量495批次、447共享網格、179分區、816個體、41物種，前後幾何預算詳見 [地形驗證](parity/TRENCH-EXPLORATION-REFERENCE.md)。

導覽保留連續游動與所有原路徑轉角，三處棲地慢行停留4秒，最後接近真實動物。巨型烏賊停點約16m；小型生物保留自然巡游和直向視野餘裕。移動、拖曳或點選即可接管，沒有自動名稱或解鎖圖鑑。深海入口移到探索選單主層。

探照燈在不增加 pass 的情況下拓寬外緣並調整距離衰減，降低背散射霧光，讓側牆層理可讀；保留雙程光譜吸收、法線、粗糙度與遠方黑暗。表面、粒子和照片光照評估共用燈具參數；側向8m岩面檢查由舊版零光照改為弱照明，90度外仍為零。
