# 0.18.25 桶眼魚與透明頭罩

基準 `6f86f7ce063c328193d1eb214eef039f63dd27f5`；[規格](parity/BARRELEYE-v01825-SPEC.md)、[形態來源與遊戲編排界線](parity/BARRELEYE-REFERENCE.md)、[獨立審查](parity/REVIEW-v01825.md)。本輪本機及公開交付驗證完成；完整商用目標仍未完成。

## 內容與渲染

圖鑑追加第 44 類桶眼魚，保留既有 43 類索引、個體、路線與保存。正常微光中層海流可連續接近 690 m、代表全長 0.14 m 的原創個體；點選後才顯示名稱，可觀察與拍照。眼管於透明液體頭罩內緩慢由上轉前，綠色晶狀體不自發光；胸鰭、尾鰭緩動，大腹鰭保持穩定。數量、代表尺寸與行為節奏是本作設定。

同一高低網格的不透明前綴供顏色與陰影使用；透明罩保留索引範圍，於既有後處理目標局部疊合，使用自身水中距離、照明、深度遮擋和相同 LOD。沒有新增全畫面 pass、render target、貼圖或逐幀生成幾何。聚焦罩一個局部 draw；失焦拍照最多九個局部 draw，是沒有折射的薄組織近似。

高模 11,574 三角、低模 3,160 三角，兩模索引資料合計 623,400 bytes。以實際模型凸面驗證各眼動角度的眼組織仍在罩內；全部眼組織使用同一旋轉，法線跟隨眼動、尾波與胸鰭形變。仍有程序模型感，不宣稱完整透明光學或全面超越 Wii。

## 水族館實際整合

桌機／觸控尺寸各 25／25。新存檔明確預置三類生態筆記，只作開館資格 fixture；由實際選單配置兩隻桶眼魚到位置 0／5，正常進出三次、保存重載後第四次進入。不是自然解鎖全部筆記的證據。下拉選單採可見控制項的 DOM select/change，其餘點選、拖曳與退出採原生輸入；不把 DOM 選值描述為系統原生選單驗收。

實際 cloneMesh／createScene 建立兩隻原尺寸 0.14 m 展示體，共用來源 VB／EB／透明索引範圍，但 VAO、實例緩衝區與 actor 各自獨立；不直接捏造複製批次。正常世界 531 批，進館後 585 批，54 個展示批次在反覆進出時重用。共 1,947 個正常回呼呈現樣本沒有黑色樣本、GL、屬性位移或個體不變量失敗；野外唯一 UID／尺寸／home、陣列順序、可見旗標在退出時恢復。自然時間推動小幅懸停及眼管旋轉，0／6／12 秒圖片人工可辨透明罩內的眼動；沒有指派姿態或強制 render。

最初兩次桌機 fixture 的 macOS 原生 select 鍵盤導航未改變選項，保留各自失敗報告；改成明確標示的 DOM select/change 後重新執行全部檢查。未將這個測試工具問題稱為遊戲渲染問題，也未聲稱原生系統選單已通過。亮水族館中仍有程序模型感；實體手機與完整自然開館流程不在本 fixture 的證據範圍。
