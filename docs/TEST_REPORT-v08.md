## 實際範圍

測試以真實網頁載入編譯場景；操作原生按鈕、鍵盤、滑鼠與 CDP 雙指觸控。涵蓋下水、移動、轉向、暫停、拍攝 JPEG、切換觀察個體、圖鑑、回船與 JSON 存檔下載。視野、水體濃度與第三人稱設定經重新載入後仍保留。原有存檔格式與生物 ID 保持相容。

六段航程以受控位置、紀錄與時間推進驗證；鯨魚使用實際模型位置及取景判定。這不是完整真人遊玩測試。匯入檢查驗證非法 ID、網址與設定上下限；本輪沒有重新執行所有 0.7 的檔案匯入互動案例。

手機回歸檢查 390×844、844×390、768×1024、1440×900 的版面；獨立檢查另涵蓋 320×568、360×640、568×320、667×375，包含觀察卡開啟時的按鈕命中範圍。雙指可同時游動與轉向，取消後輸入歸零。

另驗證 60Hz 排程下的自動解析度恢復、手把只有深度輸入時斷線歸零、瀏覽器拒絕滑鼠鎖定後恢復拖曳。排程與手把為 fixture，不是手機或實體手把效能結果。

## 同機效能

相同 1440×900、DPR 1、細緻畫質、4× MSAA、固定解析度與礁區攝影機；每版量測 20 秒。0.7 取自升級前公開站，0.8 取自本機 HTTP。場景載入完成後量測，不包含下載速度。

| 指標 | 原版 0.7 | 新版 0.8 | 證據 |
|---|---:|---:|---|
| 平均 FPS | 59.70 | 60.00 | ★★★ 同機實測 |
| P95 幀間隔 | 16.70 ms | 16.70 ms | ★★★ 同機實測 |
| WebGL 錯誤 | 0 | 0 | ★★★ 實際渲染 |

結果顯示此測試條件下升級維持約 60 FPS；不是顯著加速的證據，也不外推至所有手機。未進行 20 分鐘熱降頻或輸入延遲量測。

## 資產與視覺

本版場景為 307 個索引網格、3,435 個共享場景物件，gzip 14,094,578 bytes，解壓 31,517,192 bytes。12 類生物、673 個遊戲個體保持一致；個體含群游魚，並非 673 種。十二張圖鑑圖片皆從目前 WebGL 模型重新拍攝。

固定攝影機檢視開場、礁區、仰望海面、珊瑚花園與沉船；截圖是引擎輸出。修正光束條紋干擾、海面以上焦散、珊瑚遠景輪廓與部分模型封口。仍為原創程序模型和即時光學近似；沒有以截圖宣稱攝影級真實或全面超越 Wii。

## 重現

```sh
python3 build.py
python3 -m http.server 8000
node tests/v08/reef_invariants.cjs
python3 tests/v08/static_check.py
node tests/v08/browser-regression.mjs http://127.0.0.1:8000/
node tests/v08/browser-regression.mjs http://127.0.0.1:8000/ --mobile
node tests/v08/capture.mjs http://127.0.0.1:8000/ after
```

需要 Node.js、Python、Playwright 和 Chrome。測試 JSON 與實際截圖輸出至 `qa/v08/`，不列入網站版本庫。`MANIFEST.json` 覆蓋遊戲部署檔案與編譯來源。發布後另核對 Pages 的版本、編譯場景載入與桌機／觸控啟動；此報告的計數為發布前測試。
