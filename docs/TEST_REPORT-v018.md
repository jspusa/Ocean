# 0.18 礁間新訪客：發布驗證

日期：2026-10-23。程式變更基準為已發布的 `98d788f889e2b4aa2fedcd4d8526c5f065b6cd14`（0.17.1）。本次延續附近地圖串流，不改解析度、MSAA、原有自動畫質或正常更新排程；增加原創生物與手把選單，並清除無效 WebGL 呼叫及音樂切換競態。

## 範圍與量測邊界

地圖仍為 177 個按需載入的內容定址區塊，既有 481 個編譯批次與原始場景壓縮檔不變。地圖下載／常駐量及串流等待行為見 [0.17.1 效能報告](TEST_REPORT-performance.md)。新增魚以八個共用近／遠模型批次追加，不重傳整份地圖，也不複製每隻魚的模型。

新內容會改變含魚的畫面。本版舊內容差異測試僅隱藏 `sceneRole === 'reef-fish-expansion'` 的新增批次，對照原始 0.17.0 的固定相機／時間／畫質。這與新魚的獨立實際渲染驗證分開記錄，不能宣稱整版所有畫面均與原版相同。

以下瀏覽器驗證使用 Chromium／SwiftShader。手機為觸控與視窗模擬；工作量、buffer bytes 與受控回呼數均非實體裝置幀率、整機記憶體或耗電讀值。

## 行為與資源

- **四種新礁魚：** 金背花鱸 28、邦蓋天竺鯛 14、長吻蝶魚 8、雷達魚 14，合計 64 個體，圖鑑 37 → 41 類。原創幾何／色紋／鰭形與暖水展示路線；[形態及分布依據](parity/REEF-FISH-REFERENCE.md)。舊物種順序、個體識別、基因、尺度及八個取樣時間的動作保持相同。64 隻連續 180 秒／120 Hz 的完整模型界限檢查：最大單步 0.001629 m、離海床至少 0.253 m，未穿入所檢查的礁石；5 組 CPU 檢查通過。
- **新魚實際畫面與保存：** 桌面／手機直向瀏覽器 34/34，零 pageerror。四種均在實際編排棲地顯示，用真實滑鼠／觸控選取並經觀察解鎖紀錄；實際快門保存雷達魚個體識別與有分數的照片、JPEG 可解碼，重新載入保留四種發現與照片識別。注入明示的第二層熟悉度後，四種可配置成獨立水族館住客並渲染，沒有改動海中個體 home。已目視檢查四種的桌面／直向截圖與直向水族館；不是自然遊完全流程驗收。
- **新增模型成本與遠近切換：** 另次受控 WebGL 查詢，八個新批次的不同頂點 buffer 876,624 bytes、16 位索引 129,408 bytes，幾何合計 1,006,032 bytes；實例 buffer 12,288 bytes，合計 1,018,320 bytes（0.971 MiB）。這不包括 JavaScript 幾何快取、驅動或 framebuffer；原始索引模型快取另為 1,135,440 bytes。四種在 7.2／7.9／8.1／8.8 m 實際繪製依序為近、重疊、重疊、遠批次，無提交空缺或 GL 錯誤；重疊沿用原有互補遮罩。
- **手把選單：** 沿用既有 DOM 控制項及處理器，方向鍵巡覽、A 確認、B 返回、左右調整選項／滑桿、受控長按及斷線清理。閒置手把不做 DOM 巡覽。CPU 12/12，桌面／手機直向瀏覽器 37/37：首頁進入不誤拍照、保留游泳／LB／Start、設定與進階摘要、工具、照片返回、焦點清理及設定重載，零 pageerror。瀏覽器注入標準手把資料，未替代實體控制器驗收；畫布手勢及原生檔案挑選仍待補齊。
- **無效 uniform 呼叫：** 固定參數數目的 setter 重用原位置快取，跳過 shader 未使用的 `null` 位置，保留位置 0。三個實際渲染流程的程式化 GL 對照，總呼叫 213 → 134、188 → 121、213 → 134；有效參數的值、順序及每次 draw 狀態完全相同。4/4 通過。這些是指定 fixture 的提交次數，不代表整體 FPS 改善比例。
- **本機音樂：** 新選擇／重設使過期讀取與解碼結果失效，失敗保留目前曲目，替換成功才停止舊來源；不覆寫稍後的靜音設定。11/11 競態及失敗檢查通過，既有船上音樂 13/13。瀏覽器已開始的原生解碼不可中止，不宣稱能取消其暫時記憶體。
- **商用包裝：** 保留原始 MIT 與權利人，模組入口與離線單檔皆附完整授權文字，LICENSE 納入完整性 manifest，3 項包裝檢查通過。原創來源聲明與商用前仍需核實的權利／主機限制見 [商用準備盤點](COMMERCIAL-READINESS.md)，並非獨立法律清權證明。
