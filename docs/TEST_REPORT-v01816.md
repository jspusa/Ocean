# 0.18.16 入水流暢度與房間恢復

本輪以 `07ac078ca0e2a72e70d005888836725aec1a9882` 為基準。正式變更只新增有界的船體 fragment 程式、同一 WebGL context 的取樣能力快取，以及獨立本機房間服務的未確認重連恢復。模型、材質公式、波浪、光線、MSAA、初始解析度及桌機／手機自動畫質保持。

## 房間恢復

`server/` 新增精確原始 resume 請求與安全 nonce 的未確認重試證明，僅保留一個 digest，最初期限固定且重試不延長。每次交接旋轉能力值及世代；當前世代確認或通過 session／seq 驗證的操作立即撤銷證明。舊世代無法確認或奪回連線。

真 HTTP／TCP／WebSocket／CLI **34/34** 及語法檢查通過。TCP proxy 實際丟棄連續三次 joined 回覆，旁觀成員見世代 2、3、4，原客戶端最終恢復原席位於世代 5。另驗確認 ack 遺失、原期限不延長、錯誤 nonce 與舊世代確認。證據 `v01816-server-tests.log`、`v01816-server-check.log` 及 `v01816-resume-*.log`。

這仍是本機基礎：初次建房／核准的第一個 joined 遺失、重啟保存、前端同遊、公開部署與 B–E 尚未完成。完整商用及 Wii 功能目標保持進行中。

## 最終驗證與交付

本輪 CPU **89/89 suites**、靜態 **61/61** 通過，分別見 `v01816-final-cpu-results.json` 與 `v01816-static.json`；本機房間 34/34 另列。船體正式接口 RED 5/6 → GREEN 6/6，包含動態道具、交錯 shader、未知配對與編譯失敗回退；MSAA 快取 12/12。

已知黑閃原生回歸通過（`v01816-resize.json`／`.log`）：桌機與觸控涵蓋自動解析度下降／恢復、手動畫質、真正視窗／方向事件，以及實際冷區塊下載等待時保留上一張已呈現畫面；GL=0、無 context loss。不據此保證所有硬體的間歇性閃黑全部消失。

觸控尺寸的正常入口兩段各 20 秒亦通過（`v01816-startup-touch.json`／`.log`），預設 adaptive=true，585×1266 全程無 resize，平均提交間隔 16.826／16.653 ms，首次首頁切入最大間隔 180.2 ms 保留。這是在同一桌機的觸控模擬，不是實體手機或耗電測量。
