# 0.18.8 航程、相簿與備份保護

基準 `5a45359`（0.18.7）。本輪依 [規格](SAVE-v0188-SPEC.md) 完成 AskMatt implement／TDD 與獨立 Standards、Spec 審查。這是存檔可靠性切片；整體商用與完整功能對等仍未完成。

## 實作與玩家行為

Web Locks 在航程讀取、照片搬移和 Renderer 建立前取得排他使用權。第二分頁顯示原生 dialog，可用鍵盤與觸控重新讀取；它不建立另一套 GPU 遊戲。缺少或拒絕鎖定 API 時不略過保護。關閉後由新文件重新取得鎖與讀取資料，不搶占舊記憶體。普通背景切換保留原分頁，離頁／凍結則暫停操作；等待已開始的照片與匯入工作結束才釋放使用權，沒有計時租約。

航程與日誌透過同一個寫入邊界，照片在取得資料庫前後及交易回呼中確認使用權。舊版本不遵守新鎖定機制，以 storage 事件及寫入前快照比對偵測外部變更；只能停止本版繼續覆寫，不能阻止舊程式已經執行的寫入。更新時提示關閉舊版分頁。

匯出不再附帶保存或採用別頁的相簿。匯入／匯出互斥；離頁等待中的匯入仍保有鎖。匯入失敗的照片回滾只有在仍持有鎖時可執行，並保留既有 revision 比對。即使資料庫回滾失敗，記憶體仍恢復匯入前的航程及原圖，停止保存、顯示恢復畫面，讓玩家下載一致的救援備份。介面不聲稱資料庫已還原。

## Spec
