# 0.18.20 水中光影與深海照明驗證

狀態：本機驗證完成，待公開發布核對。基線 `268dd3c4594a5465d05d9a642a1e09fc9e422fd4`；[本輪規格](parity/WATER-PRESENTATION-v01820-SPEC.md)。本文件不替代完整 33 項或商用驗收。

## 實作

微粒及氣泡在原有水色合成後、最終 AA 前，使用自身世界深度／距離、既有光學與頭燈參數消光，讀 resolved scene depth 遮擋。保留 240／520 個微粒、呼吸氣泡的固定 buffer／數量／原有生命週期及四個全畫面繪製；沒有新增 FBO、貼圖或幾何。使用顯示色域透明混合近似，沒有宣稱完整物理折射／透明散射。

攝影時用自身距離及正式光圈／焦距計算同樣上限 8 px 的 CoC，放大／柔化點輪廓並補償面積能量；不是額外全畫面模糊。岩壁重用既有石材取樣及單次 noise，打散層理相位並增加有限材質差異。

`oceanSunlessView` 對非有限輸入、無效遠裁切及垂直 FOV >90° 保守回傳 false。固定 world-up 相機下，視野遠平面的最高伸展 <2×far；預設 far=950 m，眼睛深度 ≥4,900 m 時每個接收面至少有 3,000 m 水深。只裁剪表面太陽光、陰影取樣和體積太陽散射，仍更新兩張陰影貼圖、保留頭燈／AO／生物光與原有曝光。上浮時每幀恢復原路徑。

保守光學上界：surface 單通道差 <830 exp(-.009d)，volume <4.6 exp(-.009dmin)。d≥3,000 m、最大曝光 1.11×2^1.5、film Lipschitz <4 加 gamma 1/2.2 下，連續顯示域上界 <0.081 個 8-bit 色值；這不涵蓋 render target 量化或末端 AA 分支，不等於像素相同證據。

## 太陽分支像素驗證

首輪 `v01820-sunless-render.json` 共 46 場景，參照把 uSunless 改成編譯常數 0。嚴格 RGBA 檢查**失敗**：34 個 production blocks 各 1–3 個通道差異，最大 1/255；含 sunless=false 的淺一段場景，故不能把差異全歸因於移除太陽光。差異影像與 raw RGBA gzip 完整保留。沒有修改容差或宣稱完全相同。

同一正式編譯程式、僅參照強制 uniform=0 的第二輪 `v01820-sunless-uniform/report.json` 完成 46 fixtures／184 ABBA blocks。嚴格零差異診斷仍為 **FAILED**：22 個 production blocks（桌機 16、觸控 6）各 1–3 個像素的單通道差異，最大 1/255，總計 34 個通道，alpha 無差異；全數只發生在 sunless 啟用場景。所有參照與非 sunless blocks 完全一致。沒有放寬該診斷的容差。

差值同時有 +1 與 -1，不能全部歸因於刪除正值太陽能；分支運算、浮點累加、半精度 target 與末端量化／AA 是可能來源，尚未逐一歸因。原契約明確允許有界近似，因此以解析光學上界與實際差異記錄接受本次近似，沒有宣稱 byte-exact 或所有 GPU 皆相同。兩次失敗報告、差異 PNG 及 raw RGBA gzip 完整保留。

## 最終回歸

完整 CPU 首輪 94/95 的原失敗保留。修正 uniform-submission 測試後，仍使用同一份不可變 v0.18 fixture：先逐項驗證 11 個新增 active uniforms 與唯一 point pass 搬移，再將這些明確變更投影回舊呼叫／逐 draw 狀態雜湊。null=0、每個 location 只查一次、zero-location 及引用轉送斷言保持，另驗真實 bubble／point 的深淺、尺寸、曝光與攝影參數更新。單檔 7/7，最終完整 CPU **95/95 suites**；來源 shader 未因驗證修正而變更。
