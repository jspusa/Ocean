星星只表示所列範圍的驗證程度。多組檢查重複覆蓋部分能力，不能把通過數視為玩法數或功能對等百分比。

攝影測試操作真實按鈕與鏡頭控制，讀取 WebGL 像素確認光圈／對焦改變實際影像，拍下青雀鯛 JPEG，再回船投稿、解鎖配色、重載。完成投稿可重新開啟實際附件；相片載入與匯入會移除重複日期識別，避免重複附件占滿容量、擋住新照片；再拍十張真實照片後，已投稿影像仍保留在八張總容量內，重開瀏覽器及 JSON 匯入後也仍可取回。照片 metadata 經實際下載存檔與檔案匯入保留；普通快門記錄實際普通成像參數，不假稱使用未啟用的鏡頭設定。

帶路測試確認獨立訪客模型移動，並在受控位置驗證目的地、訪客距離、實際海龜與遮擋條件，再回船領取獎勵。這些受控位置加速驗證不代表已用手動游動跑完整旅途。氣量耗盡使用縮短剩餘氣量的 fixture，確認回船、清除續潛位置及保留已完成委託；規則測試另外驗證暫停、隱藏分頁和自由模式不耗氣。

生物與探索測試用真正指標／CDP 觸控手勢驗證輕撫、點觸、部位指令、連續動作、世界筆跡及雙指海圖。九件收藏皆經實際碰撞結果核對可靠近拾取；重開保存，不重複取得。另修正第三人稱互動距離、手機按鈕重疊，以及畫筆切換相機後仍攔截拖曳的衝突。哨聲經 OfflineAudioContext 實際合成，確認有訊號、結束歸零、快速重複有界且靜音生效；不是人工聽感評分。

水族館測試驗證手動／自動配置、刪除／清空、保存重載，實際獨立生物動畫、雙指縮放、鍵盤焦點／Escape、五次重返不新增 GPU 批次，以及退出／換面板／匯入重設後還原原世界的可見狀態。桌機與手機截圖已檢視全景、小魚近看和大型生物，沒有將名單代替三維展館。

新功能都保存在原有航程的獨立分區，舊存檔獲得合理初始值；輸入限制已知 ID、有界陣列與有限數值。審查發現不存在的海豚編號可占滿名額，已改為核對已初始化的實際個體目錄，並補上名額及選擇狀態修復回歸。切換面板透過共同生命週期通知取消／清理互動，不依賴已暫停的動畫迴圈。全機制存檔仍須在後續功能加入時持續驗證。

## 視覺與效能範圍

光圈景深是受深度控制的即時近似；普通游動不執行鏡頭散景取樣。沿用 0.8 已驗證的編譯礁體，沒有重烘焙或更換世界資產。應用程式版本為 0.9.0，幾何檔頭 `sourceVersion: 0.8.0` 是預期相容行為。

基礎場景仍為 307 個索引網格、3,435 個場景物件，gzip 14,094,578 bytes，解壓 31,517,192 bytes；12 類生物、673 個個體。新食物／筆跡／打撈／訪客使用有界批次；水族館首次進入建立展示批次，後續重用，不複製世界魚隻的可變狀態。

本機 1440×900、DPR 1、細緻畫質、4× MSAA、固定解析度與礁區鏡頭量測 20 秒，ANGLE Metal / Apple M3 Max 平均 **59.45 FPS**，P95 幀間隔 **16.70 ms**，WebGL 與未捕捉錯誤皆為 0。測試使用當前 0.9 引擎與功能模組；未同時啟動其他測試瀏覽器。這是基礎礁區的渲染幀率，沒有量測所有工具同時運作的極端負載。重現：`node tests/v08/capture.mjs http://127.0.0.1:8000/ v09`。

本版不是原作素材重製、攝影級掃描或科學潛水模擬。沒有 Wii 同機對照、實體手機熱降頻或長時間遊玩證據，因此不宣稱全面超越 Wii 或所有裝置都達 60 FPS。
