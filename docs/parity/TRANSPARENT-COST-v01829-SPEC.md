# 0.18.29 透明散焦效能

固定基準 `eaf62daa63ff1adbf79d6342cd8a399eb917d9b1`（已發布 0.18.28）。延續完整規格第 13、14、23、32 項及 [透明攝影規格](TRANSPARENT-PHOTO-v01828-SPEC.md)，處理上一版已量到的大型透明罩散焦成本；完整內容、實體裝置、耗電及商用驗收仍持續。

1. 在相同生物、畫質、光圈、解析度及前景條件下減少散焦 GPU 工作，不降低透明訊號、模糊品質、物件數或自動畫質設定。
2. 保留 focused shader、不透明 framebuffer、原生物身分、模型、移動、LOD 及每個模糊樣本的前景遮擋；不新增貼圖、全畫面 pass 或逐幀幾何。
3. 先保留基準來源、原始計時及像素。以相同原生 Chrome 配置，序列量測整個 Renderer.render，保留全部有效與無效樣本和正負結果。正常對焦為控制組；大型散焦、普通近拍、雙個體及 LOD 為負載組。只採用有明確改善且沒有可重現退步的候選，不能拿理論取樣數當實測。
4. 畫面以既有獨立歷史光學測試、完整 focused/off RGBA、基準受控 on RGBA 及遮擋／LOD／邊界回歸驗證。首選逐像素等價的純計算優化；任何不等價結果需解釋並依既有門檻及實際 PNG 判斷，不放寬門檻。
5. 正常攝影、沖印／保存、桌機及觸控自動畫質仍可用。完整 CPU、靜態檢查、獨立 Standards 與 Spec 審查後直接發布，核對精確 Pages 提交、公開 manifest 及實際入海。

狀態：本機實作與驗證通過。104 組場景設定與 960 幀 sweep 逐像素等價，兩端正常流程各 31／31、CPU 104／104、靜態 68／68；受控大型散焦 GPU 成本下降，細節及限制見 [報告](../TEST_REPORT-v01829.md)。公開交付待確認；實體手機、耗電及完整商用驗收仍未完成。
