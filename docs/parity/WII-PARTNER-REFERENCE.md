## 三個名額與替換流程

本節均是 **S1 第一代攻略的線索**，不是 M 或 J04 公布的容量規則。

| 階段／問題 | 正文所述語義 | 證據 |
|---|---|:---:|
| 初始夥伴 | 救援迷路的瓶鼻海豚，回船並取得海笛 | ★☆☆ |
| 其他候選 | 不同日接觸，達到第二層說明後回船觸發；拒絕後可再次接觸觸發 | ★☆☆ |
| 保有 | 同時最多三頭；文句另說不能只收同類，但尚無選單證明是否排除所有重複組合 | ★☆☆ |
| 第四頭到來 | 選一位既有夥伴告別，才加入新夥伴 | ★☆☆ |
| 告別後再交好同種 | 原個體不能召回；新個體重新命名、重新訓練 | ★☆☆ |

「可再交好同種」不等於「召回原個體及其訓練」。本專案若保留告別紀錄，應區分歷史紀錄與在隊成員，不能僅把顯示名稱當個體身分。舊存檔的原創夥伴進度如何遷移屬本作產品設計，不能拿未驗證的原作規則直接刪除玩家進度。
