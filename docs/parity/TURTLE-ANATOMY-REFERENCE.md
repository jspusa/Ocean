# 海龜外形修正：來源、實際缺陷與驗證範圍

查閱日期：2026-10-29。這次修改既有 `turtleGeometry` 與 `distantTurtle`；物種 ID、個體 ID、尺度、路線、存檔與材質編號維持原有契約。模型仍是原創簡化造型，沒有以掃描或實測資料重建個體。

## 生物學參考與原創資產

[NOAA Fisheries：Green Turtle，Appearance](https://www.fisheries.noaa.gov/species/green-turtle) 記載綠蠵龜的頭部相對小，背甲呈深褐、灰或橄欖色，腹側則明顯較淺、偏黃白；背甲中央有五片盾片、兩側各四片。這些事實支持保留小頭、深色背甲與外露淺色腹甲。既有盾片貼圖繼續使用，這次沒有下載或發布來源照片。

曲面輪廓、腹甲厚度、鰭根位置、取樣密度及動作幅度是本作的美術與效能設定，不是 NOAA 提供的幾何數據。這次不宣稱已完成種級形態鑑定、真實個體尺度校正，或達成商用寫實品質驗收。

星號表示已驗證的結構項目：★ 是一項；不是整體畫質評分。

| 項目 | 修改前的實際觀察 | 修改後的幾何驗證 |
| --- | --- | --- |
| 腹甲外露 ★ | 從下方射向身體的光線先碰到深色背甲；例如 x=-0.5、z=-0.2，第一個交點 y=-0.2895，tag 1 | 九個腹側取樣的第一交點均是淺色 tag 3，上方則是背甲 tag 1 |
| 身體接合 ★ | 完整背甲橢球包住另一個腹甲橢球 | 上下曲面共用同一圈邊界；整個殼只有一個連通分量，每條邊有兩個面，接合處法線連續 |
| 頭頸接合 ★ | 圓管與球體形成兩個互相穿入的皮膚零件 | 同一條連續曲面從殼內延伸至頭部，保留原眼部與喙部材質路由 |
| 鰭尖及鰭根 ★ | 前鰭尖留下 18 條開口邊；前鰭根 x=0.65、y=-0.045、z=-0.51 位於殼外 | 四個鰭尖封閉；完整鰭根截面位於身體內部，近、遠模型皆成立 |

鰭根仍使用 `|z|=0.51/0.48`，軟組織仍使用 tag 2；沒有新增會誤走眼部材質的標籤。背甲 tag 1、腹甲／喙 tag 3、眼部細節 tag 4、材質 5 均維持不變。動作與變形法線由正式頂點著色器的獨立測試驗證。

| 細節層 | 原有預算 | 本次實測 | 預算驗證 |

`node tests/parity/turtle-anatomy.cjs` 通過 16 項檢查。輪廓檢查使用實際三角形透視投影，設定取自既有 14 公尺切換距離、最大成人個體比例 1.12、69 度垂直視野與 1080 像素畫面；比較側面、前面、斜上、上方與斜下視角。容許差異為一個畫面像素，不以提高任意相似度分數取代輪廓要求。其他檢查包含有限數值、單位法線、無退化三角形、殼體拓撲、腹側可見性、頭頸連通及鰭根遮蔽。

## 尚需正式場景驗收

CPU 曲面檢查只能確認上述幾何條件。發布前仍需原生 WebGL 正式場景的斜側、正前及腹側畫面，確認呼吸／划鰭過程中殼體固定、鰭根沒有裂口、頭頸與喙沒有可見穿插；需在 14 公尺前後游動檢查輪廓切換，並保留桌機與觸控自動畫質驗證。既有 `guide_turtle.jpg` 也需依最終模型重新產生或明示仍是舊版，不能拿舊圖代表本次修改。

這份紀錄沒有宣稱已完成上述原生畫面驗收。材質反光、肌膚紋理的投影方向、全場景效能與其他生物造型屬於不同驗證範圍。
