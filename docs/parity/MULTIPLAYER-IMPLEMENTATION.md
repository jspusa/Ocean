固定盤點基準 `0cc9cc99893abe0063cd717492e41c308964a949`。承接工作單 11、總規格 §28–32 與官方研究中的好友、邀請、准入、共同工具、位置及斷線保存。下列分階段是相互依賴的實作順序，不是縮小完成定義。只有真正公開雙端與外網驗收完成，才可關閉工作單。

## 玩家結果

1. 兩名玩家可從既有網站可見入口建立或加入共同海域，彼此看見真正移動、方向、深度、外觀和工具效果；不以 NPC、錄影或同源 BroadcastChannel 代替跨網連線。
2. 每人有持久身分與最多 42 位好友；好友加入、移除、邀請、接受及拒絕可重開管理。公開聯絡識別不等於登入憑證。
3. 主持者可開關訪問、核准或拒絕加入；未核准者、第三人、失效邀請或版本不合者不得取得房內狀態。
4. 共同海域採相同內容版本與共同時鐘／時段；相同 UID 生物和受互動影響的反應保持一致。選單／失焦不會使另一端看到無限外推或被假裝連線。
5. 共用工具包括真實筆跡與擦除，以及既有餵食、觸碰、抓握、夥伴等適用互動的共同可見效果。權限、操作序號與重連快照有明確規則；不能只同步食物粒子。
6. 分類預設訊息由合法成員傳到另一端，顯示正確發送者；不新增自由聊天或傳送私人照片／完整存檔。
7. 地圖、畫面內／外同伴提示與暫停狀態可理解。個人故事、圖鑑、照片、收藏、角色和探圖始終由自己的正式 owner 保存。
8. 正常離開、主持者離開、斷網、重連與重開有清楚結果；過期資料停止外推，斷線不抹去個人成果、不偽造返程／完成委託。
9. 桌機、手機、自動畫質與現有單寫存檔保護保留。未加入時不開連線、不持續上傳位置、不增加全場景掃描或遠端模型；加入後物件、封包、佇列和頻率有上限。

## 架構決策

保留 GitHub Pages 遊戲入口，房間服務獨立。以自有 WebSocket 服務為傳輸，一個房間單一權威、最多兩名已核准成員。推薦部署為 Cloudflare Worker＋每房間一個 Durable Object，身分／社交資料與即時房間狀態分開；同時保持房間協定可用真實本機 WebSocket server 驗證。公共 demo relay、單一 Worker isolate 的不可靠 global map、只有 STUN 的 WebRTC 都不作正式替代。

共用協定驗證版本、房間世代、有限數值、合法工具、UID、訊息類別、長度及容量。姿態快照可覆蓋舊快照；可靠操作必須有序、去重且能從快照重建。心跳／收件與斷線生命週期獨立於會暫停的遊戲 RAF。外部資料一律不得直接覆寫個人 voyage、照片或 runtime player。

伺服器准入與可重連憑證使用不可猜測能力值；長期身分憑證與可匯出的遊戲存檔分離。不將私人憑證、邀請密鑰或雲端 token 放入 Git、公開 manifest、URL log 或測試輸出。房間工具權限及連線世代由伺服器執行，不能信任客戶端自稱主持者。

## 測試與完成邊界

以可見遊戲操作及真正 HTTP／WebSocket 公開介面驗證，CPU adapter 只補足時間、故障與惡意輸入；測試不直接修改房間內部儲存來獲得資格。每一階段逐個外部行為 RED→GREEN，不以一次建立所有假定測試代替連續實作。

本機兩個獨立 WebSocket 或瀏覽器可證明跨客戶端傳輸，不能證明外網、跨網路、實體手機或完整多人遊戲。保留 origin 的既有單寫鎖，以獨立瀏覽器資料區／裝置驗證不同玩家。

目前部署盤點：GitHub Pages 已可用；本環境未有可驗證的 Cloudflare 登入／部署權限或既有其他後端。已向使用者詢問後端選擇，等待資訊期間可繼續本機服務與遊戲實作。這是公開部署的依賴，不是把多人排除的理由。新增服務費用或帳號登入不得假設已完成。

官方架構依據：Cloudflare [WebSocket 與 Durable Objects](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)、[方案與限制](https://developers.cloudflare.com/durable-objects/platform/pricing/)。方案可用性及費用在正式部署時再次查核。
