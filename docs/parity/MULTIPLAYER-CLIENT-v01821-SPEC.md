# 0.18.21 雙人同游客戶端

基線 `2f4cc278c4cc17b413f5c139798dea5f0621263a`。本輪實作完整多人計畫的 Stage C；不關閉工作單 11，也不縮減 SPEC 28–33。

## 可驗收行為

1. 同一正式遊戲介面中，兩個獨立瀏覽器 context 能經真實 HTTP／WebSocket 建房、輸入房號申請、由房主批准或拒絕。未批准時沒有房內姿態。房主能關閉訪問；兩席上限由現有伺服器執行。
2. 核准後，下水可看見對方的真實位置、方向及基本潛水員模型，地圖與不擋中央視線的方位提示顯示距離、深度及暫停／離線狀態。只插值最近兩筆姿態，不無限外推。普通移動每秒最多 10 筆，背景／暫停不持續送相同姿態。
3. 分類預設訊息顯示正確發送者；不提供自由聊天。選用工具只顯示狀態，不聲稱同步工具效果、外觀配件、生物、日夜或個人任務。
4. 確認 joined 不依賴 RAF。連線意圖、世代、順序、首次准入回覆遺失及重連回覆遺失按既有協定處理；重試有界，不重複建房。明確離開／取消、房主結束、重載、重設或匯入存檔會清除遠端狀態，個人進度不被改寫。短暫失聯顯示重連中；過期清楚停止。
5. 憑證只存在當次頁面的記憶體，不進入 URL、儲存空間、存檔匯出、錯誤輸出或 snapshot。伺服器重啟／頁面重載不宣稱可恢復房間。連線前及離開後不建立 socket、不分配遠端渲染資源、不留下送姿態計時器。
6. 端點是部署設定，不是一般玩家輸入。未設定公網服務時，公開版如實顯示尚未開放，不嘗試任何連線。開發版 loopback 可使用同主機 8787 的現有服務；非 loopback 只允許 WSS。不得默用公共第三方中繼。
7. 既有桌機／觸控自動畫質、主動生物點選與單一存檔寫入者保留。手機驗證先明示為同機觸控模擬。

## 既定測試邊界

沿用完整多人計畫已約定的真 HTTP／WS 及可見遊戲 UI 邊界，採逐切片 RED→GREEN。transport 測試使用實際 TCP 及正式 room server；正常瀏覽器驗證使用兩個獨立 context、正式 UI、原生鍵盤／觸控移動，不以內部房間或 pose 注入代替遊玩。渲染需原生 WebGL 截圖、移動與地圖讀回，GPU 效能不由功能測試推算。
