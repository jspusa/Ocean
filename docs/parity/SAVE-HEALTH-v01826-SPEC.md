# 0.18.26 保存失敗與航程讀取保護

基準 d364ac076f65d4b2aa2e2be2d0b2f426ea54ff9e。沿用完整 SPEC、01-save-and-lifecycle 工作單及已確認的正式 Storage / IndexedDB 與玩家 UI 測試界面；此修正不代表整體商用完成。

## 可觀察契約

- 航程主檔與備份均不存在才建立新航程；任何存在但不可讀、版本不相容或讀取被拒，且無有效備份時，禁止自動保存空航程。舊 bytes 保留；只有成功載入或明確匯入有效備份才能重新允許寫入。
- 未讀取成功時顯示不可取消的恢復畫面，禁止入海；保留目前分頁使用權，以既有完整匯入交易恢復。照片初始化不得遷移資料。原始 localStorage 下載逐 key 保留 raw/error/missing 狀態，明示不含照片原圖，使用獨立格式，不能冒充完整可匯入備份。
- 正常完整匯出拒絕尚未安全讀取的預設航程／日誌。成功匯入提交後才清除讀取錯誤，回滾保留之前的狀態。
- 安全載入後的新進度保存失敗，首頁、水下與面板均有持續可見狀態，分列航程與圖鑑／設定。可重試本頁保存或匯出含原圖的完整備份；不得重新載入而丟失未保存成果。成功 primary 寫入後清除對應錯誤。
- 原圖在 IndexedDB 提交成功但航程或日誌保存失敗時，攝影／沖印提示明確並存；不把原圖成功當成所有進度成功，也不把已保存的原圖標成遺失。
- 不新增每幀儲存／檢查、GPU 工作或背景輪詢。維持自動畫質、自由探索與明確指標選魚。

## 驗證

先以正式 load/save + browser Storage 故障邊界重現覆寫，再逐段 RED→GREEN。涵蓋新玩家、雙損壞、雙不相容、read failure、有效 backup、primary write failure、照片真實提交／重試／重新開啟、正常與失敗匯入。桌機與觸控尺寸依序執行實際瀏覽器 UI，實體手機不在本機模擬證據內。依 AskMatt 進行 Standards / Spec 獨立審查，發布後另驗 Pages commit、公開雜湊及可玩性。
