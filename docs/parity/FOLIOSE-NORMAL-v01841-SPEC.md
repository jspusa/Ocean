# Foliose corner-normal correction

This is a bounded correction within the ongoing realism/contact/ecology/automatic-quality goal. The deployed baseline is v0.18.40, commit `cb665a19bbcf562161e4736640c7c60ae25af63f`. The earlier audio-entry milestone remains separate. This increment does not accept the unfinished coral art direction.

The actual source and compiled foliose meshes contain outward-facing triangles with an individual smooth corner normal pointing into the opposite face hemisphere. The existing mean-normal check misses them. `qa/parity/v01841-tissue/normal-red.json` records six failing foliose models, while actual source/archive vertex and index equality and all existing geometry checks pass. A real-triangle control with only one reversed corner proves the stronger oracle rejects a defect that its mean still hides.

For each emitted foliose triangle, retain each authored smooth normal only when it lies safely in the triangle's forward hemisphere; otherwise use that triangle's normalized geometric normal at that corner. Preserve all positions, colours, UVs, tags, triangle winding/counts, RNG, actor identities, poses, LOD ranges, shaders and quality settings. Do not flatten unaffected corners or brighten global lighting. This correction may change vertex deduplication and must be audited in the compiled archive.

Acceptance requires source geometry checks, exact expanded-triangle equality for every non-normal attribute, actual compiled equality after rebuilding, unchanged full-world poses/contact catalogue, and native full-world captures of both real foliose actors. Existing root/crown evidence can be carried only with exact positional equality; any positional difference requires renewed contact checks. Read back candidate GPU geometry and retain unchanged production shaders and camera settings. Native capture is not proof of physical-phone frame rate or battery consumption. Public publication requires independent Standards and Spec reviews, Pages commit verification, published-file hashes and normal desktop/touch entry.

The isolated A/B shape experiments remain under QA. Both pass CPU topology checks but have not earned visual or full-world contact acceptance. Neither is part of this correction. The larger realism objective remains active, including visible thin-plate/handle shapes, convincing attached bases, animal anatomy and distribution, and actual device performance.
