# 小飛象章魚：屬級原創模型與使用界線

核讀日期：2026-10-27。對象為 **Grimpoteuthis sp.**，不指定未確認的種名。這是新增的原創深海內容，不是 Wii 圖鑑中已確認的逐項替代，也不抵銷完整內容盤點缺口。

## 模型與 rig 契約

物種 ID 為 `dumbo_octopus`，登錄透過既有 `registerFauna`，另用自己的 collection，既有 44 個索引與淺礁族群不改。`renderKind: 11`、`motionProfile.type: dumbo_octopus`；完整應用程式由主整合依序追加三腳魚及本種類。獨立模型測試只在既有 44 類後載入小飛象章魚，不代表正式版本總數為 45。

- **尺度**：本作代表個體在靜止造型下，外套頂至腕冠末端的高度為 **0.20 m**；`size: .20`、`measureAxis: 1`、`modelUnitLength: 1`。不是單獨外套長、完全伸展腕長、物種最大值或某已知種的精密測量。
- **座標**：+Y 外套頂，八腕向 -Y 及四周展開，+X 面向，耳狀鰭在 ±Z。主軸高度為 `[-.5,.5]` model unit。
- **tag 1**：閉合外套與寬頭部。下端延伸到 `y=-.14`；在腕蹼根圈 `y=-.06,r=.17` 保持實際重疊，避免懸空腕冠。
- **tag 3**：兩片獨立、封閉的耳狀鰭。左右根為 `[-.018,.16,±.17]`，外端為 `[.027,.24,±.56]`；未傾斜截面中段弦寬約 `.26`，靜止鰭弦採約 0.6 rad 的前緣上抬原創姿態，讓正面可讀鰭面；不是生物學量測角度。左右、根部、末端與總包圍盒維持一致。rig 應在根部保持零位移，逐漸增加遠端擺幅，同步變換法線。
- **tag 5**：八腕、內外兩面的連續腕蹼、單排凹形吸盤及吸盤兩側的細 cirri。根在 `y=-.06`，末端 `y=-.5`；腕蹼使用同一條腕弧線作支撐，到各腕約 84% 處結束，腕間凹緣較短。全部必須使用一致的柔動變形與法線，不能讓吸盤、cirri 或蹼與手臂分離。
- **tag 4**：兩側前方的暗色眼睛，位於約 `[.15,-.005,±.15]`；沒有自發光器官、吸血烏賊的細攝食絲或透明頭罩。

固定造型 raw bounds 為 `min [-.42404013195022383,-.5,-.56]`、`max [.42404013195022383,.5,.56]`；乘 `.20` 後的包圍盒為 X 約 ±0.08481 m、Y ±0.10 m、Z ±0.112 m。這是靜態 CPU 幾何界線，不是包含 shader、actor 旋轉與游動的最終碰撞保證；主整合仍須驗證動畫全週期與真實底面間距。接觸距離 `.6 m`、觀察距離 `6 m`、近看距離 `.9 m`、挑選半徑 `.12 m` 皆為遊戲操作設定。

## 已完成的 CPU 證據與未完成範圍

在公開 catalogue → `faunaGeometry` seam，登錄缺失、模型缺失、口腕細節缺失及腕冠連接缺口各先出現失敗，再完成對應行為；未一次預寫全部功能測試。目前 `node tests/parity/dumbo-octopus.cjs` 為 9／9：包含柔軟腕冠、圓頂與跨級皮膚色彩連續性的實際幾何檢查，並保留既有索引、兩級輪廓、八腕間蹼、單排吸盤與兩側 cirri、暗色眼睛、真實外套接合、有限值／單位法線／朝外繞序／索引後非退化及有界幾何。

本檔不證明 shader rig、世界生成／棲地、安全間距、正常玩家到達、主動選取、拍照原 JPEG、保存、水族館或公開交付已完成；這些由主整合另外取證。實體手機、耗電與全程畫面穩定性也不由此 CPU 模型測試證明。


## 0.18.35 柔軟腕冠的幾何修正

本輪重新核讀上列 OET 與 Smithsonian 頁面。OET 描述相遇時外形變化，Smithsonian 說明腕蹼參與脈動游動；兩者支持柔軟可變形的腕冠，但沒有提供本作曲線、褶深或節律的測量值。未下載或移植其照片、影片與模型。

既有模型的腕冠在同一高度幾乎為等半徑環面，八根腕均向外直展，遊玩照片看起來像繃緊的裙襬。現在八腕中段形成圓弧、自由末端稍向內回捲，腕間表面在支撐之間有柔和凹褶。腕蹼、腕管、吸盤與 cirri 共用同一條手臂曲線；吸盤與 cirri 的座面方向由該曲線的切向求得。凹褶在每條腕與外套連接處歸零，沿用既有雙面腕蹼、tag 5 與正式動畫。這是原創放鬆姿態，不是精確生物力學模型。

新增測試直接對 `faunaGeometry` 的兩級 drawable mesh 作射線交點查詢，比較同高度膜面相對腕肩的內縮，並檢查八腕中段較自由末端外凸。原模型先失敗（首腕中段－末端為 −0.01036 model unit，同高度凹褶約 −0.0004／−0.00148，只有網格近似誤差）；修正後七項幾何檢查通過。原有 20 cm 靜止全高、兩耳、八腕、單排吸盤、成對 cirri、外套連接、有限數值、朝外法線與模型預算斷言全部保留。高／低三角形與索引 bytes 仍為 8,688／2,288、470,208，沒有增加繪製 pass。

本輪 RED／GREEN 日誌位於 `qa/parity/v01835-realism/dumbo-soft-crown-red.log` 與 `dumbo-soft-crown-green.log`。正常棲地圖片、動態完整包圍、GPU 成本及公開交付須由主整合另外驗證；本段不以 CPU 結果宣稱已完成畫面驗收。


## 0.18.35 外套圓頂與寬幅組織色彩

外套最後一段原本讓半徑近似線性收斂，實際高階頂部兩環相對頂點的斜率完全相同；即使頂點法線朝上，輪廓仍形成尖錐。現在只在 `y=.42` 至 `.5` 的帽頂改用平方半徑的 Hermite 插值，保留頂點、接合半徑與接合的一階導數；`y≤.42` 的外套剖面完全沿用原值。沒有加寬身體或增減網格。

皮膚保留既有主色與材質，去除會隨網格級別取樣不同的高頻頂點斑點。現在是往口腕側逐漸變淡、鰭根略帶玫瑰色過渡的寬幅原創色場；它不是烘焙陰影、血管、實測色素圖或新增透明效果。眼球與眼眶的幾何、顏色和 tag 本輪保持原狀，須交由原生照片決定後續觀感；未藉放大眼睛增加可讀性。
