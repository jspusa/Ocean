## 玩家結果

1. 切到別的分頁／應用程式，再回到遊戲，離開期間不加入效能量測，也不因該段時間誤降自動畫質。必須涵蓋瀏覽器在離開後完全不執行 RAF 的情況。仍在前景的真正長幀照常記錄；不能以截斷幀時間掩蓋卡頓。
2. 首頁提供一個次要的「調查與委託」入口，探索選單首層也可進入。保留自由入海為主操作，不新增常駐中央任務卡或魚名，不重新要求故事模式、移船解鎖或耗氣限制。
3. 調查與委託頁直接呈現現有故事及郵件的實際進度和下一步。未接、進行中、待回報及已完成必須可區分；由正式狀態推導，不新增一份可能不同步的完成旗標。玩家可以打開相符調查冊或信件，標記正式目標；不自動改寫玩家目的地或瞬移。
4. 自由探索下，接下的《回聲潮譜》顯示正確章節／步驟，完成現地記錄後引導回首頁整理，回報後顯示下一章。正常保存、重新載入、匯入及既有委託資料保持相容。舊六章與其他工具仍可使用。
5. 實際桌機與觸控尺寸，經可見入口接下首章、連續游入洞窟、記錄兩處目標、回首頁回報，再重新載入，保持真實進度與自動畫質。現地時間由正式 RAF 推進；不指派玩家座標、模擬時鐘或進度。另驗證取消記錄、錯誤距離／遮擋及不可水下回報的既有規則。
6. 原生瀏覽器的背景／恢復驗證使用真實頁面生命週期與渲染；UI 檢查涵蓋首頁及對話框、觸控直橫向、安全區、鍵盤焦點與不擋主要控制。觸控尺寸仍不等於實體手機。
