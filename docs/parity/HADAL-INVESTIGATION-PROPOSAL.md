## 玩家結果與完整敘事

玩家從「調查與委託」自行接下《海圖上的折痕》。澄請玩家補記海溝底站旁尚未納入調查冊的凹槽：同樣寫著七千公尺的海圖，沒有呈現泥台後方的真實落差。玩家設置一台基準儀，沿現有坡面完成短剖面，再返回泥台記錄獅子魚、回收器材，最後在首頁回報。結案頁呈現玩家完成的剖面、相遇記錄與澄的解讀。

這是一段原創地形調查，不將凹槽成因、形成年代、聲音來源或生物與地形的因果關係編造成科學結論。高差來自本作現有網格；記錄時間和操作距離是遊戲設計值，須在實作規格中另行列明。

## 已核對的地形候選與路線

候選坐標採本作公尺尺度，不是真實海域坐標。使用基準實際 `OceanTrench.floorAt`／`groundHeight` 與 `OceanRegions.pathClear` 做唯讀 CPU 查詢，沒有更改地形、指派玩家位置或執行 GPU。

- 海溝底站：`[766, -7000, -120]`。
- 基準儀候選地面：`[781.4, -7002.5, -134]`。以 x／z 各 `−0.3, 0, +0.3 m` 的九點查詢，支腳區高差為 `0`。
- 溝底候選地面：`[780, -7020.541031781157, -145]`。
- 兩點世界 Y 高差：`18.041031781156562 m`。結案可顯示適當精度的約18.0 m，不能把小數位當成真實測量精度。
- 基準位置至兩個既有獅子魚 home 的水平距離約 `6.720 m`、`1.887 m`；實作時仍須驗證完整動物活動包絡與器材不相交，不能只檢查 home。

定義 `H(x,z) = OceanTrench.floorAt(x,z,-6990)`。已核對的觀察站位路徑為：

```text
[766, -7000, -120]
[779, -7000, -134]
[781.4, H(781.4,-134)+2, -134]
[780, H(780,z)+2, z]，依序 z = -135,-136,-137,-138,-139,-140,-141,-142,-143,-144,-145
```

共14點／13段。各段 `OceanRegions.pathClear(a,b,.4)` 為 true；每段含兩端的33個等距位置，皆滿足 `p.y >= OceanTrench.groundHeight(p.x,p.z)+.82`。這是候選路線的 CPU 淨空證據，尚不是完整角色、器材、鏡頭或實際游動驗收。

**已確認的陷阱：上緣直接連到溝底的直線會穿地。** 必須沿共享地形的坡面折點下探，保持轉折；不得用兩個端點線性插值冒充可通行路線。任務可以只標出當前測點，讓玩家自行游動；若實作短距離引導，必須使用上述實際通行判定。既有前往底站的海流導航保持 [trench.js L128–153](https://github.com/jspusa/Ocean/blob/3b7037e58ac7c11bccd50c44a8763fc9dd8c3cbb/src/trench.js#L128-L153) 的正式路線。

正式測點的讀取面、站位、半徑及中間轉折 ID 尚須於實作規格固定；以上是可落地候選，不宣稱已存在的互動物件。記錄必須要求玩家到達各測點、停穩、保持視線及完成明確操作；自動導覽、單純深度門檻或遠距按鈕不得直接授予記錄。

## 舊存檔與失敗狀態

- 舊六章 `reports`、`step`、`sensors` 與完成結案語義保持不變；不得直接延長舊 `StoryRules.chapters`，使已完成的六章自動變成第七章進行中。
- 舊存檔缺少新調查欄位時，初始化為未接下。六章任一中途／已完成存檔都能獨立接新調查，既有郵件、裝備、照片與深海站點訪問資料不受影響。
- 新調查只接受已知 ID、有界記錄、有限數值與有效順序；禁止將任意匯入坐標當成場景生成位置。測點相依關係、器材部署／回收與報告資格由同一規則正規化。
- 保存的是已完成現地結果；進行中的停留計時、暫時選取或鏡頭狀態不冒充已完成證據。重載後從相同下一步繼續，未完成的連續記錄重新開始。
- 每個完成操作走既有正式保存管線。部署後回首頁、關閉、重開或匯入，仍重建同一基準儀；未回收不能結案。回收後不因重載又生出器材；回報一次後只可重讀。
- 地圖／摘要／冊頁只讀取狀態。UI 開啟、導航抵達、故事字幕播放、背景時間與下載等待均不能授予進度。
- 不以本機 JSON 可編輯性宣稱防作弊；正規化的目的為維持一致且可恢復的遊戲狀態。

## 生物與科學邊界

現有模型配置為700 m吸血烏賊（代表個體0.28 m）、1,400 m海豬（0.14 m）及約7,002 m馬里亞納獅子魚（0.20 m），見 [trench_fauna.js L58–69](https://github.com/jspusa/Ocean/blob/3b7037e58ac7c11bccd50c44a8763fc9dd8c3cbb/src/trench_fauna.js#L58-L69) 與 [trench_world.js L6–16](https://github.com/jspusa/Ocean/blob/3b7037e58ac7c11bccd50c44a8763fc9dd8c3cbb/src/trench_world.js#L6-L16)。它們是原創遊戲配置，不是現地觀測。

主來源在本次盤點核對：MBARI列吸血烏賊600–900 m、海豬1,000–6,000 m；馬里亞納獅子魚原始描述採集深度6,898–7,966 m，發表於2017年。因此本提案只在既有7,000 m位置使用獅子魚，不把前兩種搬到海溝底，也不把2017年命名的物種聲稱為2007年Wii精確復刻。[MBARI：Vampire squid](https://www.mbari.org/animal/vampire-squid/)、[MBARI：Sea pig](https://www.mbari.org/animal/sea-pig/)、[Gerringer et al. 2017原始描述](https://www.biotaxa.org/Zootaxa/article/view/zootaxa.4358.1.7)

現有 kind11 動畫沒有逐粒海洋雪捕獲、食物守恆或觸發式發光玩法；本提案不把圖鑑文字當成已存在的模擬。地形與壓迫感來自真實路徑、既有照明與剖面空間；不新造無科學來源的生物能力或地質結論。
