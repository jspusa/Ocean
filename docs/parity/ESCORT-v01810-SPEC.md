# 0.18.10 帶路客人與連續探索

基準 `bbfb7efecb35ceb754aa4adbbfa772fab64a3799`（已公開驗證的 0.18.9）。依完整規格第 19、31、32 條與 [信箱／訪客工作單](issues/04-mail-camera-dive.md)，修正現行自由探索與舊客人移動規則不一致的問題；完整功能、內容與實體裝置要求保持不變。

## 已重現的問題

客人固定以 2.3 m/s 跟隨，現行玩家淺水普通速度約為 5.9455 m/s；受控無障礙直游 30 秒後，客人距離超過 110 m，已超過可繪製距離。共同觀察要求相距小於 12 m，所以正常游動會令原本可接取的帶路委託無法自然進行。客人存檔仍使用舊海域邊界，合法深海位置 `[760,-7000,0]` 在讀取後變成 `[270,-120,0]`。

獨立審查也須涵蓋已被舊版存成地下座標的資料：這類無效起點在讀取／續玩時使用正式碰撞修復一次，並移除不再適用的路徑；合法位置與轉彎路徑精確保留。未完成委託回首頁後仍保存實際客人，再續玩不能重新生成到玩家旁邊；取消或已可領獎的客人則結束同行。

## 必須成立的玩家行為

1. 從目前可見的選單接下帶路委託，正常游動、加速與深海助游時，客人以連續移動跟隨實際路徑；停下時回到合理同行距離。不能瞬移客人、人工重設其位置，或降低玩家原有速度來掩蓋掉隊。
2. 轉彎與岩壁使用實際碰撞，不能只追一條會穿牆的直線。保存必要的有界路徑，不讓每幀工作或存檔隨旅途長度無限增加。舊存檔沒有新路徑時仍能正常讀取。
3. 客人在全海域的合法位置、委託進度及續玩保持一致；無效／非有限／越界資料安全正規化。已完成委託、投稿附件與既有 ID 不變。
4. 暫停、看照片、失焦、回首頁、重開與取消委託不留下持續移動或過時路徑。落隊時在既有介面提供簡短距離／等候回饋，不遮住中央觀景。
5. 帶路完成仍需要玩家抵達目的地、真實客人接近，以及共同觀察正確生物；跟隨改善不能直接給予進度或完成旗標。
6. 電腦／觸控自動畫質、正常模擬頻率、地形與生物內容保持。以真實 RAF 連續探索補充長時間證據，不以加速時間、固定相機或 CPU fixture 宣稱實機遊玩。

## 驗證界面與證據界線

沿用既有預先確認的正式功能生命週期、存檔正規化、實際瀏覽器操作與原生 WebGL 界面。先保留舊版掉隊與深海讀取 RED，再逐片驗證正常／加速跟隨、轉彎碰撞、暫停恢復、全海域保存及任務條件。原生流程從可見入口接取，使用實際游動與互動，不把客人直接放回玩家旁邊來取得成功。

另外執行 20 分鐘原生 Chrome／本機硬體 GPU 的公開站連續探索：以真實選單前往各深度、保留自動畫質，記錄完整幀間隔、CPU 時間、解析度、實際位置、路線完成與記憶體樣本。量測期間不跑其他 GPU 測試；開發期間的背景 CPU 工作不據此推算峰值性能。此為自動化原生瀏覽器負載證據，不是人眼品質、輸入延遲、溫度、瓦數或實體手機驗收。

Standards 與 Spec 獨立審查後提交並更新公開版。不得因本輪通過而關閉完整工作單或整體商用目標。

## 實測後追加：深海渲染瓶頸

公開基準的 20 分鐘真實探索平均只有 10.32 FPS。隨後同一原生 GPU、同解析度 1843×1152、品質 2／4× MSAA／scale .64 的短診斷，礁區整幀 GPU 約 21 ms，深海泥底站約 357 ms；深海 CPU P95 2.3 ms，靜態陰影更新 0 次。這支持優先調查 GPU 著色工作，不能把問題歸為串流或物理 CPU。

本輪追加有限的深海岩壁／泥層程式特化（kind 0、material 16／17），沿用既有 surfaceShaderSource 界面，只在 fragment shader 把 uKind／uMat 兩個 uniform 換成常數，讓編譯器剔除無關分支。新兩種程式保留原始 vertex shader，避免不同頂點編譯帶來的深海位置／插值捨入差異；既有四種程式不變。不得改動原始著色算式、材質細節、光照、解析度、MSAA、LOD、動物或模擬頻率；不以降畫質作為此修正。程式只預編譯一次，單一特化失敗時保留原始可用程式，不在逐幀渲染中反覆編譯。

必須以同一 WebGL context、固定相機／時間的 ABBA 整幀 GPU timer 與完整 RGBA 比較確認收益及畫面一致；可接受既有測試的至多 1/255 編譯捨入、少於 0.01% 通道差異。另外重跑真實 UI 深海抵達的短診斷，區分受控固定畫面與自然移動證據。兩軸審查也須涵蓋此追加範圍。若測量不支持收益，不能僅因 CPU 測試通過而宣稱深海效能已改善。

## 最終回歸補充

首頁圖鑑觀察只能標記棲地，不能改動角色位置、續玩資料、auto／follow 或啟動深海導覽；水中近距正式觀察保持。觸控橫向提示不得蓋住浮潛、搖桿、拍照或加速控制，版面須按實際左右安全區保留操作空間；CDP安全區與長提示fixture只屬版面驗證。
