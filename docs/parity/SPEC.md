# Wii 第一代功能對等：持續目標規格

## 問題與目標

使用者要讓現有網頁海洋遊戲具備 Wii 第一代 Endless Ocean / FOREVER BLUE 的 feature parity，並保留原本更精緻的畫面、電腦與手機、自動畫質需求。0.8 的光影升級不是功能對等。此規格不以任何單輪已實作內容重新定義完成。

以 [查證基準](../WII-PARITY-REFERENCE.md) 所列官方說明書／功能卡為起點。功能流程、內容覆蓋與跨系統保存需分別驗證；物種等原作總量未知時維持未知並繼續查證。素材、音樂、故事與地理使用原創或適用授權，功能語義與完整範圍仍保留。既有六段航程是前導章節，不能替代完整故事深度。

## 玩家故事與驗收範圍

1. 玩家能游動、停止、迅速轉身、上下浮潛、自動前進並接手，切換第一／第三人稱及水面環視。
2. 玩家能在桌機、觸控與標準手把完成所有必要操作；工具不留下卡住的輸入。
3. 玩家能讀取深度、羅盤、船方位與潛區警示，船的停泊位置實際影響下潛範圍。
4. 玩家能消耗一瓶氣量並在耗盡時溫和回船，保留探索成果；自由模式可額外無限探索。
5. 玩家能揭開未探索海圖、回看本次航跡、縮放地圖及選擇目的地。
6. 玩家能進入近距／微觀探索，依聲音提示找到小型生物與藏匿物件。
7. 玩家能聚焦、撫摸、點觸及抓握適用生物；動作各有不同且可見的結果。
8. 玩家能投放食物、看到適用生物靠近，再退出餵食。
9. 玩家能藉相遇和互動逐步理解生物，圖鑑資料及水族館資格與熟悉度一致。
10. 玩家能自由使用水中畫筆，筆跡存在海中，支援原作對應的互動／同遊用途。
11. 玩家能取得並選擇不同夥伴、呼叫伴游、持續抓握一起游動及放手。
12. 玩家能透過身體部位與動作下達訓練指令、排列連續特技、以強度控制 Go，看到實际動畫與高度／時間回饋。
13. 玩家能改變相機變焦、光圈與對焦，畫面成像實際變化；相片為當時引擎畫面。
14. 玩家能區分潛水拍攝暫存與回船沖印收藏，保留、刪除、重開相簿並選照片投稿。
15. 玩家能在研究船甲板移動、與船伴對話、看告示板、坐躺椅看海及使用船上互動點。
16. 玩家能進船艙選擇航行、換裝、沖印、相簿、時鐘、信箱、圖鑑、存檔。
17. 玩家能讓船移往已解鎖潛點，場景、海圖、範圍與出入位置保持一致。
18. 玩家能收到郵件、閱讀、接受或拒絕委託、執行、回覆及領取解鎖物；已領不重複。
19. 玩家能帶真正在海中跟隨的客人尋找指定物種／地點，依完成情況獲得回信。
20. 玩家能執行攝影投稿，以實際照片作附件，而非只送出分數或完成旗標。
21. 玩家能創建角色外觀、解鎖裝備、穿戴後看見效果並持久保存。
22. 玩家能找到物件、靠近拾取、回船收藏箱閱讀與重看；不能重複拾取相同實體。
23. 玩家能解鎖水族館，從符合熟悉條件的物種中選擇、配置、自動配置、移除或清空，進入觀賞並重載保存。
24. 玩家能調整時間到晨／昏，夜潛和深水頭燈生效，環境與生物內容隨時間有對應差異。
25. 玩家能遇到原作功能範圍的甲板動物訪客並互動。
26. 玩家能跟隨原創對話與線索探索淺礁／潟湖、洞窟、遺跡、深海、沉船及其他對等區域，解開故事進程。
27. 玩家能選擇自己的 MP3、控制音量、休憩觀景與退出閒置欣賞。
28. 兩個獨立玩家能建立／加入共同海域，看見彼此的移動和工具效果。
29. 玩家能管理好友／邀請與訪問准入，傳送分類預設訊息並看到朋友位置。
30. 玩家能正常離開／斷線恢復，自己的角色與探索進度不被另一玩家覆寫。
31. 玩家能保存及恢復全部新舊功能狀態、匯出／匯入，舊 0.8 存檔獲得合理初始值。
32. 玩家能在實際游動中看到穩定畫面與自然動作；桌機及手機自動畫質工作，功能不只在固定截圖或 fixture 中成立。
33. 玩家能體驗對等的可盤點生物、地點、任務、裝備、收藏與夥伴／特技內容；未知原作數量不能以任意替代數量驗收。

## 實作決策

沿用 WebGL2 及原創資產。擴充功能以小介面接入既有航程生命週期，進度放進既有存檔內的版本化功能分區。每區有初始值和輸入正規化，匯入只接受已知 ID、有限數值與有界陣列。功能 UI 共用船上入口及水下工具箱，不每加一個系統就堆出一排永久控制項。

場景幾何格式與應用程式版本分開；沒有變更原礁體幾何時繼續使用已驗證的 0.8 場景，新增互動物件以有界動態批次加入。未獲來源支持的參數（氣量分鐘、互動門檻等）標為本作設計值，不聲稱等同原作數值。

雙人需要真實跨客戶端傳輸及外網驗收，不能用錄影／NPC 代替。保持現有靜態網頁入口；選定連線架構時另記決策，不能因 Pages 是靜態空間就刪除此要求。

## 驗證決策

以實際瀏覽器端操作為主要驗收介面，行為狀態測試補足時間／失敗／惡意存檔界線。每個切片包含可操作 UI、遊戲內可见結果、保存重載與不破壞既有航程。對照依源文件逐項列證據；測試通過不自動等於全作對等。原本 0.8 桌機／觸控回歸仍須通過。

所有攝影／光圈／對焦、動畫、地圖、世界物件需要真實 WebGL 截圖或連續渲染證據。多人體驗須兩個獨立客戶端及外網連線。實體手機、完整真人遊玩及內容總量尚未驗證就繼續列未完成。

## 不複製的內容

任天堂的程式碼、專有素材、音樂和逐字故事不作複製目標；以原創内容實現功能。Wii 遙控器動作改成適合鍵鼠／觸控的等價操作。這些替代不刪除原作功能、內容深度或跨系統行為。
