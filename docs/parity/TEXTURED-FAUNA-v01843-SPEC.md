完整目標仍是更真實的生物、海水光影與岩層，可靠的玩家／魚類碰撞、合理且每次潛水有變化的區域生態、沒有漂浮珊瑚，以及電腦與手機自動畫質。本增量建立完整魚體素材的實際可玩路徑；不把新增一種魚當成整體完成或商用品質證明。程序小丑魚 C 與乾標本珊瑚的未接受候選不納入本版。

## 玩家可見的結果

- 近岸潟湖能遇到金目鱸 `barramundi`／*Lates calcarifer*，保留來源模型的完整頭、鰓、魚身、魚鱗與鰭條。使用已取得且授權允許改作／散布的 Khronos CC0 BarramundiFish；不冒稱本站原創雕模或實測掃描。原始 UV、索引與切線保持，公尺尺寸不再重複乘物種體長。
- 只追加一個固定邏輯個體 `barramundi-001`，其他物種索引與身份不重排。近岸位置與路線是遊戲作者配置，經真實地形與完整 rock catalogue 驗證；不放進深海，不套用小丑魚共生或密集群游行為。
- 同次與續潛依既有 seed 恢復相同路線；新潛可改變該魚的有界路線／相位，沿用現有生態機制，不逐幀亂數、不依網路時序創建身份。
- 魚體與陰影使用同一平滑擺尾；頭部穩定，原有貼圖隨魚身移動。法線／切線按同一變形正確傳遞，眼睛與鰓不因動作裂開。這是原創簡化動作，不宣稱生物學測量的游姿。
- 近岸實際游動、轉向及接近岩石／海床時不穿越；碰撞外框涵蓋所有擺尾相位、實際尺寸與數值餘裕。不得用舊魚的形變半徑假裝新模型已驗證，也不得為隱藏穿透而關閉魚或移除周圍岩石。
- 可用滑鼠／觸控主動選取、觀察收錄、導航、攝影與水族館展示，維持現有不擋中央視線的操作。圖鑑使用實際模型縮圖和正確來源說明。

## 進海與資源行為

- 音訊與新魚素材均不可成為進海的必要等待。同步註冊小量物種／身份資料；新魚幾何與三張貼圖於入口完成後選配載入。pending、永不回覆、404、解碼錯誤、GPU 上傳失敗皆仍可入海、游泳與觀察其他魚。
- 素材未備妥時不出現可點選／導航的幽靈魚。有限重試與清楚的單魚重試操作，不讓素材失敗改成整頁錯誤。重試／重入不得重複身份、batch 或 GPU 資源；過期回覆不再掛回已釋放的 owner。
- 使用來源 OPAQUE 材質，不新增透明 pass。獨立 source tangent sidecar，不擴大現有全世界 archive 的 12-float 頂點格式。每 renderer 共用該魚的 mesh／材質，水族館 clone 保留切線，正確持有／釋放共享資源。
- 保守預設 512 三圖；桌面較高品質若選 1024，必須用穩定條件，只載入一套，不因短期自動畫質波動反覆下載。既有自動解析度保留。512 細節與成本需在真實可玩場景驗證，不能用靜態框景審查推論實體手機 FPS／耗電。
- baseColor 僅一次 sRGB 解碼；normal／ORM 為線性資料，UV/Y/handedness 不任意翻轉。材質沿現有水下光照；保留目前光學近似的限制，不宣稱完整 glTF 參考 PBR 一致。
