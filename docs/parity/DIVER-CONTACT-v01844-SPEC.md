# 玩家完整身體碰撞

固定基準：`91848fdf1fae4338408ee1dcbfd05565b1c63832`（0.18.43）。此工作處理使用者「我跟魚都可以穿越石頭」之玩家部分；魚、海龜美術與深海隨機分布仍是獨立未完成項目。

## 可重現缺陷

實際封裝的潛水員比原有 0.4 m 玩家球長。`qa/parity/v01844-turtle/full-goal-probe.cjs` 以正式 collide 接近旋轉且非等比縮放的岩石後，球安全，但 3,608 個剛性模型頂點位於岩內；第一個見證點另由原始岩石三角形 ray parity 確認。此資料是 CPU 幾何證據，不是原生畫面或手機實測。

## 要求

1. 以正式 kind-5 mesh 與完整踢水／手臂動作範圍建立細長的分段凸包絡。每個完整三角形三角須由同一凸球涵蓋，不只測頂點聯集。沿用既有岩石 BVH 和地區牆，不新增第二份世界。
2. 平移與旋轉都須掃掠；旋轉的球心弧線須有解析誤差界。整組平移及最後姿態須重新驗證，失敗保留最後安全的完整姿態。不能把模型各部位各推各的。
3. 第一人稱亦保護身體；切第三人稱直接呈現同一安全姿態。視線自由轉向，接觸可限制身體轉向，不能鎖住滑鼠／觸控。保留真實岩拱通道和自由水域的移動。
4. 處理入海、續玩、快速定位及無位移轉向；補間不得把身體切入岩石。保留原入海不等待音效、自動畫質、存檔與觀察操作。
5. 接觸查詢保持局部、使用可證明安全的空間餘量減少重複工作；不得因本修復新增渲染材質、三角形或 draw call。實測 CPU 成本，不能由幾何測試宣稱 FPS／實體手機耗電改善。

## 驗證與交付

先保存基準反例；測正式模型所有三角形的解析包絡與代表動作。再以實際封裝岩石驗證頭、腳蹼、轉向、快移、狹窄處與視角切換／插值。序列跑原生電腦和觸控模擬，保留前後場景、GL與入海證據。Standards、Spec 各自獨立審查後發布，查 Pages 精確提交並核對線上檔案；不將此 slice 當完整擬真目標完成。
