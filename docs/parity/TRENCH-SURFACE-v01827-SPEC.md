# v0.18.27 — 海溝可見岩層與沉積表面

本輪基準為 `df7b1a7042fc6b544e893fd9ee3d2833d96e8c94`（公開 0.18.26）。完整目標仍依 SPEC.md、CONTEXT.md 及 issues/07、13；本切片不等同完整商用或 Wii 對等驗收。沿用已核准的 OceanTrench.build／OceanRegions 碰撞、Renderer→WebGL、正常玩家操作接縫。

## 玩家結果

1. 700／1400／7000 m 站點近距離岩壁有真實的侵蝕層緣、突出與凹入；側移、仰視時有幾何視差及遮擋，不靠貼圖黑線冒充形體。
2. 細粒泥底與硬岩層分開著色，細節隨距離穩定過濾；不使用大塊岩石貼圖與岩壁條帶覆蓋沉積物。
3. 去除精確共用的內部碰撞面之渲染提交，保留完整實體碰撞 planes、外露封邊、路線、生物核心、研究點及存檔個體。幾何必須與 collision/floorAt 相符，不引入裂縫、不可見障礙或新穿牆點。
4. 桌機及觸控尺寸維持原自動畫質、解析度與 MSAA 規則。不得藉降畫質或減少原有生物達成成本改善。
5. 完整導覽保留 690 m 桶眼魚停留；其後 900 m 皺鰓鯊的四秒觀察維持完整、可讀的側身，包含首次到站與不同巡游相位（側身方向餘弦 > 0.85）。觀察位置依同一接近速度與自然姿態做一次有界預估，停留終點固定，不改魚的位置、朝向或生態。原 100／40 px 投影門檻、碰撞限制、巨魷魚 12–18 m 距離及桶眼魚接近規則不變。

## 驗證與發布

- CPU RED→GREEN：實際 build 幾何不得包含精確重合的內面；可見截面具足夠分層輪廓。既有地形、路線、研究點、地形高度吻合檢查全部保留。
- 完整場景必須重新烘焙／分區；公開載入的幾何與正式來源一致。驗證完整 fallback 與 streaming metadata，保留原生物 UID。
- 真實 GPU 固定相機、時間、quality、framebuffer；baseline/candidate ABBA，量測完整 frame。截圖／readPixels 在 timing 之外。保存完整原始樣本、提交量與陰性結果；觸控只代表本機模擬。
- 親看正常到站、近距側移／仰視與切溝底部 PNG。影像需要能辨認層緣、泥面及近距生物；數字或通過測試不能代替視覺審查。
- 正常玩家流程走完海溝研究路線，桌機／觸控維持主動點選名稱、自動畫質；已知 resize／串流保留畫面之黑閃回歸必須通過。
- 定向檢查後完整 CPU／static suite 一次，Standards 與 Spec 分開審查。Pages 建置狀態、公開每檔雜湊與可玩性驗證完成才稱已發布。

預期移除內部幾何降低提交與載入成本，近景質感提升不應增加固定海溝路線的整體 GPU 成本；實測若未達成，保留結果並調整，不以單次最快樣本作結論。實體手機、耗電及所有硬體無黑閃仍需另行驗收。
