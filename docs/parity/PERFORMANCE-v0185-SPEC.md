## 畫質與量測界線

固定畫質測試必須保持解析度、MSAA、模型、貼圖、LOD、陰影、光影算式、幾何提交數及繪製順序；不加 FPS 上限、不減生物、不更改模擬頻率。自動比例功能的測試另行量測，不把減少像素的結果算成固定畫質 shader 收益。

對照完整 framebuffer：既有軟體 WebGL 回歸預設仍要求逐位元組相同。原生 GPU 另記錄所有 RGBA 差值（包含小視角）；編譯器常數折疊可能產生最終 8-bit 色彩的 1 級舍入差，僅容許每渠道最多 1、變更渠道少於 0.01%，任何輪廓／可見缺損必須處理。這不等同宣稱全部原生畫面位元相同。第一次原生小視角嚴格測試在礁景得到 3 個渠道各差 1，故新增明示的 `--compiler-rounding` 原生驗收模式，沒有改掉原有預設零差值斷言。

GPU 使用原生 Chrome、單一完整 frame timer query、暖機後交錯 A/B；每個 draw 的 query 會強制 tile flush，不用它推算正常 GPU 瓶頸比例。實際 RAF 另取樣，揭露裝置／尺寸／設定及 P95／P99。手機版面使用瀏覽器觸控模擬，只能證明相同電腦上的觸控設定與操作，不能宣稱實體手機 FPS、續航或耗電百分比。

MSAA 暫存附件 invalidate 已做獨立 A/B，沒有可確認收益，撤回；不發布這項假設。閉合岩背面剔除只分析，不改地形或增加破面風險。
