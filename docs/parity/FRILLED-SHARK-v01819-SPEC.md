# 0.18.19 皺鰓鯊深海遭遇

基準 `a2a4bdab378555b25d53af8a0c774f4228982065`，沿用完整規格與使用者已授權的持續改善、直接更新線上版範圍。此項補上深海可見內容，不代表完整商用、全部物種、多人或實體手機驗收完成。

1. 正常入海後選擇深海泥底站，沿連續海溝在約 900 m 遇見一隻 1.7 m 皺鰓鯊 Chlamydoselachus anguineus。深度、體長、個體數、巡游和動作節律為原創遊戲配置；不靠瞬移或自動解鎖。遭遇位於現有岩壁旁的安全水體，保留既有 700/1400/7000 m 站、連續導航與無氧氣限制。
2. 原創高低 LOD 都有棕褐色細長身體、六對褶鰓及首對跨喉褶皺、短吻端位口、三尖齒、成對胸鰭／腹鰭、後置單背鰭及臀鰭、細長尾部。無明顯雙叉鯊尾、外加發光或追殺行為。科學資料與原創假設分開記於 FRILLED-SHARK-REFERENCE.md，不使用外部模型、照片或貼圖。
3. 專屬緩慢側向身尾波動，頭部穩定；正式時間驅動、顏色與陰影共用變形，法線同步，暫停凍結。不因鏡頭改變而搬動。整身與動態包絡留在水體、避開岩層；水族館使用自身座標與真實尺寸。
4. 沿途導覽接近到整身可見距離並停留。僅滑鼠／觸控主動選取；既有觀察、圖鑑、相機、相簿、保存重新載入及正常站點抵達可用。未選取不在中心自動顯示名稱。圖鑑有實際模型縮圖與原創 SVG 後備。
5. 追加第 43 類，不更動前 42 類索引或歷史個體 UID／外觀／位置／動作。編譯世界與程序生成各生成一次；只新增共享高低模型與兩個 instance batch，不增加逐幀幾何、貼圖或 shader 編譯。
6. 高 LOD <= 12,000 三角形，低 LOD < 高 LOD 60%，新增索引幾何 < 1 MiB。自動畫質維持，既有畫質／頻率／內容不為取得效能通過而降低。固定相同場景和畫質測量新增個體 GPU 差額，保留原始值及測量限制。
7. 沿用已確定的 registerFauna/faunaGeometry、addLife/載入附加、updateLife、正式渲染與玩家 UI/保存邊界，逐項 RED→GREEN。CPU 驗證幾何／包絡／相容；原生瀏覽器驗證實際外觀、正常桌機與觸控流程、連續游動無全黑幀。觸控模擬不冒充實體手機。

8. 近景成本診斷後，為 kind 11／material 0 的深海生物加入載入時預編譯的 fragment 特化；保留原頂點程式、陰影與 fallback，逐幀不編譯。受控 A/B 僅切換正式 generic／特化程式，固定其他內容，核對完整 RGBA 與原生 GPU 計時；未證明效果則不以此宣稱效能改善。
