# 0.18.13 載入中斷後，仍能繼續進入海洋

固定基準 `3b7037e58ac7c11bccd50c44a8763fc9dd8c3cbb`，上一版 0.18.12 已公開驗證。本輪處理完整規格第 31、32 條的啟動可靠性；海溝新增調查另留可實作提案，完整內容與商用驗收仍未完成。

## 玩家結果

1. 材質圖片沒有成功或失敗事件時，單次最多等待 12 秒。網路圖片沿用 150／400 ms 退避及最多三次嘗試；data／blob 圖片只嘗試一次。正常較慢但期限內完成的載入仍成功，不改畫質、取樣、降採樣及資產。
2. 全部材質準備好才替換現有材質。一張終止失敗時，清理全部未完成圖片的事件、計時器及來源，再釋放新 GPU 材質；過期事件不得使用已釋放資源。既有畫面保留，之後可以再次升級。
3. 開場材質失敗明確顯示素材未能載入，提供原有重新嘗試入口並聚焦該按鈕，不誤稱瀏覽器不支援 3D。重新連線後可由正常按鈕重新載入、自由入海，保持自動畫質。原有 WebGL／context loss 省電重啟與備份流程保持不變。
4. 完整場景備援檔約 21 MiB，下載與非同步解壓整體最多等待 60 秒，涵蓋 headers、body 及讀取解壓結果。沿用區域下載的取消及截止機制，區域預設仍是 12 秒；保留壓縮／解壓大小上限、格式驗證及驗證後才上傳 GPU 的順序。逾時取消請求並進入既有程序場景備援，晚到結果不得重複上傳或加入世界。
5. 不增加逐幀特效、模型、材質解析度或模擬頻率。桌機／觸控預設自動畫質、已知黑閃邊界與原場景仍通過回歸。本輪不以這些啟動修正宣稱 FPS 或耗電改善。

## 實作與驗收

沿用已授權的正式啟動、瀏覽器 Image／fetch／計時器、Renderer 材質交易、場景載入與可見恢復入口等測試邊界。按單一行為 RED → GREEN；CPU 注入無事件／延遲結果確認清理與截止，原生 Chrome 用真正 HTTP 停滯及真實時間確認畫面、重試和入海。原生觸控尺寸不等於實體手機。

CPU 至少涵蓋首試／重試／embedded 停滯、成功前後計時器、過期回呼、整組取消、升級重試、完整場景 headers／body／解壓停滯及晚到不修改世界。原生桌機與觸控尺寸驗證素材停滯到錯誤入口、正常重試後入海；完整場景至少一次真實 body 停滯後可操作程序備援。非同步截止不能中斷同步 GL、JSON 或主執行緒工作。

兩軸獨立審查依固定基準；必要回歸、建置通過後依既有授權直接更新 Pages，再驗證指定提交、全部公開 manifest 雜湊與可遊玩狀態。推送、本機通過與公開部署分別記錄。
