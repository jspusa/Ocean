# 0.18.30 深海不可見海面的提交成本

固定基準為已公開 0.18.29 `4a3d9851ed4db525a52185f5d4f306f21ea05764`。延續完整規格第 32 項及桌機／手機自動畫質要求。先前共用頂點候選因沒有可信的普遍收益而撤回，資料與負結果保留於 [實驗紀錄](WATER-GRID-EXPERIMENT.md)，不混入本次程式。

1. 保留原水面幾何、shader、可見海面、物種、岩層、光照、解析度、MSAA 及自動畫質。只在既有 `oceanSunlessView` 證明整個視錐位於 3,000 m 以下時，省略完全不可能進入視野的海面提交；目前 far=950 的門檻為相機深度 4,900 m，FOV 超過 90 度及不符合原規則的情況仍走原路徑。
2. 省略範圍只有水面 uniforms、VAO、draw 及對應統計。alpha-to-coverage 關閉、深度狀態、MSAA resolve、體積光、粒子與後製保留；返回淺水的第一個完成幀恢復海面。串流未就緒時仍保留上一個完成畫面。
3. 在已確認的正式 Renderer→WebGL IO 與原生瀏覽器影像界面驗證：門檻前後、極深海、朝上、原點跨界、淺水返回及低品質。只有深海允許精確減少一個 draw 與原海面頂點／三角形，其他工作量一致；完整 RGBA 零差異，深海關閉 depth test 的真實海面 query 亦無覆蓋。
4. 固定 v29 原 render 與實際候選同 context、同場景、同資源比對。至少 60 個完成暖機幀，200 個相鄰平衡 ABBA／BAAB GPU queries；所有計時先於圖像讀回。保留無效、負結果及中斷資料，不由頂點數推定 FPS 或耗電收益。
5. 測試清理採明示 v2 契約：局部診斷精確恢復即時 GL 狀態；跨海域結束以正式 renderer 完成原視角、驗證有效 GL 結束狀態、還原設定及清除測試資源，不聲稱能恢復串流已退休的啟動期 handle。所有錯誤仍使驗收失敗。
6. 正常桌機／觸控入海、連續深海探索、主動生物選取、自動畫質與已知黑閃回歸須通過；完整 CPU／靜態與兩軸獨立審查後才發布並核對 Pages 精確提交和公開檔案。觸控模擬不是實體手機／耗電驗證，完整商用目標仍為進行中。
