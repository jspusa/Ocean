# 0.18.32 可停留與續行的深海導覽

審查基準 `2e91620777c354367255d5e18069b1b4f8231fae`。延續完整規格第 1、2、9、13、26、31、32 項與工作單 07／08／13；完整商用目標維持進行中。

## 問題

現行生物導覽只停四秒便離開。玩家主動選魚、游動或拖曳會停止 auto，下一次 updatePlayer 清除整趟行程。看生物、拍照及繼續原目的地因此無法形成連續流程。

## 本輪必要行為

1. 從既有入口選擇海流目的地，沿真正連續水體游動。到中途生物觀察點便停下，沒有倒數或自行離開；抵達只提示觀察，不選魚、不顯示自動魚名、不授予知識。動物繼續自然活動，玩家可以自由環視與移動。
2. 既有側邊通知提供明確「繼續前往」及「結束導覽」。玩家主動選魚、拖曳、游動、攝影或選單時，導覽交還控制並保留目的地。沒有新中央卡片或永久首頁控制項；操作按鈕至少 44 CSS px，手機直橫向可用。
3. 「繼續前往」必須依當前真實位置重新規劃合法路線，跳過本趟已抵達的中途觀察點，不返回舊座標、不瞬移、不重複同一停靠。無合法路線時保留暫停的目的地並提示游到開闊處；不可穿岩或清掉行程。切換目的地會開始新的停靠進度。
4. 使用既有 deepsea 保存分區存放目標站及有界的已停靠 encounter ID。舊存檔仍正常讀取；未知站、未知 ID、重複與非法輸入被正規化。回首頁、重開、完整匯出／匯入保留目的地及已停靠點；續玩保持自由操作，只有明確點擊才恢復導覽。開始新潛水不承接前一潛的導覽，明確結束或抵達最終站則清除目的地。
5. 所有保留與清除操作不改圖鑑、調查、照片或既有 visited。手動接手不能吃掉當次移動輸入。主動繼續才清除觀察選取、跟隨及殘留移動；使用原有地形、碰撞、動物尺度、渲染和自動畫質。
