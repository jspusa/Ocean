## 本輪行為

- 既有 44 種、索引、個體身分、棲地與舊存檔保留；尾端追加三腳魚 `Bathypterois grallator` 與小飛象章魚 `Grimpoteuthis sp.` 各一隻固定身分個體。原創幾何，不能拿現有模型換色。
- 三腳魚約 2,400 m，代表標準體長 25 cm；兩條腹鰭與下尾鰭真正支撐泥面，感覺胸鰭獨立微動，不模擬無依據的步行。標準體長與延伸鰭分開記錄。
- 小飛象章魚約 3,600 m，代表全體縱向尺度 20 cm；成對耳鰭、八腕蹼、單排吸盤與 cirri；緩慢懸游和拍鰭，保持全身水中安全間距。屬級身分與原創尺寸／節律界線明寫。
- 現有連續海流導覽新增兩次可無限停留的相遇；可手動接手、續行、主動點選觀察、拍照、收入圖鑑及保存。未點選不出現中央魚名。
- 船上追加兩個獨立原創攝影來信，透過正式底片／沖印／原圖附件投稿；生成個體或開選單不算完成。
- 世界與水族館使用相同尺寸及動畫介面；按距離切換近遠模型。只增加兩個個體和四個 LOD 批次，沿用材質與渲染 pass、自動畫質，不增加全螢幕粒子。

幾何包含三腳魚真實三點接地、章魚八腕／蹼及完整動態包圍；確認正確法線、有限數值與模型預算。新個體在程序生成與編譯場景載入皆只生成一次，保持既有 UID／home。正常桌機與觸控模擬從入海沿現行導覽抵達兩者，主動觀察、原始 JPEG、保存重載及攝影附件成立。渲染檢查須直接使用正式 WebGL shader，記錄正常畫面、自動畫質、GL／context 與有限條件下的成本；不能把模擬宣稱為實體手機、耗電或全機種黑閃驗證。發布後核對 Pages 精確提交與公開雜湊、正常入海。
