# 0.18.18 手把工具指標與輸入生命週期

基準 `c0a5fbe8a1ca71309e3c86864e8ac71327ceb574`。依完整規格第 2、5–15、22–23、31–32 項，補上現有工具可見但標準手把無法操作的缺口；不把此切片當作完整商用或全部裝置驗收。

## 玩家行為

- 保留游泳模式 A 拍照、B 主動選取畫面中央生物、X 地圖、Y 加速、LB 快速轉身、RB 水面環視、雙搖桿及扳機浮潛、Start 選單。
- View／Select 切換明確的手把指標模式，只有使用時顯示小游標和簡短提示；左搖桿自由移動、A 點選／按住拖曳、右搖桿捲動、方向鍵調整已選選項、RT 精細移動，B 或 View 離開。指標模式完整消耗該幀手把操作，不同時拍照、選魚、巡航或游泳。
- 指標作用於既有可見 UI 與工具，沿用正式事件處理器、幾何與範圍規則；控制器來源有獨立的捕捉／釋放生命週期，不能把虛構 pointer ID 交給原生 setPointerCapture。原生滑鼠／觸控的捕捉仍由瀏覽器處理。不得改造 isTrusted 或宣稱軟體指標是可信手勢。
- 水中筆可自由描繪、五色、擦除、撤銷、完成與保存重載；維持世界座標、遮擋與容量。生物可主動選取、靠近、輕觸／來回撫摸、餵食、邀請、哨子、抓握與放手，不直接寫信任或略過部位命中。
- 船邊訓練可在實際嘴部／胸鰭完成連點、輕撫和按住六種指令，最多三招、清除、調強度、Go 與回饋；既有動畫、熟練與保存不變。
- 同一指標支援微觀近看／鏡頭／拍照／退出、打撈、探索海圖平移／選點、水族館環視與甲板訪客互動。這些必須有各自證據，不因共用路由就自動視為完成。
- B／View、Start、換工具、換面板、回首頁、失焦、隱藏、拔除手把、換控制器、真滑鼠／觸控接手及 WebGL context loss 均取消未完成手勢，不提交半筆、不補發 tap、不留下移動輸入；重新取得控制須先放開按鍵。
- 游標速度與長按語義依實際時間，30／60／120 Hz 不改變結果；閒置未啟用的控制器不增加 DOM 掃描、場景繪製或 GPU 資源。

## 既定驗證邊界

延續已使用的正常可見 UI、標準 navigator.getGamepads 系統輸入、正式 renderer 與保存／重載邊界。逐項 RED→GREEN 驗證標準按鍵／軸狀態如何觸發可見行為；DOM／時間 adapter 只替代系統邊界，不 mock 自己的領域規則。原生 WebGL 驗收只在 navigator 輸入來源模擬控制器，經正式 pollGamepad 與真 UI 操作，不直接呼叫工具或修改成果。

至少保留一條從正常入口招募並訓練的自然流程；明示任何測試使用的舊存檔 fixture，不能替代自然招募。可獨立以正式幾何／保存接口覆蓋碰撞、越界、冷卻、取消與重載。

文字輸入、原生檔案選擇、瀏覽器可信手勢保護（首次聲音／全螢幕）與實體手把／實體手機仍分別列出，不用這次工具路由宣稱已完成。公開發布須核對 Pages 指定 commit、所有 manifest 檔案及公開正常操作。
