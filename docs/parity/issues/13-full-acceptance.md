## 0.18.10 連續探索與深海渲染（已發布）

公開 0.18.9 已完成一次 1,200.70 秒原生 Chrome／Apple M3 Max 的真實 RAF 探索：實際往返三個深度帶、12 段路線、30.72 km，沒有觀測到 context loss。但全程 visible 平均只有 10.225 FPS，P95／P99 為 333.4／650.1 ms，**屬穩定完成證據，並未達到流暢目標**。全程原始資料保留選單、畫質重設及每次慢幀，沒有慢幀上限剔除；continuous 僅作輔助指標。背景 CPU 工作及首次測試的每秒 GL 查詢使它不能當成裝置峰值性能，也不能直接把兩版長測全部差異歸因 shader。詳見 `qa/parity/v0189-endurance-desktop.json` 及本輪報告。
