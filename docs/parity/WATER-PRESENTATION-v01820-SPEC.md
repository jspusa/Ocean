# v0.18.20 水中可見度與深海照明

狀態：本輪已實作、驗證並發布；完整範圍與公開交付見本輪報告。固定基線 `268dd3c4594a5465d05d9a642a1e09fc9e422fd4`。
承接完整 [SPEC](SPEC.md) 第 32 項及使用者對漂浮亮光、黑閃、海溝真實感、低負載的要求；不縮減 33 項總範圍。

## 本輪契約

1. 原有懸浮微粒與呼吸氣泡使用自己的世界深度、相機距離及共用太陽／頭燈參數。深水熄燈不再有自發亮青色。氣泡仍由原有呼吸與上浮生命週期管理，潛航器內不產生氣泡。
2. 原有兩組點繪製移至水色／霧合成後、最後反鋸齒前。讀取已解析的不透明深度遮擋；後牆距離與空水不能改變同一粒子的照明。沒有新增全畫面 pass、貼圖、FBO、點數或幾何。此為顯示色域透明混合近似，不宣稱完整物理散射／折射。
3. 岩壁利用既有岩石樣本與 noise 打散重複層理，不新增材質讀取或 noise 次數；沉積平原保留細緻平緩特性。世界座標固定，不因相機移動滑動。
4. 在可證明太陽照明極小的深水範圍，允許保守略過無效太陽計算與陰影。保留頭燈、AO、生物發光、材質及所有物種；回到有光區須即時恢復陰影。界線、光學誤差上界與實際像素結果須記錄，不能將近似宣稱完全等值。
5. 電腦、觸控配置原有解析度／品質／自動調整不降低。幾何裂縫、正常轉向／游動／品質調整不黑閃、主動指向才出名稱等既有契約仍適用。

## 介面與驗證

使用既有 Renderer shader／render 介面與純規則函式，不引入新的遊戲儲存欄位。既有影像、場景 streaming、照片與介面流程保持相同。

- RED→GREEN：實際 Renderer 的 GL 呼叫順序；production shader 隔離氣泡的深度／燈光／遮擋／距離；照明裁剪的數學邊界與喚醒。
- 原生 WebGL：基線／候選同相機、時間、品質、解析度的影像及 ABBA GPU 計時；不將截圖／readPixels 密集量測當作正常 FPS。
- 正常 UI：電腦和觸控導覽抵達深海、主動觀察與拍照；連續畫面與原有 resize 保留畫面回歸。觸控模擬不等於實體手機。
- 收尾：完整 CPU／靜態套件、獨立 Standards／Spec 審查、更新版本、Pages 成功狀態、公開檔案雜湊及正常啟動驗證。
