An analytic inverse bend or a triangle-centroid filter is not an equivalent surface and is not used for this contract. Its output must exactly match all 2,904 static individuals in the immutable baseline; candidate identity/genes remain a separate compiled-world invariant.

Construction can cache actual failed local vertex/face witnesses for the same posed actor and immutable substrate. Each candidate re-transforms the witness using its current pose; a witness that no longer fails falls through to the complete gate. Positive clearance is never cached between poses. Root support may reject a candidate before crown work, but successful candidates still pass both original criteria. This construction work is absent from gameplay's verified replay path.
