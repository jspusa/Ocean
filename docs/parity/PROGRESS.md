# 持續目標接續紀錄

目標仍是 Wii 第一代 Endless Ocean 的完整 feature parity，維持電腦／手機、自動畫質與原有水下畫面方向。0.10 是已驗證的可玩切片，不是完成標記。

## 本版狀態

延續 0.9 的互動／夥伴訓練、探索／筆跡／打撈、委託／訪客、水族館，0.10 新增：

- 真實 JPEG 底片 → 回船選片沖印 → 相簿 → 投稿；20 底片／120 相簿／96 MiB 原圖，容量、舊版搬移、資料庫失敗救援、多分頁衝突、完整備份與附件固定。
- 可走動的甲板、可見人物、船伴／告示板／收藏箱／躺椅／下水點、八類船艙物件入口、角色外觀、可見配件、海豹／企鵝訪客、躺椅本機音樂與閒置欣賞。人物仍為程序化風格，寫實精緻度有待繼續提高。
- 四個實際移動研究船的泊位、對應入水點與航程探索範圍、保存、動態返航指引。仍是一個連續原創海域，不能冒稱原作全部地區。
- 0.10 擴寬實體船體／甲板／欄杆並重新烘焙，場景 sourceVersion 同為 0.10.0。新增場景定位標記供移船使用。照片庫初始化需 await；進度與影像分開但匯出包含完整原圖。

TEST_REPORT.md 是最新檢查與限制；REVIEW-v010.md 記錄兩軸審查與四個修正。官方功能基準在 ../WII-PARITY-REFERENCE.md，內容清單在 ../WII-CONTENT-INVENTORY.md。214 條目是核對 42 張社群保存原作畫面的計數，不是任天堂公布數字，也不是本作已完成的物种數。

## 接下來的獨立切片

1. 工作單 08／12：按已核對的 214 個原作圖鑑條目擴充珊瑚、小型生物、深海／海岸及傳說內容，完善微觀探索。加入虎鯨等夥伴與完整訓練候選／特技；不能以改名同模型冒稱完整內容。
2. 工作單 07／09／10：洞窟、遺跡、深海、全潛區、原創主線／解鎖與日夜、季節生態。Nintendo Playtest 已證實季節會影響生物出現；精確曆表仍需查證。四個泊位只完成移船機制。
3. 工作單 04／05／12：繼續查核全任務、收藏、裝備、船上事件及原作相簿限制，擴充角色與船艙美術。現有六封原創委託、九件收藏及兩種來訪動物不是完整原作數量。
4. 工作單 11：真實跨客戶端雙人遊玩、好友／准入／訊息／筆跡與工具同步／位置、斷線保存。原 WFC 退役不刪除需求；需外網實際驗收，不能用 NPC 或同機錄影代替。
5. 工作單 13：完成新增工具完整手把操作，實體手把／手機、長時段與完整真人玩法驗證。現有手機檢查是 Chromium 觸控模擬，沒有實體手機驗收。

所有後續切片仍需 UI、實際三維結果、保存重載、失敗案例與回歸。可以持續交付局部版本；只有完整矩陣與全部 33 條玩家故事有證據後，才可將持續目標設為完成。
