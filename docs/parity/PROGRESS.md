# 持續目標接續紀錄

目標仍是 Wii 第一代 Endless Ocean 的完整 feature parity，並維持電腦／手機、自動畫質與既有畫面方向。0.9 是已驗證的可玩切片，不是完成標記。

## 本版狀態

新增共同功能生命週期，生物熟悉度／互動／海豚訓練、探索圖與航跡／世界筆跡／實體收藏、郵件／帶路客人／攝影參數／投稿附件保留／氣量／換色、可配置的三維水族館。所有區塊走原有航程保存與備份；保留 0.8 編譯礁體，不因應用程式版本升級重烘焙。

實際範圍、重現命令、測試計數及限制以根目錄 TEST_REPORT.md 為準。0.9 審查見 REVIEW-v09.md；完整原作一手證據在 ../WII-PARITY-REFERENCE.md；完整玩家故事在 SPEC.md。畫面／觸控測試為本機 WebGL 與 Chromium 模擬，沒有實體手機驗收。

## 接下來的獨立切片

1. 工作單 04：拍攝暫存 → 回船沖印 → 收藏相簿 → 選片投稿的完整攝影工作流。現在已保存真實投稿照片，但尚無沖印與相簿刪除／完整管理。相片容量及原作規則需繼續查證；未確認的本作參數明確分開。
2. 工作單 05：實體甲板點選移動、互動點、船伴／告示板／躺椅與船艙物件入口，角色外觀與裝備逐步完善。原作甲板可走；船艙只需官方已證實的物件互動，不自行要求無證據的自由行走。
3. 工作單 12、08：補齊原作內容範圍一手盤點，再擴充微觀生物、虎鯨夥伴與物種種類。未知數量不可當零或以 12 類／673 個體冒稱等量。
4. 工作單 07、09、10：移船／不同潛區、洞窟／遺跡／深海與原創劇情、解鎖及日夜生態。
5. 工作單 11：真實跨客戶端雙人遊玩、好友／准入／訊息／工具同步／位置與斷線保存。原 WFC 退役不刪除這項需求；必須有外網實際驗收，不能用 NPC 或同機錄影代替。
6. 工作單 13：新增工具完整手把操作尚未實作；完成後再做實體手把／手機、長時段與完整真人玩法驗證。

每一切片仍需 UI、實際三維結果、保存重載、必要失敗案例及既有回歸。可以持續交付局部版本；只有完整矩陣與全部 33 條玩家故事有證據後，才可將持續目標設為完成。
