# 持續目標接續紀錄

目標仍是 Wii 第一代 Endless Ocean 的完整 feature parity，維持電腦／手機、自動畫質與原有水下畫面方向。**0.13是原創區域及調查的交付切片，不是完整目標的完成標記。** 全部33條玩家故事及未完成內容仍保留在 [SPEC](SPEC.md) 與 [功能矩陣](../../FEATURE_PARITY.md)。

## 本版狀態

0.13.0本機候選已完成最終畫面、七場景雙尺寸效能、CPU25組、靜態47/47及離線10/10，正準備發布及核對公開85檔。前一已驗證公開版0.12.1遊戲提交 `b7443bd6862d1ddcc80870d098e80cd1cb840afa`；歷史公開11項及76檔雜湊、離線10項見 [0.12.1報告](../TEST_REPORT-v0121.md)。本輪基準為乾淨main `50180d23384636da73a74f75890e906c46bdb5ab`。

## 0.13實作

- 有頂洞道、側室與天窗，遺跡中庭及檔案室，約94m深裂谷；牆、頂與地面影響游動、視線和第三人稱鏡頭。
- 六章《回聲潮譜》承接眠海號記錄器：洞中調查、遺跡解讀、回訪、三點儀器部署及連續記錄、兩種深海生物完整輪廓觀察、回收與回船解讀。三個新研究泊位隨故事解鎖，合計七個泊位。
- 五種原創模型、九個固定個體：腔棘魚、巨型烏賊、吞鰻、駝背鮟鱇、日本蜘蛛蟹。合計32類／734個體，原725個體的ID、生成順序、home、初始位置、種子、尺寸保留。
- 頭燈照亮實際表面，包含錐形範圍、距離、法線與水中光色衰減；洞中／深水自動啟用。圖鑑、微觀、照片原圖與水族館沿用同一模型及公尺尺度。
- 修正新增卡片後頁尾遮擋移船、快速回船被過期轉場藏起介面、海面誤報深水地標、相機平滑穿牆、照片／失焦未中止連續記錄、只看生物中心也算全身觀察等問題。

## 驗收界線

桌面1440×900故事89/89、直向390×844故事90/90、橫向844×390故事89/89已通過；直向另有完整個體在合法距離但被裁切時拒絕記錄的案例。全六章、七泊位、三點儀器實體增減、深於91m的保存恢復、真實檔案下載及新儲存區匯入有證據。洞道全路段約100.56m由實際鍵盤／觸控輸入驅動；跨區使用位置fixture，等待用遊戲tick加速，不能宣稱無輔助全程真人遊玩。

原控制桌面40／觸控48、原玩法桌面／觸控各32、導航各18已於本版重跑。三尺寸新生物／區域135/135，微觀40/40，原礁區模型桌面22/22、觸控17/17亦通過。最終效能與交付結果收錄在 [本版報告](../../TEST_REPORT.md)，不能將前版測量寫成這版效能。

圖鑑為真模型棚景，棲地測試保留真UID及個體尺度；CPU幾何、模型數量與GPU提交數不單獨證明畫質。物理手機、完整手把、長時段真人遊玩仍待執行。沒有原作同硬體對照，不宣稱全面超越Wii或攝影級擬真。

## 後續獨立切片

下輪優先處理已目視的美術差距：洞道與裂谷仍呈規則牆板、鮟鱇頭型及鰭／關節材質仍有程序模型感。需在真實遊玩視角改善自然岩體輪廓、材質和生物解剖；不能只增加多邊形、數量或測試通過率，就宣稱達成使用者的擬真目標。以現有路線、碰撞及存檔相容性為回歸基準。

1. 工作單02／08／12：既有八種夥伴、六基本手勢與進階強度變體、六種微觀候選及新增五種深水內容保留；繼續覆蓋完整圖鑑、岸上／傳說／海綿珊瑚與自然行為，補查完整交好事件及全部特技。214是原作圖鑑保存畫面盤點，不是Nintendo公布數字。
2. 工作單07／09／10：洞窟、遺跡、深水裂谷、六章原創調查及七泊位已落地，不能再列為完全未實作；仍需完整原作區域／主線深度盤點、更多故事內容、日夜與季節生態，原作逐物種季節曆表仍待查證。
3. 工作單04／05／12：全委託、收藏、裝備、船上事件與原作相簿／水族館範圍，繼續補角色及船艙美術。六封原創委託、九件收藏、兩類來訪動物不是完整原作數量。
4. 工作單11：真正跨客戶端雙人、好友／准入／訊息／筆跡與工具同步、位置及斷線保存。原WFC退役不刪除需求；需外網實際驗收，不能用NPC或同機錄影代替。
5. 工作單13：新工具完整手把操作、實體手把／手機、長時段與完整真人玩法。

每個後續切片仍需玩家UI、真實三維結果、保存重載、失敗案例與相應回歸。只有完整矩陣及33條玩家故事全部有相符證據後，才可將持續目標設為完成。
