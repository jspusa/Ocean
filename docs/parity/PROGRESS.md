# 持續目標接續紀錄

目標仍是 Wii 第一代 Endless Ocean 的完整 feature parity，維持電腦／手機、自動畫質與原有水下畫面方向。0.11 是圖鑑與微觀探索的交付切片，不是完成標記。

## 本版狀態

0.10 基準遊戲提交為 `b92cfda40cb1e49c9f8b2ba3dbb5cce8f51ad3f0`；歷史交付證據保存在 docs/TEST_REPORT-v010.md。0.11 遊戲提交 `22d1c058e655714819ab8a344764433a4293487d` 已於2026-10-13發布，公開版11項與67份檔案雜湊全部驗證；根目錄TEST_REPORT.md保留完整結果。

0.11 新增八種獨立形態生物與 31 個固定個體，合計 20 類／704 個體。海馬、海蛞蝓、花園鰻、槍蝦、躄魚可由微觀工具尋找與近看；蓑鮋、烏賊、鸚鵡螺具有獨立動作。海馬24 mm、槍蝦28 mm等尺寸保持不變，鏡頭使用近裁切與局部環視。微觀不改潛水員位置，遮蔽、躲藏、距離與實際停留時間共同決定觀察資格。

新增模型與動作接入原圖鑑、熟悉度、底片、沖印、相簿及水族館；原有673個體ID及尺度基準不變。新UID含底線的保存已修正，微觀照片完整備份保留mode、視角與個體。圖鑑導航使用實際棲地位置，不依賴暫定地標索引。棲地支撐對齊實際地面三角面，水族館移到獨立原點座標顯示，並將支柱頂面埋入底床，避免共面造成的微距破面。

來源參照只支持形態、尺寸及生物背景；座標、數量、動畫、互動距離與任務是原創遊戲設計。FAUNA-REFERENCE.md 記錄八種來源。214條目是原作圖鑑保存畫面的盤點數，不是任天堂公布數字，也不是本作已完成數量。

0.10 的甲板行走、八類船艙物件、角色／訪客／本機音樂、四個真實移船泊位，以及原圖底片／相簿資料庫繼續保留。人物和生物仍是程序模型，尚未達到攝影級精細度；本輪不宣称全面超越 Wii。

## 後續獨立切片

1. 工作單08／12：持續擴充剩餘圖鑑條目與可辨識模型、海岸／深海／傳說內容；完善微觀棲地、海綿與珊瑚類、其他自然行為。海馬等八種已落地，不能再列為未實作，也不能因此把工作單08整項打勾。虎鯨及完整夥伴候選／特技尚待完成。
2. 工作單07／09／10：洞窟、遺跡、深海、全潛區、原創主線／解鎖、日夜與季節生態。四個泊位只完成移船機制。季節影響生物已由原作一手資料證實，精確曆表仍需查證。
3. 工作單04／05／12：繼續查核全任務、收藏、裝備、船上事件及原作相簿限制，擴充角色與船艙美術。現有六封原創委託、九件收藏及兩種來訪動物不是完整原作數量。
4. 工作單11：真正跨客戶端雙人遊玩、好友／准入／訊息／筆跡與工具同步／位置、斷線保存。原WFC退役不刪除需求；需外網實際驗收，不能用NPC或同機錄影代替。
5. 工作單13：新增工具完整手把操作、實體手把／手機、長時段與完整真人玩法。現有手機證據是Chromium觸控模擬，沒有實體手機驗收。

所有後續切片仍需玩家UI、實際三維結果、保存重載、失敗案例與適當回歸。只有完整矩陣與全部33條玩家故事有證據後，才可將持續目標設為完成。
