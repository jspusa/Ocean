# 0.13 原創區域與調查故事切片

延續 SPEC 17、24、26、31、33，使用既有同意的瀏覽器 UI、公開行為規則、保存／失敗案例介面驗收。本輪不是全作 feature parity 結案。

三處可實際游入的空間位於現海域邊界內：有頂洞道與側室、人工石造遺跡與檔案室、下降到約 94 公尺的裂谷。地面、牆與屋頂同時參與碰撞及遮擋；地圖、進度及研究船泊位指向實際空間。保留既有 725 個體的身分與生成順序。

原創《回聲潮譜》承接眠海號記錄器，六個研究章節：洞中層理與天窗、遺跡刻文與圖形解讀、取得解讀後回訪、三點觀測器部署與連續記錄、實際觀察兩種深海生物、回收儀器與回船結案。每章須完成現地行為後在船上回報，解鎖後續情報及泊位。六段既有航程仍是前導篇，不能用新六章聲稱完整原作故事深度已等量覆蓋。

調查必須在水下、三維距離內、視線未被牆／岩石擋住；暫停、離開、遮擋不可偷跑計時。解讀刻文須依線索輸入圖形，錯誤可重試。物種觀察要求畫面內真實個體與持續時間，名稱與保存旗標不能代替。觀測器部署／回收會改變實際場景物件。

測試依序：入口及保存預設 → 現地計時／失敗條件 → 解讀／回報門檻 → 觀測器生命週期 → 保存重載；區域路徑及遮蔽 CPU 檢查；桌機、直向與橫向觸控模擬的真實 WebGL 遊玩與截圖。新五種模型須有原作範圍依據、生物一手來源、實際公尺尺度、独立輪廓與動作。仍待完整原作故事盤點、全物種、季節、多人与實體裝置驗收。
