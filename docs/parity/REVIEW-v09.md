## Spec

審查發現 2 項本版 P2 偏差及 1 項需要明確列出的持續目標缺口：

1. SPEC「以實際照片作附件，而非只送出分數或完成旗標」：原投稿只保存日期，最近八張照片輪替會失去影像。已將完成投稿所參照的照片持續保留在八張總容量中，其餘位置輪替最新照片；信箱可重新開啟實際附件。新增十次真實快門後附件仍在、重載保存、實際點開及 JSON 匯入檢查。追查亦修正重複照片日期的匯入／載入邊界：唯一化識別並避免新快門日期碰撞，八個相同日期不會再占滿保留名額。
2. SPEC「不每加一個系統就堆出一排永久控制項」：原生物互動列在每次潛水都顯示。改為附近有適用目標、正在使用互動工具／抓握或同行夥伴時才顯示；提供明確工具啟用與退出流程。
3. SPEC「標準手把完成所有必要操作」：新增手勢工具與面板仍缺完整手把映射。已明確列為未實作，而不是僅缺實體手把測試；此需求仍留在完整 goal 中。

完整目標另外仍缺沖印／完整相簿管理、甲板／船艙與移船、完整角色及動物訪客、微觀內容、時段生態、雙人／好友／斷線流程，以及內容等量盤點。沒有把這些未完成項目降格成已完成；未發現新增的未授權外部服務或範圍擴張。
