# 0.18.11 皇帶魚中層遭遇

基準 `ad9142f6d54a8cf96139b750f7a642048e125c80`（已公開驗證的 0.18.10）。依完整規格第 9、13、24、32、33 條與生物圖鑑工作單，補上正常下潛可辨識的深海內容。完整對等、多人與實體裝置驗收仍保留，不因單一物種新增而完成。

## 玩家結果

1. 玩家由可見入口正常入海，選擇微光中層站，沿連續路線在約 480 m 遇見一隻固定身分的長冠皇帶魚 Regalecus glesne。代表體長 4 m、個體數、位置、巡游範圍、動作節律為原創遊戲配置；來源支持的形態與深度另見 OARFISH-REFERENCE.md。不放到 7,000 m，不複製外部模型／照片／文字。
2. 實際高低 LOD 均呈強烈側扁帶狀身體、銀色帶暗斑皮膚、紅色沿身背鰭、前端延長冠鰭、成對細長腹鰭、小胸鰭與可見眼睛。沒有普通魚的大扇尾、臀鰭或外加發光。主體尺寸以公尺保持一致，不靠文字標籤假裝新物種。
3. 以背鰭波動及緩慢懸停／轉向呈現動態，主體大致直線，含自然的頭朝上姿態而非永遠固定垂直。動畫使用正式時間，暫停選單與已拍照片預覽凍結（攝影取景維持既有即時行為）；顏色與陰影共用變形。移動不隨玩家／鏡頭瞬移，全身與動態外廓留在有效水體。
4. 沿途導覽接近到整條身體與附肢可見的寬側距離並短暫停留，保持選取由滑鼠或觸控發起，不能自動解鎖圖鑑。正常觀察、資訊、攝影、相簿及重新載入有效；未選取不以中央視線擋住畫面。既有微光站仍照常抵達，不因新遭遇卡住。
5. 物種及個體附加到既有清單；41 類既有物種索引及所有歷史個體 UID／外觀／位置／行為保持相容。已編譯世界與程序生成路徑不重複生成。新圖鑑使用本作實際模型渲染及原創 SVG 後備，來源與產生方式列 CREDITS。
6. 僅共用一組高低模型與兩批 instance，不增加逐幀建立幾何／shader。模型高階不超過 12,000 三角形，低階低於高階 60%，新增索引幾何不超過 1 MiB。動畫／材質只作用於新物種；不降低既有解析度、MSAA、畫質、模擬頻率或內容來取得通過。
7. 桌機與觸控尺寸的正常入海／導覽／主動選取／照片／保存流程均有原生 GPU 證據，並檢視模型截圖與連續動作。固定相同場景／解析度，開關新個體比較 GPU／幀時間，保留原始資料與限制；保留自動畫質。觸控模擬不作實體手機驗收。

## 工作與驗證邊界

沿用專案既有的公開內容邊界：registerFauna／faunaGeometry 的實際輸出、正式 addLife／載入後附加及 updateLife、正式圖鑑與存檔生命週期，以及玩家可見 UI。以一項行為 RED → 實作 → GREEN 的順序擴充，不為測試新增專用 runtime 後門。幾何尺寸／外廓與內容相容由 CPU 檢查，視覺、光照、正常輸入與 GPU 成本由原生瀏覽器驗證，兩者不互相代替。
