# v0.18.50 原創海龜造型與全身色彩

基準：已驗證公開 v0.18.49，`11bec02d5507c01ae9cc7ecf4f7ad0ed7e5f3629`。目標是實際改善海龜殼／頭頸／鰭的連續輪廓，以及各部位相符的全身色彩，不能以局部數值通過當作完整擬真完成。Sketchfab 候選尚未取得；本版實作原創模型，將來可保留為選配資產載入前的可用模型。

## 造型與預算

先以 `qa/parity/v01850-turtle-original/world-candidate.js` 的單一候選作受控形態檢查。新殼前寬後收、峰值稍後移，前鰭有厚肩根及不對稱後掠槳身，頸稍窄、喙短鈍；仍是美術建模，不稱為量測重建。外露面不得有裂縫、反向法線或浮離的眼／鰭。高低 LOD 共用同一形態，保持現役完整划鰭、UID、路線與種子消耗。

原有三角數高 12,970／低 1,074 不增；UV seam 可產生合理重複頂點，indexed bytes 最多比基準增加 12%。保留接觸 radius `1.719214937115194` 的下限，並重新檢查全 phase 與垂直界。v49 的可見界保留。九個常駐貼圖與既有渲染 pass 不增；替換 slot 5 使用一張 1024² RGB atlas，舊圖保留以容納舊版頁面，壓縮下載量另如實列出。新 atlas 全身採樣一次；眼部保留原幾何色彩。不以關閉魚群或降低整體自動畫質掩蓋成本。

## Atlas 契約

1024×1024，原圖左上為 (0,0)，與目前 `UNPACK_FLIP_Y_WEBGL=false` 的 image 上傳及 UV v=0 對應。六個色彩區塊無文字、無眼睛／鼻孔圖案、無烘入方向光、無透明邊或背景照片。每個 rect 的邊緣為同部位連續色彩；內縮取樣避免 mip 跨區污染。生物形態／材質為原創 imagegen＋美術設定，不是生物掃描或完整 PBR 掃描。

各部位 triangles 使用自己 rect 的參數 UV，不再用個體 genes 平移整張色圖。殼的 UV 以共同實際 x/z 範圍映射；頭頸的圓周 seam 放在腹側並在網格 seam 複製 vertex attributes，不能讓一個 triangle 跨越整張 atlas。雙鰭可鏡射共享貼圖，仍使用相同解析形狀及合理法線。眼／鼻 tag 4 不讀 atlas，保留原 attributes；頭部淺色下頜改由連續色圖／解剖色差，不按三角形硬切成腹甲 tag。

實際素材分區取自原創生成、版面修正及盾片／啞光修正後的1254²圖：x627，水平界y720／930／1084；技術等比例縮放至1024²後使用上表四捨五入座標。生成工具未精確遵循最初的等大方格，因此調整UV配合實際美術內容，而非宣稱圖像已精確符合原格線。全區16px內縮隔離有抗鋸齒混色的邊緣。

atlas slot 採 CLAMP_TO_EDGE、trilinear mip、明確 anisotropy 1，最大 mip level 3（該層 texel 寬8個base pixels，不代表實際畫面footprint上限）。以真實 UV footprint 在4至8 base pixels之間平滑收斂至各部位低頻色彩，達8時完全退出紋理細節；配合16px內縮避免內部rect串色及遠距閃爍。近景細法線仍由受限幅度的材質細節呈現，必須在材質分支合流後算導數，保持低畫質正常。

## 接受條件

1. 先同鏡位比較單一形狀候選：baseline→candidate→baseline-restored，原光照／相機／時間／實際 actor、鄰居與材質不變，還原畫面必須 exact。觀看側／正／背／腹／斜／抬鰭、遠 LOD 與一般遊玩鏡位。外形不合格不能只靠貼圖遮掩。
2. 所有正式 triangles 有限、非退化且法線合理；殼閉合共邊，眼／鰭根有實際正接觸。所有 atlas triangles UV 有限、在本部位 rect 內、具合法 UV 面積；seam/pole 例外必須逐類寫明，不能一律略過。
3. 對現役完整兩 LOD 執行 production VS 的完整週期、剛性／根部、法線與可見界測試；另外解析全相位 contact 與垂直範圍，不因新 rest radius 稍小就縮窄原路線 clearance。
4. 新材質在實際 uploaded geometry、實際 slot、正式 shader 中驗證 chart方向、mip/wrap與整體動畫外觀。固定一般視角及解剖鏡位；不能為接受偷偷加光、改尺度或移走其他動物。
5. GPU 成本固定同機、同相機、同候選幾何，交替 baseline/candidate 材質測量；保存所有結果及限制，不推論實體手機耗電。正常桌面／觸控維持原自動畫質及進入流程。更新實際圖鑑圖、來源／提示詞紀錄，再完整建置、雙軸審查、精確 Pages commit 與公開全部 manifest 驗證。
