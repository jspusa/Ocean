# 0.15 玩家主動選取與深海潛航

使用者2026-10-15要求先發布裂縫修復，接著改善生物材質、光影、岩層，加入海溝與深海生物，重做過度精簡的操作介面，移除視線中央自動魚名；電腦／手機自動畫質保持。0.14裂縫已發布驗證，基準main `3b03ff8`。

## 可驗收範圍

- 一般游動不自動選中央生物或顯示中央名稱。桌機指向提供輕提示，短按／手機短點選擇真實可見個體；拖曳、多指、工具操作不能誤選。觀察計時、名稱和互動共用一個runtime UID；相機仍能獨立拍攝，不必先選取。
- 正式HUD清楚提供回船、拍照、工具、暫停，顯示實際深度與航程狀態。手機雙搖桿、上浮／下潛按鈕，320／390直向與844橫向不互相遮住。取代遠端bootstrap的臨時隱藏CSS與移動節點補丁，保留有用偏好。
- 從研究船的深海工具部署研究潛航器，700／1400／7000m直接對應實際world Y。三站可自由手動探索，站間沿連續三維路徑航行，可用移動接手；可回收返船。深海存檔不會截到−120m，重載／匯出匯入回到同一位置。
- 研究模式保留淺海泊位、全部原有圖鑑／照片／故事進度；不消耗潛水氣瓶，不把訪客和淺海夥伴拉到深海，不顯示潛水員氣泡。第三人稱呈現研究潛航器。
- 新吸血烏賊、海豬與馬里亞納獅子魚分別配置在合理的自然深度範圍內，保持公尺尺度、真實幾何／陰影／LOD與同一個體身分。Pseudoliparis swirei於2017命名，明示原創海溝追加，不冒稱2007 Wii精確復刻。
- 鸚鵡螺重建真實殼口、內唇、頭罩及觸手；皮膚、殼、眼與薄膜分開設定材質。岩層提供可見輪廓與相符碰撞；燈光、懸浮物、地形細節於實際遊玩畫面檢查。
- 自動畫質保留，在桌機與觸控模擬驗真實RAF與自動調整。實體手機驗證與同硬體Wii比較仍未完成；不以幾何或測試數量宣稱攝影級。

## 證據要求

CPU覆蓋無自動選取、有效／無效目標、手勢取消、深海位置保存、分層平台與碰撞、動物尺度／動作、旅程步進與舊內容保留。瀏覽器以實際點選／觸控部署、移動、選取、快門、返回、重載及JSON匯入驗收；fixtures清楚標示。三尺寸截圖需目視；新模型另用同一公開mesh的受控多角度辨識，不能拿它冒充玩家自然距離。

發布前完成Standards與Spec獨立審查、必要回歸、實際效能、離線啟動與公開檔案SHA-256核對。完整Wii功能對等仍依SPEC與FEATURE_PARITY追蹤，不因本版交付設為完成。
