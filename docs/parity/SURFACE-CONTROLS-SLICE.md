# 水面環視與快速轉身

本切片補上 [SPEC](SPEC.md) 第 1 項兩個缺少的動作，保留連續自由游動與極簡介面。

原作依據是 [WII-PARITY-REFERENCE](../WII-PARITY-REFERENCE.md) 所記錄的 Nintendo 第一代英文說明書印刷 p.7、9：快速轉身及水面環視確實存在。該文件已核對原版 PDF 並保留官方連結與雜湊。本切片沒有重新核對原作按鍵圖、轉身動畫長度或水面啟動深度；以下網頁按鍵及數值都是本專案的操作設計。

| 動作 | 桌面 | 觸控 | 標準手把 |
|---|---|---|---|
| 快速轉身 | Z | 選單 → 更多探索工具 → 快速轉身 | 左肩鍵 LB |
| 水面環視／返回水下 | U | 同一折疊工具區的水面環視／回到水下 | 右肩鍵 RB |
| 環視 | 拖曳／自由滑鼠 | 拖曳場景 | 右搖桿 |
| 恢復游動 | 移動、上下浮潛，或 Esc | 左搖桿、上浮／下潛按鈕 | 左搖桿、深度扳機；選單鍵也可退出環視 |

快速轉身會讓實際朝向反轉 180°，取消自動跟隨及抓握，清除移動慣性，不變更位置。水面環視必須由玩家先游到開闊水面下 1.25 m 以內；介面以 1.2 m 提示。相機抬至海面上 0.35 m，保留玩家原本的水下座標。地區實體及礁石／船物件的完整相機通道會阻止穿透；它不提供從深海傳送到水面的捷徑。

環視期間使用真實海洋渲染與原有拍照。偏好的第一／第三人稱設定不變。移動時立即回到原本鏡頭模式，返回首頁、重新潛水或快速移動也會清除此暫時狀態。存檔仍保存潛水員的真實位置與朝向；不保存海面鏡頭高度或啟用狀態。

CPU 驗證：`node tests/parity/surface-controls.cjs` 共 13 項通過，涵蓋深度／遮擋門檻、鏡頭位置、各移動輸入退出、快速轉身與跟隨取消、暫停隔離、原有存檔讀回，以及實際 `pollGamepad` 的按鍵邊緣。原有區域鏡頭檢查 11/11、連續游動 9/9、連續海域探索 6/6 通過。區域鏡頭測試已補載連續海域所需的 `trench.js`。

瀏覽器腳本：`node tests/parity/surface-controls-browser.cjs http://127.0.0.1:8000/`。它使用實際鍵盤、原生 CDP 觸控、注入的標準手把經 production poll、相機截圖與真實儲存重載；水面位置及物理時間是明示 fixture。結果寫入 `qa/parity/surface-controls-browser.json`，不能以 CPU 通過代替這份執行結果。
