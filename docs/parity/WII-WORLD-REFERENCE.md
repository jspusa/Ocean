# Wii 第一代世界、區域與故事：證據及實作範圍

查證日期：2026-10-13。對象僅為 **2007 年 Wii《Endless Ocean／FOREVER BLUE》第一代**，對應 [SPEC 17／24／26／33](SPEC.md)。承接 [內容盤點](../WII-CONTENT-INVENTORY.md#地區與地圖候選名稱不能當成已驗證完整世界) 與 [功能研究基準](../WII-PARITY-REFERENCE.md)。本文件是研究與下一階段驗收建議，不是 Ocean 的完成宣告，也不將第二代《Blue World／Adventures of the Deep》的地區、傳說或工具混入。

## 下一階段原創實作建議

下表是**本專案設計建議**，不是把待查攻略轉寫為任天堂官方規格。優先度星星只表示下一階段對 SPEC 缺口的幫助；與上方來源星星分開。

| 原創切片 | 最少應有的可玩內容 | 完整回合的驗收 | 優先度 |
|---|---|---|:---:|
| 洞窟調查 | 可辨識入口、實體洞頂與岩壁、能手動游過的分岔／回接路線、透光與黑暗區、局部棲地與現地線索 | 從船上接線索→移船→親自找到洞口→游入／探索／原路或支路返回→回船解讀→保存後重訪；不能碰到入口就完成整區 | ★★★★★ |
| 遺跡解讀 | 真正可進入的石造房間與高低路徑；有位置、距離與視線要求的原創記錄；解讀所得能指引第二次到訪 | 未取得記錄時回船不能完成；已取得時有對應資訊；新線索須在現場再次使用或核實，並推進下一目標 | ★★★★★ |
| 深海探索 | 真實下潛落差、漸減環境光、頭燈照到局部物件、獨有深海生物／棲地，以及可理解的出入與回程 | 船位／入口／地圖／深度一致；氣量耗盡、手動回船、重載均保留正確區域與成果。若設裝備門檻，取得與效果都要可玩 | ★★★★★ |
| 沉船調查 | 能辨識船體與破口，可游入的艙段及出口，內外各有值得尋訪的證物／棲地 | 由情報定位→手動游入與尋物／攝影→離開船體→回船交付；實體證物和相片可重看且不能重複領取 | ★★★★☆ |
| 跨區故事收束 | 船伴對話依已查明證據更新；不同區域的發現指向後續問題；最終現地發現、回船回應及完成後自由探索 | 線索未成立時不能靠開選單補旗標；中途存檔／匯入能接續；完成後仍能回訪，既有圖鑑、照片、收藏、夥伴不丟失 | ★★★★★ |
| 時段／季節重訪 | 至少有能親眼區別的生態變化；若設暫時阻路，要有可見原因、提示及等候後真的變化 | 調晨／昏後再下潛，親自確認路徑或生物改變；保持退出路線可理解。具體週期與門檻標成本作設計 | ★★★★☆ |

建議先把「洞窟現地證據→回船解讀→下一區域」做成一個從頭可玩、可保存的切片，再擴展遺跡／深海／沉船與跨區收束。原創故事可圍繞海域環境紀錄、失聯調查線索與生態觀測發展；不搬用原作人物、白色傳說生物的劇情、碑文或結局台詞。

對每區使用同一份內容清單：入口與出口、可游空間、分岔／回路、獨有棲地、實體記錄、回訪變化、調查完成條件。這些項目應對應玩家能做的事與可核對的世界物件。地名數、信標數、章節文字量和擴大的地圖邊界，均不能單獨作為空間玩法對等的證明。

## 實作驗收需要補的證據

1. 桌機與觸控各有從船上出發、走實際路徑、取得證據、回船推進的一條連續玩家流程；不能只把玩家座標設到目標旁後點按。
2. 瀏覽器畫面證明洞頂／房間／深度／頭燈／船體內部真的被渲染；移動測試證明碰撞、入口和出口可用，壁後目標不能隔牆完成。
3. 在進度每個中間狀態重載及匯入；舊存檔仍可繼續，已領獎勵與拾取物不重複，船位、海圖、區域入口及本次航跡一致。
4. 頭燈、氣量、回船、暫停、相機、微觀、夥伴與帶客流程不得被區域切換遺留在不相容狀態；船移動也不能讓玩家留在舊區域外。
5. 將本作新增區域與原作查證表分開計數：切片全綠只能證明該切片，不足以關閉 SPEC 33 或整體功能對等目標。

以上是後續遊戲驗收建議；本輪只研究來源，**沒有執行 Ocean 的 GPU、瀏覽器流程或效能測試**。
