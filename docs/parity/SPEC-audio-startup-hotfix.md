# 音效準備不能阻擋入海

來源：玩家回報一直卡在「準備海底聲景」，無法進入遊戲。

- 可選的 Web Audio 預備工作最多等待 1.5 秒；原生 suspend Promise 永不完成時仍要結束載入並開啟開始按鈕。
- 預備失敗、逾時或失焦時卸除未使用的音效圖；原生 close Promise 的完成與否不得阻擋入海。
- 玩家正常點擊或觸控開始後，仍在原本的使用者手勢中重試啟用聲音。舊音效 Promise 晚完成不能關閉或修改新的播放圖。
- 首頁預備保持靜音、不抓音樂、不啟動音效週期工作；關閉聲音的偏好、背景分頁及存檔所有權規則維持有效。
- 桌機和觸控操作都能完成正常入海，保留自動畫質；不修改或清除玩家存檔。

驗證邊界：沿用既有原生瀏覽器的 Web Audio 系統邊界注入與正式 UI；以不帶 user gesture 的 CDP 讀取觀察，避免測試本身解除 autoplay 限制。原生 Chrome 的觸控模擬不等於實體手機驗證。
