## 保存及生物狀態

`features.encounters` 保存 `{schema:2, seed, protection:{species,uids}}`。保護名單是該次下潛採用的物種與夥伴 UID 快照；它和 seed 一起決定路線相位與出席個體。`init`／`reset`／`prepareDive({resume:true})` 重播保存的全部輸入，只有新的 `prepareDive({resume:false})` 更新 seed 並重新擷取保護名單。載入不取得隨機數。Web Crypto 不可用時使用有界、不同於前次的本機後繼值，不因取亂數失敗而阻止進入。

舊版只有 seed 的存檔會保留 seed，首次載入時從該存檔的棲地標記、已接委託與夥伴名單擷取保護快照，往後正常保存即保留它。沒有 seed 的更舊存檔使用固定預設 seed。這項遷移無法復原舊版從未保存、且已被改過的歷史保護名單；只承諾遷移後的重播一致性。格式錯誤或不明物種／UID 會受到清理，名單只包含既有個體。

每個實際動物物件以 WeakMap 保留原來的 phase／orbit。每次從這個基準重新推導，不累積偏移，不改 UID、基因、體型、home／center 或照片參照。路線相位只改動已有安全巡游路線的游泳個體；附著／穴居／底棲生物及深海觀察路徑維持原位與參數。沒有新增物種、個體或 GPU 幾何。

常見游泳礁魚按物種與原棲地分組，保留至少 70% 與至少兩隻；原本不足兩隻的群不會消失。獨有及深海生物不抽掉。新下潛開始時已接攝影／帶路委託的物種、標記中的棲地目標、已擁有夥伴不受出席抽選影響。潛水中修改標記，或回船接下／取消委託後續玩，都不重排這次已建立的路線與出席名單；新的保護輸入於下次新下潛採用。每個常見物種／棲地保留的居民仍可尋找，標記不會令缺席個體立刻出現在眼前。新擁有的夥伴由既有季節系統的 owned override 保持可見，不改變既有路線相位。

季節出現條件為 `owned || (encounterPresent && wildHabitat && seasonalAvailable)`。因此新相遇配置不會使鸚鵡螺在白天出現，也不會把冷水物種變成暖水海域的野生訪客；舊有明確擁有的夥伴仍可保留。

續玩保留同一個相遇配置與路線。這不聲稱瀏覽器重新載入後，未保存的全域動畫時間也回到完全相同的瞬間。

## 六條群游路線

| 群 | 個體數 | 原創路線中心（遊戲公尺） | 接觸檢查 |
| --- | ---: | --- | --- |
| 中央礁庭 | 140 | 約 `[1,-6.7,-12]` | ★★★★★ |
| 西側通道 | 48 | 約 `[-57,-11,-43]` | ★★★★★ |
| 東側通道 | 48 | 約 `[58,-12,-60]` | ★★★★★ |
| 沉船入口 | 48 | 約 `[101,-23,-132]` | ★★★★★ |
| 外礁坡 | 48 | 約 `[-14,-28,-183]` | ★★★★★ |
| 外洋走廊 | 48 | 約 `[321,-19,-36]` | ★★★★★ |

每次配置只在上述路線附近小幅改變中心與群的展布，必要時提高深度以避開地形；不把熱帶礁魚隨機撒進深海泥底。`schoolHome`、`schoolGroup`、`schoolSpan` 是從 seed 推導的暫存欄位，原來的 380 個 UID 及身體模型不變。

保守完整包絡使用水平半徑 `16 × span + 0.35 m`、垂直半高 `1.44 × span + 0.35 m`。地面支撐上界涵蓋實際近／遠地面三角網格的頂點格線、深海實際 5 m 網格、實際岩石頂點包圍盒及既有區域實體。群底比該上界至少高 0.9 m，群頂低於海面 0.75 m。獨立測試另外逐一檢查已編譯的真實地面／岩石／船體三角面與全部 LOD。

每群的 `schoolFloor` 保存這個保守支撐上界，讓動作系統在已驗證範圍內重用；離開範圍仍回到正常地形檢查。BVH／地形驗證與亂數只發生在配置時，游動每幀不重新挑選群或建立資產。

## 驗證

```sh
node tests/parity/encounters.cjs
node tests/parity/seasons.cjs
```

相遇測試使用已編譯的實際個體及幾何、正式 features/navigation/deepsea prepareDive 鏈、正式 markPlace／saveVoyage／loadVoyage／readVoyage、正式保存清理與 reset、正式季節及群游動作。儲存後端及 DOM 回饋是測試轉接器，保存內容仍是正式流程產生的 JSON。其他模組建立 DOM／GPU 的 init/reset 由測試略過；不把這項 CPU 測試當成完整瀏覽器匯入或玩家實機驗收。

涵蓋新下潛、潛水中標記棲地後保存／續玩／重載、接取與取消委託、seed-only 遷移、固定保護快照、匯入重播、壞 seed、夥伴、日夜條件、委託與棲地標記、固定附著動物、各群最低數量、64 個保存 seed、380 個不變 UID、真實地形包絡、實際群游位置，以及相片參照不變。公開版仍需另外完成正常操作、畫面、流暢度及部署確認。
