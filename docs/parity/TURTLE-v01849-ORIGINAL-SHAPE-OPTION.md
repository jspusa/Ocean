## 殼：保留取樣排列，換解析輪廓

`src/world.js` 的 `turtleGeometry`／`bodyHalf` 保留目前網格排列及高低取樣數，替換解析 rim。局部 +X 朝頭、+Y 朝上、Z 為左右；`a=0` 朝頭、`a=π` 朝尾。以下列為 `[角度°, x, abs(z)]`，鏡射成完整閉合週期曲線：

```js
const rimControls = [
  [0,   .82,   0],
  [15,  .79,   .22],
  [30,  .68,   .405],
  [45,  .49,   .565],
  [60,  .25,   .66],
  [90, -.20,   .70],
  [120,-.65,   .60],
  [135,-.89,   .45],
  [150,-1.05,  .285],
  [165,-1.14,  .13],
  [180,-1.17,  0]
];
```

採用週期平滑插值；前後端需維持鏡射切線，不可在 `abs(angle)` 邊界形成折線。徑向 dome 可以沿用現有參數：

```js
const s = Math.sin(b);
const x = -.20 + (rimX + .20) * s;
const z = rimZ * s;
const y = -.075 + .012 * Math.cos(a) * s * s
          + (under ? -.15 : .35) * Math.cos(b);
```

此候選讓殼頂為 `.275`、略低於目前 `.298`，峰值移至 `x=-.20`，前後 rim 高度不同。`j===rings` 不再強制寫回固定 `-.075`，應使用兩半共同的解析 rim。移除現有 `sin(a*14)` 均勻邊緣波紋。頂端應保持唯一、上下 rim 精確共邊；不得為了套用此公式而保留兩份不一致的邊界。

## 前鰭：單一連續有厚度曲面

以這組控制列替換 `fin(u,v)` 的形狀計算，既有高／低取樣數保持不變。格式為 `[u, z, centerX, centerY, leadingWidth, trailingWidth, halfThickness]`：

```js
const frontFlipperControls = [
  [0,   .49,  .39, -.060, .075, .085, .055],
  [.12, .63,  .33, -.065, .120, .150, .046],
  [.30, .86,  .20, -.075, .160, .200, .028],
  [.50, 1.13, .06, -.085, .130, .170, .018],
  [.72, 1.39,-.12, -.095, .085, .120, .010],
  [.90, 1.59,-.31, -.100, .035, .060, .004],
  [1,   1.67,-.39, -.100, 0,    0,    0]
];
```

使用平滑且不過衝的 row interpolation；`c = Math.cos(v * TAU)`。截面公式：

```js
const x = centerX + .5 * (leadingWidth + trailingWidth) * c
                  + .5 * (leadingWidth - trailingWidth) * c * c;
const y = centerY + halfThickness * Math.sin(v * TAU);
const lateralZ = z * side;
```

曲面從厚肩根逐步收為長槳尖，前後緣不再完全對稱；不是額外添加的肩球、鰭片或飾條。末端參考半徑約 `1.718`，接近既有 `1.719214937…`；**這只是一個控制點估算，尚未證明整個插值曲面、法線或完整動作包絡合格**。實際插值不可讓寬度／厚度過衝為負，尖端必須閉合並重新驗證 cap normal。

## 目前動作與接觸擁有權

`src/engine.js` 的 `kind 2` 是依 tag 2 與 `abs(z)` 的錨定 shear，並非骨架：`|z|≤.51` 固定，`.51–1.45` 平滑增加權重，最大位移 `y=.37`、`x=.07`，前後鰭共用同一式。殼、腹甲依 tag 保持剛體；頭部位於不動區。

上述前鰭根 `.49` 可留在不動區；厚根需完整埋入殼內，後續曲面再從肩部伸出。首個形狀候選建議不改 shader。若之後改成肩關節旋轉，應另立動畫、變形法線、同動作陰影與接觸範圍契約。

`src/individuals.js` 的 `animalContactEnvelope` 仍擁有岩石接觸包絡。新的視覺形狀若縮小，也不能默默縮窄既有安全下限；若曲面或動作增大則必須擴大有效包絡。六個 UID、種子消耗、路線、個體尺度、存檔及 LOD 距離維持原有擁有權，不由造型函式另行修改。
