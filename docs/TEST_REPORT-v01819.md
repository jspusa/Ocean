# 0.18.19 皺鰓鯊深海遭遇

基準 `a2a4bdab378555b25d53af8a0c774f4228982065`。依 [本輪規格](parity/FRILLED-SHARK-v01819-SPEC.md) 進行原創內容、渲染與正式操作驗證；完整功能及商用目標保持進行中。

## 內容與保存

新增一隻代表全長 1.7 m 的皺鰓鯊，約 900 m 岩壁旁可遇見，接入前往 1,400 m 深海泥底站的正常連續導覽。第 43 類物種追加於既有 42 類之後；前版身分、外觀、棲地與存檔不移動。原創形態、棲地參考與遊戲設計值分列 [來源說明](parity/FRILLED-SHARK-REFERENCE.md)。

六對褶鰓、喉下連接、三尖齒、後置單背鰭與長尾使用實際程序網格；沒有外部照片、掃描或模型。圖鑑棚景與自然深海畫面分開，不用棚景證明自然遊玩。

## 受控畫面與成本

原生近景、高低 LOD 與頭部診斷截圖已人工檢查；遠距以真正 36 m 距離選中低 LOD，再使用棚景鏡頭檢視，不以此冒充自然深海首見。新增個體只佔一組共享高低模型與兩個 instance batch，無逐幀幾何生成。

保留 kind 11／material 0 的 fragment 特化：載入時預先編譯第 8 個表面程式，失敗可回退 generic，逐幀不編譯。只改兩個常數 selector，頂點、陰影、畫質、解析度和其餘內容保持。皺鰓鯊、吸血烏賊、海豬與馬里亞納獅子魚，在兩個時間、三種深海／棚景照明、桌機／觸控配置共 **48 案例、192 個 ABBA 比對畫面**，完整最終 RGBA／SHA-256 與 generic 一致，差異 channel、最大差異及 alpha 差異均為 0。皇帶魚使用 material 6，維持原通用路徑。`v01819-frilled-surface-camera2.json` status=passed、errors=[]、pixelFailures=[]。

## 診斷紀錄與審查

最早 GPU 個體成本 fixture 沒有在計時前開燈，深海截圖全黑；其 `v01819-frilled-gpu-initial.*` 僅保留為診斷，不能用來證明可見動物成本。修正後計時前開燈，並要求動物中心真實像素可見且有差異。早期頭部六條褶鰓過於機械整齊，調整曲線與同皮膚色階後重新產生真正模型縮圖；三角形數與包絡不變。

首次 surface 等值 runner 的海豬取景使用 8 cm 視線球，大於實際約 5 cm 離地焦點而被正確碰撞檢查拒絕。保留前 12 案例零差異與原失敗紀錄；改沿正式 fauna selection 的 1 mm 視線精度，另保留相機自身 12 cm 淨空、泥台高度及完整遮擋檢查，不搬動深海個體。

新增遭遇使 7000 m 導覽模擬超過舊測試 200 秒窗；放寬測試觀察窗至 300 秒後 205.7 秒到站，沒有調快或瞬移。GPU rig 的有效 RED 是基準引擎沒有新尾波，而非最初 runner 選錯 shader 的啟動錯誤；兩種紀錄分開保留。

橫向原生執行前，檢查到 runner 錯把直向 70 CSS px 的長軸要求套用到 390 px 高視窗；依既有 CPU 短視窗契約改為 40 CSS px，桌機／直向仍為 70。完整入鏡、寬側、真實尺度、遮擋與正常觸控命中 UID 要求不變。最終橫向實測 54.38 CSS px，`v01819-frilled-touch-landscape-local.json` 26/26、errors=[]、fatal=null；不把 DPR 換算的實體像素冒充 CSS 尺寸。

[兩軸審查](parity/REVIEW-v01819.md) 有真正獨立 Standards／Spec 來源。先前 P2 圖鑑 JPEG 無 SVG 備援已修並通過獨立 Spec 複查；只有非阻擋 P3 提示分類維護建議。整體商用、完整原作內容、多人與實體裝置驗收仍在進行。
