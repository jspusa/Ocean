# 重返蔚藍 · 光之海 — LIVING OCEAN 0.8

一個可以直接在電腦與手機瀏覽器遊玩的原創海洋探索遊戲。

**[開始潛水](https://jspusa.github.io/Ocean/)**

從研究船下水，在珊瑚花園與遠洋之間自由游動，觀察十二類生物、拍照，完成六段航程記憶後回船。保留 0.7 航程、圖鑑、照片與存檔相容性。沒有倒數、戰鬥、帳號或付費服務。

## 0.8 畫面與體驗

- 一致的水下色彩衰減、方向散射、受遮擋的光束、沙地流動光紋、海面波浪與 Snell 折射視窗。
- 分枝與層狀珊瑚遠景保留輪廓；新增中空海綿、成片海草與沉船附著生物。
- 魚類身形與魚鰭、魟魚腹面和斑點、海豚吻部與背鰭更新；魚群共同移動、轉向，個體有加速與滑行差異。
- 新玩家預設第一人稱，可切換跟隨潛水員。視野 55–90°、水體濃度可調，支援滑鼠自由環視。
- 更清楚的遊戲相片，最長寬度 1920 像素（以實際渲染解析度為上限）；圖鑑使用本版模型重繪。
- 自動畫質在負載下降後也能於 60Hz 裝置逐步恢復。手機保留雙搖桿、多點觸控、直向和橫向配置。

這是即時遊戲光學與原創程序模型，並非攝影掃描或科學求解。Wii《Endless Ocean》是體驗方向；沒有任天堂素材，也未完成與 Wii 原作的內容量、美術與實機全面對照。

## 操作

電腦使用 WASD／方向鍵游動、拖曳環視、E 上浮／Q 下潛、Shift 加速。V 切換視角，F 觀察，X 切換取景，空白鍵拍照。M 海圖、J 圖鑑、B 航程冊、Esc 暫停、H 只看風景。設定內可開啟滑鼠自由環視；點一下海面開始，Esc 釋放。

手機左搖桿移動、右搖桿環視，↑／↓ 調整深度。支援同時觸控。標準手把保留雙搖桿及扳機輸入；沒有實體手把與 iPhone 全面測試證據。

故事模式須親自游向地標，海圖只標記航向。自由重遊可從圖鑑選擇近距離觀察。

## 保存

航程、設定、圖鑑、最近八張照片保存在目前瀏覽器。航程冊可匯出／匯入完整 JSON 備份。匯入前會確認替換，檔案只在本機處理。清除網站資料會清除本機進度。

## 開發與發布

網站為純靜態檔案，不需要 npm、CDN、API key 或後端。保留 `index.html`、`src/`、`assets/`、`music/` 的相對位置；支援 GitHub Pages 專案子路徑。

Python 3.10+、Node.js 18+：

```sh
python3 build.py
python3 -m http.server 8000
```

只修改介面或著色器時可 `python3 build.py --pack-only`。幾何改動必須完整編譯。編譯也產生可離線開啟的 `standalone.html`；它不列入 Git，網站沒有 Service Worker。

驗證：

```sh
node tests/v08/reef_invariants.cjs
python3 tests/v08/static_check.py
node tests/v08/browser-regression.mjs http://127.0.0.1:8000/
node tests/v08/browser-regression.mjs http://127.0.0.1:8000/ --mobile
```

瀏覽器測試需要 Playwright 和 Chrome；可用 `PLAYWRIGHT_PATH` 指定已有套件。只屬開發驗證工具，不會隨網站載入。測試輸出在 `qa/v08/`；詳細結果見 `TEST_REPORT.md`。舊 `tests/v07/` 保留歷史證據，不作 0.8 測試結果。
