# 重返蔚藍 · 回到海洋 — LIVING OCEAN 0.18.21

一個可以直接在電腦與手機瀏覽器遊玩的原創海洋探索遊戲。

**[開始潛水](https://jspusa.github.io/Ocean/)**

一個按鈕入海，從珊瑚礁、遠洋一路游到 7,000 公尺海溝。所有海域連續相接，不需要開船、解鎖泊位或更換潛航器。原有圖鑑、照片與航程存檔仍可延續。

## 0.18.21 雙人同游客戶端

新增正式建房、申請與批准介面、遠端潛水員、海圖位置、分類預設訊息與有界斷線恢復。只有主動連線才傳送暫時名稱、位置、方向、選用工具及預設訊息；照片與個人存檔保留本機。尚未同步生物、世界時間、工具效果與外觀配件；沒有持久好友系統。

公網房間服務尚未設定，公開版會如實顯示「連線服務尚未開放」，並繼續單人探索。本機開發可同時執行 [房間服務](server/README.md)，使用相同遊戲介面；這不代表跨網路多人服務已上線。部署端點由 `room-service.json` 設定，不能透過分享連結或任意使用者輸入改寫。

桌機與同機觸控模擬各通過 67 項本機雙端操作檢查。功能、斷線／故障恢復及公開交付界線見 [本輪報告](docs/TEST_REPORT-v01821.md)；不代表實體手機效能或完整多人功能驗收。

## 0.18.20 水中光影與岩層

微粒與呼吸氣泡依自己的深度、距離與頭燈照明顯示，開放水域不再被背景處理抹去，後方岩壁也不會改變近處氣泡的消光。拍照時會依自身距離回應光圈與對焦；仍使用原有點數與繪製次數，沒有增加全畫面特效。

深海岩壁利用既有材質打散層紋，保留連續地形、全部 43 類生物與主動指向觀察。電腦及觸控的原有自動畫質預設保留。本輪驗證與效能界線會記錄在 [本輪報告](docs/TEST_REPORT-v01820.md)，整體商用目標仍依完整驗收清單追蹤。

## 0.18.19 岩壁旁的皺鰓鯊

從「深海與海溝」選擇深海泥底站，沿連續下潛路線在約 900 m 接近皺鰓鯊。原創細長身體、六對褶鰓、三尖齒與後置鰭，配合獨立身尾波動；點選後可觀察、拍照並保留記錄，圖鑑增加為 43 類。既有個體、存檔與桌機／手機自動畫質保留。

代表全長 1.7 m、路線和節律是本作設計值；形態來源見 [皺鰓鯊參考](docs/parity/FRILLED-SHARK-REFERENCE.md)，驗證範圍見 [本輪報告](docs/TEST_REPORT-v01819.md)。

皺鰓鯊等備有原創插圖的圖鑑，在模型縮圖下載或解碼失敗時會顯示備用插圖，重新開啟仍優先載入模型縮圖。照片與既有保存不受影響。

深海生物使用預先編譯的精簡表面程式；四類生物、不同時間與照明的 48 組完整畫面比對一致。固定場景 GPU 量測及波動見本輪報告，不改模型、陰影或自動畫質預設，也不把單機量測當作全裝置幀率承諾。

## 0.18.18 手把工具指標

標準手把按 View／Select 開啟工具指標：左搖桿移動，A 點選或按住拖曳，右搖桿捲動，方向鍵調整選項，RT 精細移動，B／View 回到游泳。水中筆沿用實際世界座標與正式保存；切換工具、暫停或由滑鼠／觸控接手時取消未完成手勢，避免誤畫與持續移動。

水下生物、船邊訓練與甲板訪客的輕撫判定改為累積位移，修正慢速操作及高更新率下認不出來回動作的問題。手把提示移開底部控制列，5 秒或開始點選後收起，留下游標繼續操作。

滑鼠、觸控與自動畫質保留；指標只在主動啟用時顯示。原生檔案與文字輸入由滑鼠、觸控或鍵盤接手。實際逐項結果與實體裝置限制見 [本輪報告](docs/TEST_REPORT-v01818.md)，完整功能與商用目標仍在追蹤。

## 0.18.17 入海音訊與連線恢復

第一次入海的音訊系統改在載入畫面內靜音準備，點擊才開始播放；關閉聲音的偏好、多分頁保護與自動畫質保留。這把必要初始化移出點擊處理，沒有把總載入成本說成消失。正常桌機與觸控尺寸以無合成手勢的原生瀏覽器驗證；詳細結果及限制見 [本輪報告](docs/TEST_REPORT-v01817.md)。

本機房間服務補上首次建房／核准回覆遺失的原席位恢復與明確取消；仍未接成遊戲內雙人，也未部署公開後端。

## 0.18.16 入水流暢度

研究船與船艙材質改用預先編譯的專用繪製程式，減少船底佔滿視野時的顯示卡負擔。保留模型、光影、抗鋸齒與桌機／手機自動畫質；不預先降低解析度。切換畫質時重用同一顯示環境的取樣能力資料，仍完整檢查新畫面空間並保留失敗前的畫面。

本輪量測與限制見 [0.18.16 報告](docs/TEST_REPORT-v01816.md)。本機房間服務補強重連回覆遺失的恢復，仍未接入遊戲或公開後端。

## 0.18.15 渲染節奏與調查追蹤

降低高更新率螢幕上重複的場景繪製：首頁約 30 次／秒，游泳及互動觀賞最多約 60 次／秒，保留游泳速度、觀察時間與自動畫質。裝置真正卡頓時仍會降畫質，恢復順暢後再逐步回升；這是工作量上限，不是所有裝置的 FPS 或耗電保證。

調查冊與「調查與委託」現在可選擇「追蹤此調查」，完成一步後路標跟著更新。自己改標記就會退出追蹤，讀另一冊不會改掉目的地；回報後清除追蹤。手把 B 只在主動按下時選畫面中央的魚，滑鼠與觸控仍按實際指向選取。

驗證與已知限制見 [0.18.15 報告](docs/TEST_REPORT-v01815.md)。另新增可獨立執行的 [本機房間服務](server/README.md)，尚未接入遊戲或公開部署，不能作為可玩多人功能。

## 0.18.14 海圖上的折痕

從「調查與委託」接下新的獨立調查，沿海流游到 7,000 公尺海溝底。部署基準儀，親自沿切溝下探、記錄三處地形高度，回到泥台點選獅子魚觀察，再回收器材並回首頁整理記錄。中途可保存與重開接續；原六章故事可以同時進行，桌機與手機保留自動畫質。

剖面採用本作實際地形，生物保持原本大小與棲地。完整驗收範圍與器材成本見 [0.18.14 報告](docs/TEST_REPORT-v01814.md)，完整功能對等與商用門檻仍持續追蹤。

## 0.18.13 回到海洋

素材下載停住時會自動重試；仍無法完成時，可由畫面上的「重新嘗試」恢復。完整場景備援下載也有等待期限，失敗後使用原有程序場景。材質更新失敗保留原本畫面，桌機與手機繼續使用自動畫質。這次沒有增加渲染特效或改變畫質預算，範圍與驗證見 [0.18.13 報告](docs/TEST_REPORT-v01813.md)。

## 0.18.12 繼續那段探索

首頁與探索選單現在能直接打開「調查與委託」，查看已接工作、下一處調查目標、同行觀察進度與攝影交件條件。自由探索也會顯示正確調查步驟；回首頁回報後，可在調查冊讀到本章解讀。主要入海按鈕與清爽的水下畫面保留，目標只在你選擇標記時更新。

修正切換分頁或應用程式後，把背景時間算入效能量測與自動畫質的問題。真正發生在前景的慢幀仍完整計入。範圍與驗證見 [0.18.12 報告](docs/TEST_REPORT-v01812.md)。

## 0.18.11 微光中的皇帶魚

## 0.18.10 深海渲染與同行

減少海溝岩壁與泥層的著色負擔，保留材質、光照、場景內容及電腦／手機自動畫質。帶路訪客現在會隨實際游速連續跟隨並保留轉彎，回首頁續玩不再重新生成；合法深海位置完整保存，舊版卡在地下的訪客會在讀取時修復。右下角提供簡短同行距離。

原生 GPU 計時、完整畫面比對、真實游泳與保存證據見 [0.18.10 報告](docs/TEST_REPORT-v01810.md)。完整功能對等、實體手機與商用驗收仍在進行。

## 0.18.9 匯入中斷恢復

匯入時先保留完整舊航程、圖鑑／設定及照片原圖；若分頁或瀏覽器程序中斷，重開會先恢復未完成的匯入，再載入遊戲。恢復遇到儲存錯誤或外部變更時暫停啟動，仍可從持久恢復紀錄下載匯入前的完整備份。日誌主檔損壞會讀取有效備份，無可用備份時不自動用預設值覆蓋。匯入期間有等待提示，桌機／觸控自動畫質保持原設定。

照片資料庫升為第 2 版，更新前請關閉其他 Ocean 舊分頁。這是瀏覽器程序中斷與儲存失敗的保護，不保證網站資料遭刪除或裝置損毀後仍可復原；請定期匯出完整備份。範圍與證據見 [0.18.9 報告](docs/TEST_REPORT-v0189.md)，整體商用與實體裝置驗收仍在進行。

## 0.18.8 航程與備份保護

同一瀏覽器的航程一次由一個分頁使用；第二個分頁會提示先關閉原分頁，再重新讀取最新進度，不會啟動另一套 3D。匯出備份不再順便寫入存檔。照片搬移與匯入會完成或還原後才釋放使用權；即使儲存還原失敗，也保留匯入前的航程與原圖供救援匯出。

請使用支援 Web Locks 的新版 Chrome、Safari 或 Firefox，並在更新後關閉其他舊版 Ocean 分頁。舊版不遵守新保護機制，偵測到外部變更時本頁會停止保存。這不是跨裝置雲端存檔，也不能保證瀏覽器程序崩潰時跨儲存區的原子性。[測試範圍與限制](docs/TEST_REPORT-v0188.md)。

## 0.18.7 游動與顯示恢復

解析度切換改為先建立完整的新畫面，配置失敗時保留舊畫面繼續繪製。海域下載加入 12 秒逾時、最多三次自動嘗試及可操作的重試／返回；等待同一區塊不再每幀累積重複回呼。顯示中斷時可匯出航程並以省電畫質重新啟動，仍保留自動解析度。另修復鍵盤操作被全域捷徑攔截，以及損壞主存檔污染正常備份的問題。[測試範圍與限制](docs/TEST_REPORT-v0187.md)。

## 0.18.6 游動光影與海溝探索

修正自動畫質調整時把剛畫好的畫面清空、造成黑色閃屏的問題。尺寸變更會等到下一幀與附近地形準備好後套用；深海跨越浮動座標原點時，也會同步更新陰影座標。

水中光束改為跟隨海面長波的平滑光場，保留海床焦散與自然呼吸泡。深海導覽移到探索選單主層，沿途慢下來觀察既有種類的深海生物，最後帶到可自行點選的觀察距離；隨時游動或拖曳便能接手。海溝增加近側岩壁、有限泥台及真實下切地形，保留原有個體與存檔。電腦與手機繼續預設自動畫質。[驗證與量測範圍](docs/TEST_REPORT-v0186.md)。

## 0.18.5 高解析度卡頓與每幀負載修正

新增海床專用著色程式，在保留相同模型、貼圖、光影與抗鋸齒的情況下，讓 GPU 刪除海床用不到的分支。原生 M3 Max 的固定高解析度礁景 GPU 中位時間由 49.1ms 降至 23.1ms；同設定連續運作測試約由 18–19 FPS 提升至 38 FPS。觸控模擬的 GPU 時間亦下降，但這些數字不是實體手機或電池續航承諾。

同時修正大螢幕自動畫質比例被像素上限抵消的問題，現在會確實調整繪製尺寸；手動偏好保持不變。減少深海生物的重複路線邊界計算、沒有餵食時的空掃描，以及指向空白處的遮擋查詢。保留正常更新頻率、自由探索、深海及指向／點選介面。[量測方法、畫面比對與限制](docs/TEST_REPORT-v0185.md)。

## 0.18.4 材質載入失敗恢復

修正正式站材質短暫回傳 HTTP 503 時無法啟動，以及失敗後的圖片回呼存取已釋放 GPU 資源的問題。網路材質最多自動重試兩次；永久失敗時清理待執行的工作，材質升級則保留現有貼圖。沿用原圖、解析度、光影與正常更新頻率。[故障重現與驗證](docs/TEST_REPORT-v0184.md)。

## 0.18.3 裝置效能報告修正

修正裝置效能報告把地圖資料版本誤寫成遊戲版本的問題。下水後從「暫停 → 設定 → 進階設定 → 測試裝置效能」開始量測，再選「匯出」。報告與檔名使用目前遊戲版本，另外保留地圖版本，並補上 P99 幀時間以辨識少數嚴重慢幀。報告只由玩家匯出到本機；取樣、畫質、渲染排程及 0.18.2 的 GPU 優化維持原樣。[驗證與限制](docs/TEST_REPORT-v0183.md)。

## 0.18.2 GPU 表面繪製優化

針對仍卡頓的回報，量測實際 GPU 繪圖後，為岩石、珊瑚及礁魚預先編譯三個固定著色程式，讓編譯器刪除各自用不到的材質及動作分支。保留原始著色運算、完整模型、貼圖、光影、遠近過渡及正常更新頻率，附近地圖的載入與釋放距離不變；裝置若拒絕其中一個程式，該類物件使用原有程式。

桌面／觸控共 11 個完整內容視角與 0.18.1 逐 RGBA 位元組相同，解析度、抗鋸齒、幾何、繪製及資料上傳量一致。GPU 計時方法與實測範圍見 [0.18.2 報告](docs/TEST_REPORT-v0182.md)；軟體 WebGL 的改善比例不代表所有手機的 FPS 或耗電量。

## 0.18.1 每幀更新優化

針對游玩仍卡頓的回報，刪除固定深度及轉向樣本用不到的海床查詢、重用固定洞頂索引，並把附近地圖的三組範圍判斷合成一次掃描。保留畫質、正常更新頻率、完整生物狀態及原有載入距離。

在同一 Chromium、相同內容及更新次數下，不含繪圖的正式遊戲邏輯更新中位時間，淺礁由每幀 2.296 ms 降至 1.063 ms；外海與海溝亦減少約 52–55%。這不是整體 FPS、GPU 或實體手機耗電量測。[方法與驗證](docs/TEST_REPORT-v0181.md)。

自由探索須親自游向地標，海圖只標記航向。圖鑑會標記遠處生物的棲地，游近後才可進入觀察；微觀物種同樣須先接近。桌機與手機預設自動畫質，可依負載降低或恢復解析度。

## 保留畫質的效能優化

0.17.1 的固定地圖按需要載入與釋放，沿移動方向預載；動物共用模型、碰撞與完整遊戲狀態保留。淺礁首次場景資料約 12.2 MB（含索引，原整包 21.6 MB），遠方地圖不必一次進入 GPU。另保留附近碰撞查詢、原精度海床、精確 16 位索引、相同模型共用資料及氣泡工作區。11 組固定視角與原版逐像素一致，保留解析度、抗鋸齒、細節及就緒時的更新頻率；必要區塊未到齊時保持前幀並暫停移動，避免缺洞。工作量下降不等同於真機 FPS 或耗電量測。

上述下載量與逐像素比較是 0.17.1 固定場景的結果；0.18 額外魚群及提交優化的成本與驗證另列於 [0.18 報告](docs/TEST_REPORT-v018.md)，不能把新增生物後的整幅畫面宣稱與舊版相同。

實測數據與重跑方式見 [效能驗證](docs/TEST_REPORT-performance.md)，遊戲引擎作法見 [調研紀錄](docs/parity/PERFORMANCE-REFERENCE.md)。

## 保存

航程、調查章節與觀測器、互動筆記、夥伴、筆跡、航跡、收藏、委託、水族館、角色、泊位與設定保存在目前瀏覽器；20 張底片與 120 張相簿照片使用獨立本機影像資料庫。航程冊可匯出／匯入完整 JSON 備份；匯入前確認替換，檔案只在本機處理。舊存檔會補入新功能初始值。清除網站資料會清除本機進度。

## 開發與發布

網站為純靜態檔案，不需要 npm、CDN、API key 或後端。保留 `index.html`、`src/`、`assets/`、`music/` 的相對位置；支援 GitHub Pages 專案子路徑。

Python 3.10+、Node.js 18+：

```sh
python3 build.py --pack-only
python3 -m http.server 8000
```

基礎場景幾何改動需執行完整 `python3 build.py`。本輪沿用經逐塊核對的場景分塊，透過正式載入流程追加皺鰓鯊；程序生成與編譯場景都防止重複個體。編譯也產生可離線開啟的 `standalone.html`；它不列入 Git，網站沒有 Service Worker。
