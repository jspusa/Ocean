# 重返蔚藍 · 歸潮航程 — OPEN WATER v0.7

**可玩的單人航程試作（vertical slice），不是已完成 Wii 全功能對等或通過商業發行驗收的正式版。**

研究船出發 → 自由下潛 → 探索連續海域 → 觀察／攝影／故事委託 → 回船結算。這一版把 v0.6 的小礁區展示擴充成有保存進度與收尾的原創航程。原「石朗」礁區只是地點靈感；新增海域統一稱「歸潮海域」，沒有暗示真實石朗的測量精度。

## 開始遊玩

電腦可下載獨立 `Shilang_Ocean_v0.7.html`，用一般支援 WebGL2 的瀏覽器開啟。完整網站包則需維持下列結構，透過靜態網站網址進入：

```
index.html
.nojekyll
src/
assets/
music/
```

網站包的 index.html **不能單獨拿走**。尤其需包含 `assets/reef.mesh.gz`、`src/open_world.js`、`src/voyage.js` 和其他原有腳本。ZIP 應先解壓，不要直接把 ZIP 檔當成網站首頁。

開始畫面選「航程故事」，點「開始航程」。研究船附近下水後，可跟隨方位標記游向第一片珊瑚；也可選「自由重遊」，不受委託順序限制。第一次使用聲音需要點擊開始／聲音按鈕。自動漫遊不等於實際玩家路線或安全潛水示範。

## 第一航程

1. 從錨地游到珊瑚花園，累積 30 公尺游動。
2. 觀察至少 3 類生物，收錄圖鑑。
3. 拍一張 60 分以上生物照片。
4. 自己游到西側環礁之門；海圖只標記航向，不傳送。
5. 找到眠海號旁黃色記錄器，靠近讀取原創故事。
6. 在遠洋迴廊的視野中觀察大翅鯨累積 4 秒，然後返回研究船。

這是既定內容範圍，不代表已做真人完整遊玩時長測試。可隨時從暫停選單返回船上，進度不要求同一次下潛完成。

## 操作

| 輸入 | 動作 | 支援狀態 |
|---|---|:---:|
| WASD／方向鍵；滑鼠拖曳 | 移動／環視 | ★★★ |
| E／Q；Shift；C | 上下潛／短暫加速／切換巡航速度 | ★★★ |
| V／F／X／Space | 視角／近距觀察或讀取／取景框／拍照 | ★★★ |
| M／J／B／Esc | 地圖／圖鑑／航程冊／暫停或關閉 | ★★★ |
| 手機左、右搖桿；↑↓ | 移動、環視、深度，可同時多點觸控 | ★★☆：瀏覽器觸控模擬通過 |
| 標準手把雙搖桿／LT、RT | 移動、環視、上下潛 | ★★☆：API fixture，非實體手把測試 |
| 手把 A／B／X／Y／Start | 拍照／觀察／地圖／巡航／暫停 | ★★☆ |

按 H 或設定內「只看風景」隱藏主介面；仍能用退出鈕返回。巡航只提高移動速度，不是自動駕駛。在故事模式，圖鑑不會把你傳送到遠方生物；靠近後才可切換觀察。自由重遊則保留快速找模型的功能。

## GitHub Pages

將解壓檔案放在 repository 根目錄。Settings → Pages → Build and deployment → Deploy from a branch → 選 main 和 /(root)，再儲存。使用 Pages 提供的網站網址，不是 GitHub 原始碼頁面。

也可在本機於此目錄執行 `python -m http.server 8000`，再用瀏覽器開啟 `http://localhost:8000/`。此交付沒有替你建立 repository、部署網站或開啟收費。

模組程式與素材使用相對路徑，保留專案子目錄相容性；HTTP 頂層導覽在本測試容器被瀏覽器政策阻擋，因此沒有把靜態路徑檢查說成公開網站端到端驗收。

更新時整組替換 src、assets、music 和 index.html。v0.7 的場景版本需要 v0.7 腳本；不要與前版 reef.mesh.gz 混用。沒有 Service Worker／PWA 快取，因此不應宣稱網站版已支援安裝或離線快取；獨立 HTML 才包含完整離線資料。

## 保存與資料

`return-blue.shilang.v1`：設定、圖鑑、8 張照片、最近 60 筆日誌。
`return-blue.voyage.1`：航程、已發現地標、最佳攝影分數與繼續位置；`.backup` 留前一次備份。

儲存限制或無痕視窗可能導致不能保存。請使用航程冊的「匯出完整存檔」備份；跨裝置以匯入 JSON 搬移。匯入會替換進度，會先詢問。讀入限制 16 MB，只接受本遊戲格式與已知物種、地標，照片只接受有大小上限的 JPEG data URL。

更換網站來源會換一套 localStorage。網站包沒有後端，不代表可以把本機存檔當作有反作弊保護的付費憑證。

## 畫面與效能

保留 4× MSAA（裝置不支援時降級）、個體形變、法線貼圖、動靜態陰影分離、距離模型、動態解析度和固定步長游動。新地形採分塊高／低精度網格，遠方礁體也有簡化模型；沿途不再產生地形或臨時下載新模型。第一次載入仍須取得約 28 MB 網站資料，未做弱網負載驗收。

可以按左下 FPS（電腦 F8）實際量測 20 秒並匯出。目標 60 FPS 不是保證；本次沒有硬體 GPU、實體 iPhone／Safari 或熱降頻測試。不要用截圖或軟體 GPU 功能測試宣稱全裝置流暢。

## 重建

現成發行檔不需要安裝套件。修改場景後，在專案目錄使用 Python 3.10+ 與 Node.js 18+：

```
python build.py
```

只改 UI 或腳本而未改幾何時：`python build.py --pack-only`。場景烘焙會重產生 assets/reef.mesh.gz；完整編譯後生成 index.html 與 standalone.html。修改幾何、地標或生物生成時不能跳過烘焙。

詳見 TEST_REPORT.md、FEATURE_PARITY.md、RELEASE_CHECKLIST.md、CREDITS.md。字型使用系統字型，包內沒有字型檔。
