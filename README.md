## 0.17 外海相遇

- 重做藍鯨、鯨鯊與大翅鯨的頭部、連續尾柄、尾鰭及胸鰭曲面，消除浮在皮膚上的管狀嘴線。藍鯨斑駁、喉褶與鯨鯊斑點、鰓裂使用連續表面細節；遠近模型共用輪廓與花紋。
- 大型遠洋生物移到遠離起始淺礁的開放水域，沿完整路線檢查身體與海床間距。藍鯨與鯨鯊不會在剛入水的位置迎面出現，圖鑑可以標記外海棲地。
- 暖水礁海不再自然出現白鯨、康氏矮海豚與太平洋白側海豚；既有夥伴、圖鑑與水族館內容保留。深海生物依棲地深度分層，原有調查進度延續。
- 新增快速回頭與近水面的水面環視，支援鍵盤、觸控選單與標準手把映射。從深處必須先游上來，離開環視可繼續潛水。首頁與基本設定維持極簡。
- 修正鯨鯊動態陰影、尾擺後的表面法線，以及大型生物遠近模型交疊閃爍。

Wii 第一代功能對等仍在進行；本次補的是水面環視與快速回頭，完整多人同遊、內容覆蓋及實體裝置驗收尚未完成。海域與動物路線為原創配置，沒有宣稱一比一還原實際潛點。進度見 [功能追蹤](FEATURE_PARITY.md)。

## 0.16 自由入海

- 移除船邊半徑、氣量倒數與強制回船；新遊戲與舊存檔都預設自由探索。東方大陸坡連接淺礁和深海，移動、碰撞、海圖與存檔使用同一組世界座標。
- 開闊深水有平順的海流助游，靠近海床與深海生物時放慢。選單的「深海與海溝」也能跟隨海流一路游到目的地，拖曳或移動可隨時接手，沒有瞬間傳送。
- 新增 26 公尺藍鯨與兩隻 8.5 公尺鯨鯊；共 37 類生物。藍鯨保有水平尾鰭，鯨鯊以垂直尾鰭左右擺動。修正原有大翅鯨遠近模型輪廓不一致的問題。
- 保留吸血烏賊、海豬、馬里亞納獅子魚等深海生物，加入吸血烏賊發光器、探照燈水中散射與懸浮粒子色差；深海呼吸和海流聲持續播放。
- 首頁只顯示入海、續玩及設定／關於。設定先顯示聲音、音量、畫質；其餘收在進階設定。暫停選單提供地圖、圖鑑與設定，研究船和完整舊工具保留在「更多探索工具」。
- 返回首頁會保存游泳位置，可直接續玩。延伸的探索格、航跡與水中筆保留舊有識別碼；舊存檔無需重新開始。

這仍是即時程序模型的原創海洋遊戲，非攝影掃描。深海游泳與助游速度是遊戲設計，不模擬真人生理或真實潛水。以下為歷史版本紀錄，其中船隻限制與潛航器流程已由 0.16 取代。

## 0.15 深海潛航與新的操作介面

- 回研究船，選「深海與海溝 · 研究潛航」，即可部署到 700m 微光中層、1,400m 深海泥底或 7,000m 海溝底。三站採實際公尺座標；站間有連續航路，移動或拖曳可立即接手。
- 深海使用研究潛航器，探照燈自動開啟，不消耗淺海氣瓶；可自由移動、觀察、拍照及回收返船。重新整理、匯出及匯入會保留實際深度，淺海泊位、圖鑑與照片延續。
- 新增吸血烏賊、海豬及馬里亞納獅子魚，共35類／740個體。模型維持真尺度，具有分別的腕蹼、管足及薄鰭動作；棲地深度參考自然範圍，地形與研究站為原創。馬里亞納獅子魚是本作追加，非Wii原作逐物種復刻。[來源與量測](docs/parity/TRENCH-FAUNA-REFERENCE.md)。
- 滑鼠指向提供輕提示，點一下或手機短點選取生物；一般環視不再自動在中央顯示名稱。選取資訊放在側邊，點空白處或關閉即可取消。拍照仍可直接取景。
- 主畫面保留回船、深度、拍照、工具、暫停。工具內集中地圖、圖鑑、視角與設定，手機保留雙搖桿及升降按鈕；字幕及導航提示可切換。
- 鸚鵡螺重建殼口與軟體部位；生物皮膚、殼、眼與薄膜分開材質。海溝新增斷層、泥底與實際碰撞，深處坐標採相機附近原點保持小型生物穩定。電腦和手機仍預設自動畫質。

## 0.14 潮汐與季節

- 研究桌新增航程日曆，可休息一天、七天或等到下一季。從航程第 1 年 6 月 1 日出發，月份、跨年與閏日沿用同一份航程存檔；失焦、暫停及檢視照片會停住時間與耗氣。
- 鸚鵡螺在夜間出現，白鯨在冬季到訪，太平洋白側海豚在春秋出現。圖鑑列出下一次時段與棲地；牠們會等離開視野後才退場，不會在眼前突然消失。已結識的夥伴和獨立水族館展示會保留。
- 春夏可遇到船上海豹，秋冬可遇到企鵝。這些月份、時間、來訪安排是本作原創遊戲規則；不代表原作逐物種曆表或真實海域的精確觀察預測。[季節來源與界線](docs/parity/SEASONS-REFERENCE.md)。
- 海蝕洞改為沿長度起伏的拱形洞腔，深海裂谷改為連續不規則岩肩；可見曲面與碰撞共用幾何。游動會沿岩面滑行，避免快速移動穿過薄洞頂。
- 駝背鮟鱇重做頭顎、深入口腔、彎曲牙齒及薄鰭膜，保留 9 cm 個體尺度。所有生物身分、航程進度、照片與收藏延續既有存檔。

本版仍未完成完整功能對等與攝影級擬真；季節內容先涵蓋三種生物，其他常駐內容及完整原作圖鑑仍待擴充。

## 0.13 回聲潮譜

- 玄紋海蝕洞有兩個洞口、天窗、分岔與側室；沉潮觀測遺址有門廊、中庭、雙門檔案室；無光裂谷可沿海床下降到約 94 公尺。牆、屋頂與地面參與真實碰撞、遮擋和陰影，第三人稱鏡頭會避開洞頂。
- 在眠海號讀取記錄器後，回研究船打開「回聲潮譜」。六章原創調查包含層理記錄、刻紋解讀、回訪核對、三深度觀測器部署、持續觀察深海生物及儀器回收。每章需要現地行為與回船解讀，不能只從地標上方經過。
- 三個研究泊位隨調查開放，現在共有七個泊位。儀器實際出現在海床上，回收後移除；調查、解讀、泊位和深潛位置一起保存，舊存檔保留原本進度。
- 新增腔棘魚、巨型烏賊、吞鰻、駝背鮟鱇與日本蜘蛛蟹，五種各有獨立原創形態、鰭／腕／腿動作與真實公尺尺度。新增九個體，合計 32 類／734 個體；原 725 個體的身分、尺寸與位置保留。9 cm 鮟鱇仍須近看，不會被放大成巨魚。
- 洞內與深水會自動啟用潛水燈；光錐照亮表面，並依距離與水色吸收衰減。畫質仍依電腦或手機負載自動調整。

這些地形、故事、儀器、時間門檻和棲地配置均為本作原創；微縮深海不是自然棲息深度重現。[區域參考](docs/parity/WII-WORLD-REFERENCE.md)、[生物来源與尺度](docs/parity/ABYSS-FAUNA-REFERENCE.md)。完整原作潛區、故事與內容覆蓋仍在進行。

0.12.1 修正船上休憩音樂的輸出：原創配樂與本機 MP3 都能在躺椅和閒置欣賞時播放，支援靜音、音量調整，起身後淡出；休憩不播放水下呼吸聲。

## 0.12 海上的朋友

- 新增真海豚、太平洋白側海豚、康氏海豚、虎鯨、白鯨、偽虎鯨與瑞氏海豚，連同原有瓶鼻海豚共八種可結識的鯨豚。七種各有原創輪廓、斑紋、公尺尺度、巡游及尾擺；新增21個持續個體，場景合計725個體／27類。
- 在「工具 → 鯨豚夥伴」標記各自棲地。近距觀察與輕撫後邀請，名冊可有三位、每種一位新夥伴；支援命名、選擇、哨子、抓握、告別與直接替換。舊版既有同種夥伴及熟練度全部保留。
- 回船後在嘴部／胸鰭連點、輕撫或按住，下達旋轉跳躍、前／後空翻、尾行、鳴唱、握鰭六種指令。最多排列三個，再調整 Go 強度；熟練後可執行雙翻／螺旋及三翻／超級螺旋變體。各自熟練度、表演高度與時間會保存。
- 夥伴名冊、告別個體、名字及訓練一起納入完整存檔；大、小夥伴使用相應取景，手機直向與橫向均可直接操作身體。水族館沿用同一模型和尺寸，大型鯨豚有各自容量成本。

原作六指令與候選線索見 [夥伴研究](docs/parity/WII-PARTNER-REFERENCE.md)；精確熟練門檻、信任值、動作與容量是本作設計。尚未確認全部原作招式／解鎖，這次新增不等於完整對等。[形態來源與尺度](docs/parity/CETACEAN-REFERENCE.md)。

## 0.11 微小生命

- 新增豆丁海馬、灰姑娘海蛞蝓、花園鰻、蘭氏槍蝦、彩繪躄魚、月斑蓑鮋、寬腕烏賊與鸚鵡螺，八種各自建立原創幾何；共新增 31 個固定身分的個體，圖鑑目前為 20 類。
- 生物保持公尺尺度，例如豆丁海馬高 24 mm、槍蝦體長 28 mm。海馬附著、海蛞蝓爬行、花園鰻縮洞、槍蝦覓食躲藏、躄魚緩行、鰭裙波動與噴水滑行各有動作，沒有將牠們放大成大型魚。
- 下水後從「工具 → 微觀探索」沿聲音或畫面方向提示尋找微小生命。靠近可見的生物，再點標記進入局部鏡頭，環視、放大、安靜觀察及拍照；游泳位置不變，不能從遠處直接解鎖。
- 微觀照片沿用底片、回船沖印、相簿與完整備份。觀察筆記和個體身分會保存；藏起來或被礁石擋住的生物不會獲得觀察／照片進度，反覆開關鏡頭也不能累加同一次發現。
- 水族館使用相同尺寸、模型與動作，新增細小生物的近看與手機雙指縮放。動作與棲地是原創遊戲近似；尺寸與形態依據見 [生物參考](docs/parity/FAUNA-REFERENCE.md)。

## 0.10 延續的船上與攝影生活

- 水下拍攝保存到 20 格底片；回船在沖印桌選片，收入最多 120 張的相簿，才可用於攝影投稿。支援放大、下載 JPEG 原圖、刪除與投稿附件保護，不自動覆蓋照片。
- 原圖改存本機 IndexedDB，底片與相簿共用 96 MiB 上限。完整備份包含影像本體；舊版相簿自動搬移。空間不足、跨分頁衝突與遺失原圖會顯示可操作的恢復方式。
- 真實甲板路徑、可見人物與步行動畫，能走到船伴、告示板、收藏箱、躺椅、船艙與下水處。船艙有八類物件入口；角色外觀與可解鎖配件可修改，船上有海豹／企鵝來訪事件。
- 躺椅視角可欣賞海面、播放原創配樂或選擇本機音樂；音樂檔案不會上傳。
- 四個原創泊位會移動研究船、甲板物件、船邊訓練位置與下一次入水處。航程模式探索範圍為船邊 180 公尺，完成記憶或發現對應區域可開放泊位；自由探索模式可移動全部泊位、漫遊整片海。

這些泊位、解鎖、角色與容量是本作設計。相機 20 格有原作畫面依據；不將本作相簿容量或移船距離當作原作數值。完整原作內容仍待逐項補齊。

## 延續的相遇與探索

- 撫摸、點觸、投餵與熟悉度筆記。適用大型生物可抓握伴游；五種在本海域自然出現的鯨豚可結識為夥伴，另三種冷水鯨豚保留既有夥伴。夥伴支援命名、呼叫及船邊訓練，排列連續動作並調整訊號強度。
- 海圖隨探索揭開迷霧並記錄航跡；探索工具內支援縮放、平移與雙指縮放。五色水中筆跡留在海中，可擦除或撤銷；九件原創實體收藏可靠近打撈。
- 六封原創攝影／帶路委託逐步開放。帶路訪客會實際跟隨；攝影委託需從相簿選擇符合物種與構圖條件的照片，回船投稿並解鎖潛水衣配色。
- 相機視角、光圈、對焦和曝光補償會改變實際影像。這是即時景深近似，不是物理相機求解。拍攝後的底片與相簿流程見上方。
- 新舊航程皆為自由探索，沒有氣量倒數或耗氣返船。研究桌可休息到晨、昏、夜並選擇隨時間改變光照。
- 水族館依觀察進度解鎖，熟悉的生物可手動或自動配置、移除、清空，進入實際三維展缸觀賞。

熟悉度門檻、委託與水族館容量是本作設計值，不聲稱等於原作數值。尚缺完整潛區／故事／生物內容、完整角色及船上事件、完整夥伴解鎖／特技對照、完整微觀生態內容及雙人連線；這些需求仍保留。來源與驗收範圍見 [官方資料盤點](docs/WII-PARITY-REFERENCE.md) 和 [完整規格](docs/parity/SPEC.md)。

## 畫面與操作

水下色彩衰減、方向散射、受遮擋的光束、沙地流動光紋、海面波浪與 Snell 折射視窗延續 0.8；珊瑚、海草、魚群與大型生物使用原創程序模型。這不是攝影掃描或實測海域，未宣稱全面超越 Wii。

電腦使用 WASD／方向鍵游動、拖曳環視、E 上浮／Q 下潛、Shift 加速。Z 快速轉身，U 在開闊水面下環視海面。V 切換第一／第三人稱，F 選取指標下生物，X 取景，空白鍵拍照。M 海圖、J 圖鑑、B 航程冊、T 潛水工具、Esc 退出工具／暫停、H 只看風景。設定內可開啟滑鼠自由環視。

手機使用左搖桿移動、拖曳場景環視，↑／↓ 調整深度；支援多點觸控、直向與橫向。快速轉身與水面環視收在「選單 → 更多探索工具」。標準手把使用雙搖桿及扳機，LB 快速轉身、RB 水面環視；其餘工具的完整手把流程與實體裝置全面驗證仍待完成。

自由探索須親自游向地標，海圖只標記航向。圖鑑會標記遠處生物的棲地，游近後才可進入觀察；微觀物種同樣須先接近。桌機與手機預設自動畫質，可依負載降低或恢復解析度。

## 保留畫質的效能優化

固定障礙物改用附近空間格查詢，靜態海床重用原始高度資料；繪圖減少相同資料與材質參數的重複上傳，並更精確地排除視錐外的固定幾何。保留原版解析度、抗鋸齒、細節與更新排程，11 組固定視角與原版逐像素一致。完整地圖資源串流尚未實作；工作量下降不等同於真機 FPS 或耗電量測。

實測數據與重跑方式見 [效能驗證](docs/TEST_REPORT-performance.md)，遊戲引擎作法見 [調研紀錄](docs/parity/PERFORMANCE-REFERENCE.md)。

## 保存

航程、調查章節與觀測器、互動筆記、夥伴、筆跡、航跡、收藏、委託、水族館、角色、泊位與設定保存在目前瀏覽器；20 張底片與 120 張相簿照片使用獨立本機影像資料庫。航程冊可匯出／匯入完整 JSON 備份；匯入前確認替換，檔案只在本機處理。舊存檔會補入新功能初始值。清除網站資料會清除本機進度。

## 開發與發布

網站為純靜態檔案，不需要 npm、CDN、API key 或後端。保留 `index.html`、`src/`、`assets/`、`music/` 的相對位置；支援 GitHub Pages 專案子路徑。

Python 3.10+、Node.js 18+：

```sh
python3 build.py --pack-only
python3 -m http.server 8000
```

幾何改動需執行完整 `python3 build.py`。本版重新烘焙 0.17 場景，包含大型生物曲面、固定個體與棲地位置；船的定位標記繼續支援移船。編譯也產生可離線開啟的 `standalone.html`；它不列入 Git，網站沒有 Service Worker。
